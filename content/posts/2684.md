## 版本docker > 1.12

修改/etc/docker/daemon.json文件，没有则手动创建。

```
{
    "registry-mirrors":[
        "https://registry.docker-cn.com",
        "http://hub-mirror.c.163.com",
        "https://docker.mirrors.ustc.edu.cn"
    ],
    "insecure-registries":[]

}
```
registry-mirrors添加对应额国内镜像即可。

## 重启docker服务即可

systemctl restart docker
