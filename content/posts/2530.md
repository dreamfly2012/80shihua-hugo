<p>php7.4编译安装的时候，会出现 Package requirements(sqlite3 &gt; 3.7.4)的错误，但是输入sqlite3之后显示</p>
<pre><code class="language-shell">SQLite version 3.22.0 2018-01-22 18:45:57</code></pre>
<p>说明sqlite版本没有问题，这个时候需要执行下面的命令就可以了</p>
<pre><code class="language-shell">sudo apt-get install libsqlite3-dev</code></pre>
<p>如果是centos系统，则执行下面的命令就行</p>
<pre><code class="language-shell">sudo apt-get install sqlite-dev</code></pre>
