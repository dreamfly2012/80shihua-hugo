下面是一个求数组最大值的例子，输出的结果会是什么呢？

```javascript
var tmp = new Array('1','12','4','124','9','8','22228','456');
var max = tmp[0];
for(var i=1;i<tmp.length;i++){
  if(max<tmp[i]){
    max=tmp[i];
  }
}
console.log(max);
```
如果不仔细分析，会认为是22228，结果却是9。

这是因为数组中的元素加了引号，是字符串，我们需要将他进行转换成数值。

```javascript
var tmp = new Array('1','12','4','124','9','8','22228','456');
var max = paresInt(tmp[0]);
for(var i=1;i<tmp.length;i++){
  if(max<paresInt(tmp[i])){
    max=paresInt(tmp[i]);
  }
}
```
