<h2>交叉编译</h2>
<p>在一个平台上生成另一个平台可执行的文件，就叫做交叉编译。</p>
<p>一个cpu体系可以有不同的操作系统，一个操作系统也可以使用不同的架构平台。</p>
<p>有了交叉编译，我们在windows上写的程序，也可以生成在linux运行的二进制程序，可以说写一次代码，可以各个平台运行。</p>
<h2>go</h2>
<p>通过使用go version 可以查看当前go的版本</p>
<pre><code class="language-shell">go version go1.13.1 windows/amd64</code></pre>
<p>笔者的当前环境是go1.13.1</p>
<p>目前交叉编译非常方便，命令也很简单，直需要在cmd命令上设置环境变量即可，记住，不要使用powershell<br />
，要使用cmd才行。</p>
<pre><code>set GOARCH=amd64
set GOOS=linux

go build</code></pre>
<h2>powershell 交叉编译</h2>
<p>powershell和cmd设置环境变量的方式不一样</p>
<pre><code class="language-shell">$env:GOPATH=&quot;amd64&quot;
$env:GOOS=&quot;linux&quot;

go build -o &quot;web&quot;</code></pre>
<p>通过-o指定编译的文件名，linux可执行文件不需要后缀名.</p>
