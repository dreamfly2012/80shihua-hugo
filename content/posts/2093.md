<p>模板引擎就是一个可以再模板中使用变量的一套框架，可以方便我们进行html的嵌套</p>
<p>接下来我们讲解如何在go开发中使用模板引擎。</p>
<ol>
<li>引入模板引擎包html/template</li>
<li>创建模板文件夹，创建模板文件</li>
<li>在控制器中对模板中使用的变量进行赋值</li>
<li>在模板中使用变量</li>
</ol>
<pre><code class="language-go">handleIndex(w http.ResponseWriter, r *http.Request){
   data := {
      Title string
      Items []string
   }{
      Title:,
      Items:[]string{
         &quot;zhangsan&quot;,
         &quot;lisi&quot;,
      },
   }

   templates.ExecuteTemplate(w,,data)
}</code></pre>
<pre><code class="language-go">    var templates *template.Template

    templates = template.Must(template.ParseGlob(&quot;templates/*.html&quot;))
    r := mux.NewRouter()
    r.HandleFunc(, handleIndex)</code></pre>
<p>通过调用tempate.Must方法，我们可以对模板文件夹进行解析</p>
<p>然后调用tempalates.ExecuteTempate表示具体调用哪个模板文件，并且需要传什么参数。</p>
