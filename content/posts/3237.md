1：存储

Replit 使用云存储来保存其所有数据，并且它有很多存储空间：每个项目 500MB。

VSCode将所有数据保存在您的设备上。

2：开源

任何知道Replit是什么的人都可以在Replit上查看您的代码，除非您有黑客计划（您必须付费）。

在VSCode上，你所有的代码都是私有的，除非你使用GitHub来开源。

VSCode 上的 GitHub 很棒，因为它易于使用。

Replit 上的 GitHub 也很棒，但它会创建一些不必要的文件，例如文件夹、文件夹和文件。**pycache**venvpoetry.lock

3：软件包安装

在 Replit 上，当您需要导入模块时，它会自动安装软件包，而无需使用 pip。

在 VSCode 上，您必须使用并手动安装软件包。pip

4：托管

在 Replit 上，当您运行具有前端的代码时，它会自动免费托管它。

在 VSCode 上，只有设备上的人员才能看到代码的前端。

5：哪些设备

Replit 可以在您可以登录 Replit 的任何设备上运行。

VSCode 将仅在您安装了代码的设备上运行。

总结：

| replit | VSCode |
| --- | --- |
| 节省云存储 | 保存在您的设备上 |
| 公共代码 | 私有代码 |
| 在 GitHub 上创建不必要的文件 | 在 GitHub 上完美运行 |
| 自动软件包安装 | 手动软件包安装 |
| 免费托管 | 无托管 |
| 在任何设备上运行 | 仅在一台设备上运行 |
