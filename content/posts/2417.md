<p>windows10上目前可以使用的虚拟机主要是三种，一个是vmware，一个是virtualbox，一个是hyper-v，其中virtualbox是开源的虚拟机，但是相对来说性能稍差一些，vmware是收费的，而hyper-v是微软自带的虚拟机，综合可虑，有自带的工具，我们就使用自带的。</p>
<h2>安装需求</h2>
<p>Hyper-V 可用于 64 位 Windows 10 专业版、企业版和教育版。 Hyper-V 需要二级地址转换 (SLAT) &#8211; 存在于 Intel 和 AMD 最新一代的 64 位处理器中。</p>
<ul>
<li>具有二级地址转换 (SLAT) 的 64 位处理器。</li>
<li>CPU 支持 VM 监视器模式扩展（Intel CPU 上的 VT-x）。</li>
<li>最少 4 GB 内存。 由于虚拟机与 Hyper-V 主机共享内存，因此将需要提供足够的内存来处理预期虚拟工作负荷。</li>
<li>虚拟化技术 &#8211; 可能具有不同标记，具体取决于主板制造商。</li>
<li>硬件强制实施的数据执行保护。</li>
</ul>

<p>8.配置网络，通过NAT技术进行连接</p>
<p>NAT 使用主计算机的 IP 地址和端口通过内部 Hyper-V 虚拟开关向虚拟机授予对网络资源的访问权限。</p>
<p>网络地址转换 (NAT) 是一种网络模式，旨在通过将一个外部 IP 地址和端口映射到更大的内部 IP 地址集来转换 IP 地址。 基本上，NAT 使用流量表将流量从一个外部（主机）IP 地址和端口号路由到与网络上的终结点（虚拟机、计算机和容器等）关联的正确内部 IP 地址</p>
<p>此外，NAT 允许多个虚拟机托管需要相同（内部）通信端口的应用程序，方法是将它们映射到唯一的外部端口。</p>

<h2>注意事项</h2>
<p>hyper一般是随系统启动而启动的，因此启动系统之后，我们可以直接连接虚拟机。</p>
<p>vmware和hyper是不兼容的，如果使用hyper请先卸载vmare.</p>
