<p>随着技术的发展，目前开发一个桌面应用变得非常的简单，我们可以使用各种语言来开发桌面应用，今天我们就来介绍下使用JavaScript如何开发桌面应用。</p>
<h1>什么是Electron</h1>
<p>electron是一个开源的JavaScript框架代码，很多应用都使用它进行了开发，比较著名的案例有Discord,Slack,Notion,Vscode,Spotify等。</p>
<p>electron通过使用JavaScript，HTML,CSS等技术来开发桌面应用，它采用NodeJS作为后端环境，使用Chromium浏览器引擎作为运行容器。</p>
<p>electron开发了很多API来供我们调用，通过这些API，我们可以使用很多桌面的功能，让桌面应用开发异常方便。</p>
<h1>Ecectron APP 架构</h1>
<pre><code>
├── index.html
├── index.js
├── node_modules
├── package-lock.json
└── package.json
</code></pre>
<h2>安装</h2>
<p>安装electron非常的简单，只需要使用下面命令即可。</p>
<pre><code class="language-shell">mkdir my-electron-app 
cd my-electron-app
npm init
npm install --save-dev electron
</code></pre>
<p>在package.json文件中添加启动脚本。</p>
<pre><code class="language-json">{
  &quot;scripts&quot;: {
    &quot;start&quot;: &quot;electron .&quot;
  }
}</code></pre>
<pre><code class="language-shell">npm run start</code></pre>
<h2>后端</h2>
<p>对于每一个electron应用，都会有一个 <code>index.js</code> 或者 <code>main.js</code> 文件，这个文件会告诉我们应用运行的页面是什么，页面的配置是什么。</p>
<pre><code class="language-js">// Modules to control application life and create native browser window
const { app, BrowserWindow } = require(&#039;electron&#039;)
const path = require(&#039;path&#039;)

const createWindow = () =&gt; {
  // Create the browser window.
  const mainWindow = new BrowserWindow({
    width: 800,
    height: 600,
    webPreferences: {
      preload: path.join(__dirname, &#039;preload.js&#039;)
    }
  })

  // and load the index.html of the app.
  mainWindow.loadFile(&#039;index.html&#039;)

  // Open the DevTools.
  // mainWindow.webContents.openDevTools()
}

// This method will be called when Electron has finished
// initialization and is ready to create browser windows.
// Some APIs can only be used after this event occurs.
app.whenReady().then(() =&gt; {
  createWindow()

  app.on(&#039;activate&#039;, () =&gt; {
    // On macOS it&#039;s common to re-create a window in the app when the
    // dock icon is clicked and there are no other windows open.
    if (BrowserWindow.getAllWindows().length === 0) createWindow()
  })
})

// Quit when all windows are closed, except on macOS. There, it&#039;s common
// for applications and their menu bar to stay active until the user quits
// explicitly with Cmd + Q.
app.on(&#039;window-all-closed&#039;, () =&gt; {
  if (process.platform !== &#039;darwin&#039;) app.quit()
})
</code></pre>
<pre><code class="language-js">const { app, BrowserWindow } = require(&#039;electron&#039;);
</code></pre>
<p>关于electron的一些重要知识点:</p>
<ul>
<li><a href="https://www.electronjs.org/docs/latest/api/app">app</a>; 控制应用的生命周期</li>
<li><a href="https://www.electronjs.org/docs/latest/api/browser-window">BrowserWindow</a>; 创建新的浏览器窗口。</li>
</ul>
<pre><code class="language-js">const createWindow = () =&gt; {
  const win = new BrowserWindow({
    width: 400,
    height: 400,
  });
  win.loadFile(&quot;./index.html&quot;);
};
</code></pre>
<p><code>createWindow</code> 函数做了两件事:</p>
<ol>
<li>它定义了窗口的一些属性，比如高度，宽度。</li>
<li>加载一个文件 <code>index.html</code></li>
</ol>
<p>调用这个函数，就相当于在浏览器中打开了 <code>index.html</code> 文件。</p>
<p><code>createWindow</code> 需要在 <code>whenReady</code>执行之后才调用。</p>
<p><code>whenReady</code> 返回一个Promise 对象。</p>
<pre><code class="language-js">app.whenReady().then(() =&gt;{
  createWindow();
});
</code></pre>
<h2>前端</h2>
<p><code>index.html</code> 文件里面的内容就是应用前端要显示的内容。</p>
<p>下面是它的内容。</p>
<pre><code class="language-html">&lt;!--index.html--&gt;

&lt;!DOCTYPE html&gt;
&lt;html&gt;
  &lt;head&gt;
    &lt;meta charset=&quot;UTF-8&quot;&gt;
    &lt;!-- https://developer.mozilla.org/en-US/docs/Web/HTTP/CSP --&gt;
    &lt;meta http-equiv=&quot;Content-Security-Policy&quot; content=&quot;default-src &#039;self&#039;; script-src &#039;self&#039;&quot;&gt;
    &lt;title&gt;Hello World!&lt;/title&gt;
  &lt;/head&gt;
  &lt;body&gt;
    &lt;h1&gt;Hello World!&lt;/h1&gt;
    We are using Node.js &lt;span id=&quot;node-version&quot;&gt;&lt;/span&gt;,
    Chromium &lt;span id=&quot;chrome-version&quot;&gt;&lt;/span&gt;,
    and Electron &lt;span id=&quot;electron-version&quot;&gt;&lt;/span&gt;.

    &lt;!-- You can also require other files to run in this process --&gt;
    &lt;script src=&quot;./renderer.js&quot;&gt;&lt;/script&gt;
  &lt;/body&gt;
&lt;/html&gt;
</code></pre>
<p>经过上面的配置，我们就实现了用自定义的浏览器窗口打开了一个自定义的页面。</p>
<h1>运行 Electron App 运行</h1>
<p>之前我们在scripts中配置了启动脚本，因此我们直接运行脚本即可。</p>
<pre><code class="language-shell">npm run start</code></pre>
<h2>结果</h2>
<p>如果没有意外的话，我们的<code>electron</code> 的第一个应用就运行成功了。</p>
