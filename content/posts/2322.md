## yum命令

我们知道windows上安装软件非常方便，只需要点击下一步就可以了，但是查找软件，下载软件却并不简单，有时候可能会花费大量的时间，相比于windows,linux安装软件非常简单，以centos举例，我们只需要一个命令就可以安装软件了。

```
<code>yum instlall mysql</code>
```
一行命令，一个软件就安装好了。

## 安装源

为什么一行命令就可以将下载软件和安装软件搞定了？原来yum命令会去寻找安装源，哪里面就是一个网址，而那个网址提供了许多软件的安装包，我们执行install命令的时候，就会从那些安装包中找到对应的安装包，然后下载，然后解压安装。

当然不同的源对应的安装包是不一样的，有些多，有些少，默认centos提供的源是在/etc/yum.repos.d/CentOS-Base.repo

我们可以下载自己的源

```
<code>wget http://mirrors.163.com/.help/CentOS7-Base-163.repo</code>
```
然后执行命令,就可以看到自己的软件包源了

```
<code>yum makecache
yum -y update</code>
```
