<h2>golang</h2>
<p>Go（又称 Golang）是 Google 的 Robert Griesemer，Rob Pike 及 Ken Thompson 开发的一种静态强类型、编译型语言。Go 语言语法与 C 相近，但功能上有：内存安全，GC（垃圾回收），结构形态及 CSP-style 并发计算。</p>
<h2>Gin</h2>
<p>Gin是go语言开发的一个HTTP高性能web框架，它有着Martini风格的API,但是性能却是Martini的40倍，同样，他提供丰富的功能，可以满足常用开发需求。</p>
<h2>安装</h2>
<ul>
<li>通过go get 安装
<pre><code class="language-shell">go get -u -v github.com/gin-gonic/gin</code></pre>
</li>
<li>通过go mod 安装
<pre><code class="language-shell">go mod init test</code></pre>
<p>程序引入即可，然后go run就会自动安装包依赖</p>
</li>
</ul>
<h2>使用demo</h2>
<pre><code class="language-golang">package main

import &quot;github.com/gin-gonic/gin&quot;

func main() {
    r := gin.Default()
    r.GET(&quot;/ping&quot;, func(c *gin.Context) {
        c.JSON(200, gin.H{
            &quot;message&quot;: &quot;pong&quot;,
        })
    })
    r.Run() // listen and serve on 0.0.0.0:8080
}</code></pre>
<h2>注意事项</h2>
<ul>
<li>需要配置好golang环境，版本大于1.11</li>
