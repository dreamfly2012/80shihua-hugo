首先，打开MSYS2软件，执行以下命令更新包数据：

```
`pacman -Syu`
```
执行以下命令安装C++开发环境，选择全部选择 all 即可：

```
`pacman -S --needed base-devel mingw-w64-x86_64-toolchain`
```
执行以下命令安装gcc编译器：

```
`pacman -S mingw-w64-x86_64-gcc`
```
执行以下命令安装make工具：

```
`pacman -S make`
```
