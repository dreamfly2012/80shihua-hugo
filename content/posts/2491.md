<h2>DOMDocument</h2>
<p>php提供了非常好用的解析html和xml文档的扩展库DOM，使用这个库可以非常高效的进行html和xml文档的解析，它的原理就是通过寻找首尾匹配对来进行文档的解析。</p>
<p>从上面的分析可以看出，如果首位不匹配，可能就会导致一些错误的出现，因此，这个时候我们需要设置</p>
<pre><code class="language-php">libxml_use_internal_errors(true);</code></pre>
<p>来进行错误的屏蔽，让它可以解析整个文档。</p>
<h2>解析html基本用法</h2>
<pre><code class="language-php">$dom = new \DOMDocument;
$content = htmlspecialchars_decode($content);
libxml_use_internal_errors(true);
$content = mb_convert_encoding($content, &#039;HTML-ENTITIES&#039;, &#039;UTF-8&#039;);
$dom-&gt;loadHTML($content);</code></pre>
<p>$content是要解析的html字符串，其中我们对它进行了转义，因为可能含有实体集，然后我们有进行了编码的转换，因为可能文档不是utf-8格式的，会导致日文，法文等文字乱码。</p>
<h3>获取元素</h3>
<pre><code class="language-php">$a = $dom-&gt;getElementsByTagName(&#039;a&#039;);
$p = $dom-&gt;getElementsByTagName(&#039;p&#039;);</code></pre>
<h3>遍历元素</h3>
<pre><code class="language-php">$elements = $dom-&gt;getElementsByTagName(&#039;a&#039;);
foreach ($elements as $element) {
   $element-&gt;textContent = &#039;替换成其它的文字&#039;;
}</code></pre>
<p>通过上面的循环，可以将全部a标签的文字替换掉。</p>
<h3>元素嵌套</h3>
<p>有些时候，html会嵌套很多层，比如</p>
<pre><code class="language-html">&lt;div&gt;
&lt;p&gt;
&lt;a href=&quot;xxx&quot;&gt;我是文字&lt;/a&gt;
&lt;/p&gt;
&lt;p&gt;
内容替换
&lt;/p&gt;
&lt;/div&gt;</code></pre>
<p>如果我们想要对p标签文字进行替换的化，并且不想要替换含有子元素的内容，就是这里的a标签不想替换，下面的语句不能够解决我们的问题：</p>
<pre><code class="language-php">$elements = $dom-&gt;getElementsByTagName(&#039;p&#039;);
foreach ($elements as $element) {
    if($element-&gt;hasChildNodes()){
        $element-&gt;textContent = &#039;p标签内容替换&#039;;
    }
}</code></pre>
<p>上面的代会将a标签的内容也替换掉，这不是我们想要的结果，因为hasChildNodes()这个函数表示的含有内容，无论它是标签还是文字，它都是返回true的，除非它是空标签，例如</p>
</p>
<p>它才会返回false.</p>
<p>所以我们需要自己封装一个函数进行检查是否含有嵌套标签。</p>
<pre><code class="language-php">function hasChild($element, $tags)
{
    foreach($tags as $v){
    $elements = $element-&gt;getElementsByTagName($v);

    if($elements-&gt;length){
    return true;
    }

    }
    return false;
}
$tags = array(&#039;title&#039;,&#039;h1&#039;,&#039;h2&#039;,&#039;h3&#039;,&#039;h4&#039;,&#039;h5&#039;,&#039;a&#039;,&#039;p&#039;,&#039;dd&#039;,&#039;img&#039;);   

$elements = $dom-&gt;getElementsByTagName(&#039;p&#039;);
foreach ($elements as $element) {
    if(hasChild($element, $tags)){
        $element-&gt;textContent = &#039;p标签内容替换&#039;;
    }
}</code></pre>
<p>通过我们自己封装的函数，就可以判断出$dom的node节点是否含有子标签。</p>
<p>最后调用saveHtml方法，就可以获取到修改之后的html文档内容.</p>
<pre><code class="language-php">$dom-&gt;saveHTML();</code></pre>
