<p>出现这个错误，是php的兼容性问题，造成的原因是，原来写的代码是在php4的环境下运行的，现在挪到5之后，出现了2个构造函数，解决的办法只需要把__constructor()放到前面即可，如：</p>
<div>construct放到 和类名同名的构造函数之前。<br />
&lt;?php<br />
class MyClass {<br />
function __construct() { //for PHP5.0<br />
echo &#8216;this is class2 construct&#8217;;<br />
}<br />
// 为了使类代码同时兼容 PHP4.0 和 5.0<br />
function MyClass() { //for PHP4.0<br />
$this-&gt;__construct();<br />
}<br />
}<br />
$c3 = new MyClass;<br />
?&gt;</div>
