很多时候，我们明明安装了某个字体，但是在程序里面却无法使用，或者不起作用，这个时候很多情况是我们没有设置正确字体的正确名称，因为我们通过邮件属性看到的标题等信息，并不是字体的真实名称，我们需要一些方法来获取字体的真实名称。

## python程序读取

我们可以通过下面的python程序来读取系统中的字体列表

```python
from matplotlib import font_manager
ttf_lists = font_manager.fontManager.ttflist
for font in ttf_lists:
    print(font)
```
![](https://80shihua-1251274653.cos.ap-shanghai.myqcloud.com/wp-content/uploads/2023/07/font-1.png)
font name

其中name属性就是我们想要获取的字体真实名称。

## 双击查看法

直接双击安装字体界面，会看到有个字体名称，这个就是字体的真实名称，可以被很多配置文件使用。

[![](https://80shihua-1251274653.cos.ap-shanghai.myqcloud.com/wp-content/uploads/2023/07/font2.png)](https://80shihua-1251274653.cos.ap-shanghai.myqcloud.com/wp-content/uploads/2023/07/font2.png)

图片中的第一行，字体名称就是字体的真实名称。
