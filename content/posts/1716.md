<p>最近有个朋友请求帮忙修改下他的站点，希望友情链接按照不同分类，显示不同的友情链接。默认情况下，友情链接是没有分类的，如果要按照分类显示的话，我们就需要修改数据库，增加分类这个表。既cmf_link 这个表增加一个cid分类字段，然后每个分类读取数据库相应数据，然后显示在页面上。</p>
<p></p>
<p>下面具体说下修改步骤：</p>
<p></p>
<blockquote>
<ol class=" list-paddingleft-2" style="list-style-type: decimal;">
<li>
<p>修改数据库表结构：</p>
</li>
</ol>
</blockquote>
<p>&nbsp; &nbsp;alter table cmf_link add column `cid` INT(11) NOT NULL DEFAULT &#39;0&#39; COMMENT &#39;分类id&#39;;</p>
<p></p>
<blockquote>
<p>&nbsp; 2.修改链接添加编辑模板：</p>
</blockquote>
<p>&nbsp; /public_html/themes/admin_simpleboot3/admin/link/add.html</p>
<p>&nbsp; /public_html/themes/admin_simpleboot3/admin/link/edit.html</p>
<p>添加分类字段cid到表单中即可， 注意需要在控制器中获取分类信息</p>
<p>&nbsp;</p>
<blockquote>
<p>3.修改前端显示控制器：</p>
</blockquote>
<p>在分类列表中获取对应的链接信息，然后赋值。</p>
<p></p>
<blockquote>
<p>4.修改前端模板：</p>
</blockquote>
<p>模板中判断是否存在友链，如果存在，就显示出来</p>
<p></p>
