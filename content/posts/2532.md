## 调整文件布局

- 删除自带的views里面的页面
- 根据页面模块，在views页面，router页面创建对应的模块文件夹
- 修改router下面的路由
```javascript
import Vue from 'vue'
import VueRouter from 'vue-router'
import movieRouter from './movie'
import cinemaRouter from './cinema'
import myRouter from './my'
Vue.use(VueRouter)
const routes = [
  movieRouter,
  cinemaRouter,
  myRouter
]
const router = new VueRouter({
  routes
})
export default router
```
```javascript
export default {
  path: '/my',
  component: () => import('@/views/my')
}
```
```javascript
export default {
  path: '/cinema',
  component: () => import('@/views/cinema')
}
```
```javascript
export default {
  path: '/movie',
  component: () => import('@/views/movie')
}
```
