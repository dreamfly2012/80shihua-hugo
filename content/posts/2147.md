正常情况下我们安装的php基本没有安装什么扩展文件，如果我们要安装扩展文件的话，还是使用包管理工具方便，在ubuntu下面也就是通过apt-get 来进行安装。

因此当我们缺少curl扩展或者xml扩展的时候，我们就需要使用apt-get来安装它们。

apt-get install php7.0-curl

apt-get install php7.0-xml

执行这两个命令就可以安装对应版本的php扩展了，可以说非常方便和简介。

简单来说下php的扩展是个什么东东，php扩展简单说就是一个插件，它用来扩展php的功能的，默认php无法操作xml，我们通过扩展就可以使用php来操作xml,而对xml的实际操作是通过c语言习得扩展来操作的，理论上来讲，我们可以把我们经常操作的一些功能和函数都可以用php扩展来实现，这样性能会提升一个档次。
