当在团队中协作、处理 Bug 和添加新功能时，Git 是一个非常常见的工具。以下是一些常见的 Git 操作步骤，以 Markdown 格式提供：

多人协作、处理 Bug 和添加新功能时的 Git 操作步骤：

1. 拉取最新代码： 在开始工作之前，确保本地代码库是最新的。
```bash
git pull
```
1. 创建新分支： 为了独立地开发新功能或修复 Bug，创建一个新的分支。
```bash
git checkout -b <branch_name>
```
1. 开发新功能或修复 Bug： 在新分支上进行代码的开发或 Bug 的修复。
```bash
# Add, modify, or delete code as needed
```
1. 提交修改： 完成某个功能开发或 Bug 修复后，将修改提交到本地仓库。
```bash
git add <file>
git commit -m "<commit_message>"
```
1. 推送分支： 当功能开发完成并通过测试后，将本地分支推送到远程仓库。
```bash
git push origin <branch_name>
```
代码审查： 其他团队成员可以在远程仓库上查看并审查你的提交代码。

合并分支： 当新功能开发或 Bug 修复通过审查后，将分支合并到主分支。

```bash
git checkout <target_branch>
git merge <source_branch>
```
解决冲突： 在合并分支时可能会发生冲突，需要手动解决。

删除分支： 在分支合并完成后，删除已经不需要的分支。

```bash
git branch -d <branch_name> (本地)
git push origin --delete <branch_name> (远程)
```
通过以上操作，可以高效地进行多人协作、处理 Bug 和添加新功能，保持代码库的稳定性和可维护性。
