<h2>1. react-native-qrcode-scanner</h2>
<p>很多时候我们都需要扫码来进行简单的操作，而这个包就是方便我们生成和管理二维码的。</p>
<p><strong>安装方式</strong>: npm i react-native-qrcode-scanner</p>
<h2>2. react-native-immediate-phone-call</h2>
<p>如果你想要一个拨打电话的功能，那么这个软件包非常适合你。</p>
<p><strong>安装方式</strong>: npm i react-native-immediate-phone-call</p>
<h2>3. react-native-colour-matrix-image-filters</h2>
<p>对于图片的处理是我们经常需要的功能，使用这个包，我们可以轻松地管理图片的形状和色彩。</p>
<p><strong>安装方式</strong>: npm i react-native-color-matrix-image-filters</p>
<h2>4. react-native-customized-image-picker</h2>
<p>图片上传功能是社交app离不开的功能，而这个包就是进行图片上传裁剪的。</p>
<p><strong>安装方式</strong>: npm i react-native-customized-image-picker</p>
<h2>5. react-native-websocket</h2>
<p>即时通信是很多应用对需要的功能，而websocket就是最常用的技术，而这个包对websocket进行了封装，可以让你轻松使用它们。</p>
<p><strong>安装方式</strong>: npm i react-native-websocket</p>
<h2>6. react-native-fingerprint-scanner</h2>
<p>有些时候我们需要使用指纹登录设备，而这个包就是帮助我们使用指纹的api，同时，它是支持Android和ios设备的。</p>
<p><strong>安装方式</strong>: npm i react-native-fingerprint-scanner</p>
