## 1. react-native-qrcode-scanner

很多时候我们都需要扫码来进行简单的操作，而这个包就是方便我们生成和管理二维码的。

**安装方式**: npm i react-native-qrcode-scanner

## 2. react-native-immediate-phone-call

如果你想要一个拨打电话的功能，那么这个软件包非常适合你。

**安装方式**: npm i react-native-immediate-phone-call

## 3. react-native-colour-matrix-image-filters

对于图片的处理是我们经常需要的功能，使用这个包，我们可以轻松地管理图片的形状和色彩。

**安装方式**: npm i react-native-color-matrix-image-filters

## 4. react-native-customized-image-picker

图片上传功能是社交app离不开的功能，而这个包就是进行图片上传裁剪的。

**安装方式**: npm i react-native-customized-image-picker

## 5. react-native-websocket

即时通信是很多应用对需要的功能，而websocket就是最常用的技术，而这个包对websocket进行了封装，可以让你轻松使用它们。

**安装方式**: npm i react-native-websocket

## 6. react-native-fingerprint-scanner

有些时候我们需要使用指纹登录设备，而这个包就是帮助我们使用指纹的api，同时，它是支持Android和ios设备的。

**安装方式**: npm i react-native-fingerprint-scanner
