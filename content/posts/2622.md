<h2>自定义分享</h2>
<p>分享的时候，网站可以指定用户分享的内容和图片，叫做自定义分享，根据微信提供的jsapi，我们可以实现网页的分享标题，描述，图片和链接的指定分享。</p>
<h2>使用条件</h2>
<p>要想使用微信分享，需要满足以下几个条件。</p>
<ul>
<li>在微信中访问网页</li>
<li>在微信公众号中申请认证</li>
<li>配置域名ip白名单</li>
</ul>

  private function httpGet($url) {

    curl_setopt($curl, CURLOPT_RETURNTRANSFER, true);
    curl_setopt($curl, CURLOPT_TIMEOUT, 500);
    curl_setopt($curl, CURLOPT_SSL_VERIFYPEER, false);

    curl_setopt($curl, CURLOPT_URL, $url);
    $res = curl_exec($curl);
    curl_close($curl);
    return $res;

<h2>注意事项</h2>
<ul>
<li>公众号需要认证</li>
<li>静态页面需要使用ajax来动态获取签名等信息</li>
<li>分享链接注意转义</li>
<li>调试的时候开启debug</li>
<li>注意js可能存在的报错</li>
</ul>
