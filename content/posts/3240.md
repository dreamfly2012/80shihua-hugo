<h2>poetry</h2>
<p>Poetry 是 Python 中用于依赖管理和打包的工具。 它允许您声明项目所依赖的库，并将为您管理（安装/更新）它们。 Poetry 提供了一个锁文件来确保可重复安装，并且可以构建您的项目以进行分发。</p>
<h2>系统要求</h2>
<p>poetry需要Python 3.7+。它是多平台的，可以出色地工作 在 Linux、macOS 和 Windows 上。</p>
<h2>安装</h2>
<p>linux,mac,wsl安装方式</p>
<pre><code>curl -sSL https://install.python-poetry.org | python3 -</code></pre>
<p>windows 安装方式(powershell)</p>
<pre><code>(Invoke-WebRequest -Uri https://install.python-poetry.org -UseBasicParsing).Content | py -</code></pre>
<h2>使用</h2>
<pre><code>poetry --version
poetry self update</code></pre>
<p>zsh 配置自动补全</p>
<pre><code>poetry completions zsh &gt; ~/.zfunc/_poetry</code></pre>
<p>修改.zshrc 添加路径</p>
<pre><code>fpath+=~/.zfunc
autoload -Uz compinit &amp;&amp; compinit</code></pre>
<p>0h-my-zsh 配置自动补全</p>
<pre><code>mkdir $ZSH_CUSTOM/plugins/poetry
poetry completions zsh &gt; $ZSH_CUSTOM/plugins/poetry/_poetry</code></pre>
<pre><code>plugins(
    poetry
    ...
    )</code></pre>
<h2>创建项目</h2>
<pre><code>poetry new poetry-demo</code></pre>
<h2>初始化存在的项目</h2>
<pre><code>cd pre-existing-project
poetry init</code></pre>
<h2>添加依赖</h2>
<pre><code>poetry add pendulum</code></pre>
<h2>根据配置文件安装依赖</h2>
<pre><code>poetry install</code></pre>
<h2>发布python 包</h2>
<pre><code>poetry publish</code></pre>

<h2>管理环境</h2>
<pre><code>poetry env use 3.7</code></pre>
<h2>查看环境</h2>
<pre><code>poetry env info
poetry env list</code></pre>
<h2>删除环境</h2>
<pre><code>poetry env remove /full/path/to/python
poetry env remove python3.7
poetry env remove 3.7
poetry env remove test-O3eWbxRl-py3.7</code></pre>
