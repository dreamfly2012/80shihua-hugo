## poetry

Poetry 是 Python 中用于依赖管理和打包的工具。 它允许您声明项目所依赖的库，并将为您管理（安装/更新）它们。 Poetry 提供了一个锁文件来确保可重复安装，并且可以构建您的项目以进行分发。

## 系统要求

poetry需要Python 3.7+。它是多平台的，可以出色地工作 在 Linux、macOS 和 Windows 上。

## 安装

linux,mac,wsl安装方式

```
<code>curl -sSL https://install.python-poetry.org | python3 -</code>
```
windows 安装方式(powershell)

```
<code>(Invoke-WebRequest -Uri https://install.python-poetry.org -UseBasicParsing).Content | py -</code>
```
## 使用

```
<code>poetry --version
poetry self update</code>
```
zsh 配置自动补全

```
<code>poetry completions zsh > ~/.zfunc/_poetry</code>
```
修改.zshrc 添加路径

```
<code>fpath+=~/.zfunc
autoload -Uz compinit && compinit</code>
```
0h-my-zsh 配置自动补全

```
<code>mkdir $ZSH_CUSTOM/plugins/poetry
poetry completions zsh > $ZSH_CUSTOM/plugins/poetry/_poetry</code>
```
```
<code>plugins(
    poetry
    ...
    )</code>
```
## 创建项目

```
<code>poetry new poetry-demo</code>
```
## 初始化存在的项目

```
<code>cd pre-existing-project
poetry init</code>
```
## 添加依赖

```
<code>poetry add pendulum</code>
```
## 根据配置文件安装依赖

```
<code>poetry install</code>
```
## 发布python 包

```
<code>poetry publish</code>
```

## 管理环境

```
<code>poetry env use 3.7</code>
```
## 查看环境

```
<code>poetry env info
poetry env list</code>
```
## 删除环境

```
<code>poetry env remove /full/path/to/python
poetry env remove python3.7
poetry env remove 3.7
poetry env remove test-O3eWbxRl-py3.7</code>
```
## 依赖于git

```
<code>[tool.poetry.dependencies]
# Get the latest revision on the branch named "next"
requests = { git = "https://github.com/kennethreitz/requests.git", branch = "next" }
# Get a revision by its commit hash
flask = { git = "https://github.com/pallets/flask.git", rev = "38eb5d3b" }
# Get a revision by its tag
numpy = { git = "https://github.com/numpy/numpy.git", tag = "v0.13.2" }</code>
```
