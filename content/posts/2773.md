<p>窗口管理工具tmux是可以配置主题的，配置之前，首先需要安装插件管理器</p>
<h2>下载插件管理工具tpm</h2>
<pre><code>git clone https://github.com/tmux-plugins/tpm ~/.tmux/plugins/tpm</code></pre>
<h2>安装tpm</h2>
<p>修改tmux配置文件.tmux.conf,添加下面的配置</p>
<pre><code># List of plugins
set -g @plugin &#039;tmux-plugins/tpm&#039;
set -g @plugin &#039;tmux-plugins/tmux-sensible&#039;
# Other examples:
# set -g @plugin &#039;github_username/plugin_name&#039;
# set -g @plugin &#039;git@github.com:user/plugin&#039;
# set -g @plugin &#039;git@bitbucket.com:user/plugin&#039;
# Initialize TMUX plugin manager (keep this line at the very bottom of tmux.conf)
run &#039;~/.tmux/plugins/tpm/tpm&#039;</code></pre>
<h2>激活插件tpm</h2>
<p>进入tmux环境，重新导入配置文件</p>
<pre><code>tmux source ~/.tmux.conf</code></pre>
<h2>安装主题</h2>
<p>讲下面的配置添加到配置文件中</p>
<pre><code>set -g @dracula-plugins &quot;cpu-usage gpu-usage ram-usage&quot;</code></pre>
