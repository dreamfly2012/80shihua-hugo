[Python3以上版本安装sqlite3的解决方案](https://www.cnblogs.com/ligh-test/p/10028850.html)

首先大概会报一下两个问题：

1. no mudole named _sqlite3

2. [mportError: dynamic module does not define module export function (PyInit__caffe)](https://stackoverflow.com/questions/34295136/importerror-dynamic-module-does-not-define-module-export-function-pyinit-caff)

其实这两个问题都是因为python3以上版本不太支持sqlite3，下面的方法是亲测没问题，来自（[sparkexpert](https://blog.csdn.net/sparkexpert)大神）

（1）安装sqlite3的包

1. $ wget https://www.sqlite.org/2017/sqlite-autoconf-3170000.tar.gz –no-check-certificate

2. $ tar zxvf sqlite-autoconf-3170000.tar.gz

3. $ cd sqlite-autoconf-3170000

4. $ ./configure –prefix=/usr/local/sqlite3 –disable-static –enable-fts5 –enable-json1 CFLAGS="-g -O2 -DSQLITE_ENABLE_FTS3=1 -DSQLITE_ENABLE_FTS4=1 -DSQLITE_ENABLE_RTREE=1"

（2）对python3进行重新编译

可能需要修改setup.py这个文件

![image.png](/ueditor/php/upload/image/20190529/1559120060312025.png)

LD_RUN_PATH=/usr/local/sqlite3/lib ./configure -prefix=/usr/python -enable-shared CFLAGS=-fPIC

./configure -prefix=/usr/python -enable-shared CFLAGS=-fPIC

make

make install

1. $ cd Python-3.6.0a1

2. $ LD_RUN_PATH=/usr/local/sqlite3/lib ./configure LDFLAGS="-L/usr/local/sqlite3/lib" CPPFLAGS="-I /usr/local/sqlite3/include"

3. $ LD_RUN_PATH=/usr/local/sqlite3/lib make

4. $ LD_RUN_PATH=/usr/local/sqlite3/lib sudo make install

经过上述步骤后，应该就没有什么问题了，控制台输入python3进入环境

import sqlite3没报错说明ok
