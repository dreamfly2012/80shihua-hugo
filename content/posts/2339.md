我们知道对于国际语言的翻译，谷歌做的还是很优秀的，但是因为某些原因，国内无法使用谷歌云来进行翻译，所以我们需要一种可以通过不需要授权请求api的方式，这个时候，php-google-sdk可以方便我们实现这个功能。

## 使用方式

**安装**

```
<code>composer require stichoza/google-translate-php</code>
```
**引入class**

```
<code>
use Stichoza\GoogleTranslate\TranslateClient;
</code>
```
** 创建请求对象 **

```
<code>$tr=new TranslateClient();</code>
```
**设置国内请求url**

```
<code class="language-php">$tr->setUrlBase('http://translate.google.cn/translate_a/single');</code>
```
**设置翻译源语言，目的语言**

```
<code class="language-php">$tr->setSource('en');
$tr->setTarget('ka');</code>
```
**翻译句子**

```
<code class="language-php">echo $tr->translate('Hello World!');</code>
```
**链式操作**

```
<code>echo $tr->setSource('en')->setTarget('ka')->translate('Goodbye');</code>
```
**设置代理**

```
<code>$tr->setHttpOption(['proxy'=>'tcp://localhost:8090']);</code>
```
**批量翻译**

```
<code>echo $tr->translate(['I can dance', 'I like trains', 'Double rainbow']);</code>
```
**注意事项**

此函数库只供学习交流使用，如果频繁请求，可能会导致谷歌封禁ip。
