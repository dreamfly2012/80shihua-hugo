<h2>开发编辑器</h2>
<p>采用vscode进行开发，安装c/c++插件。</p>
<h2>编译环境</h2>
<p>安装MinGW,然后安装gcc,g++,autoconf,automake,gdb等常用工具。<br />
然后将目录配置到环境变量中。</p>
<h2>SDL2库安装</h2>
<p>官网下载开发包，<a href="https://www.libsdl.org/">https://www.libsdl.org/</a></p>
<p>下载解压，使用其中的32位环境包。<br />
<a href="https://80shihua-1251274653.cos.ap-shanghai.myqcloud.com/wp-content/uploads/2020/08/sdl.png"><img decoding="async" src="https://80shihua-1251274653.cos.ap-shanghai.myqcloud.com/wp-content/uploads/2020/08/sdl.png" alt="" /></a></p>
<p>然后将里面的内容分别复制到MinGW的目录对应文件夹下面。</p>
<p>其中的bin中的dll复制到c盘windows/system32文件夹下。</p>
<h2>配置编译调试</h2>
<p>打开vscode,选择一个文件夹作为项目目录，然后选择调试，选择c++(GDB/LLDB),然后它就会在项目中创建一个.vscode文件夹，里面会创建一个launch.json文件，配置这个文件。</p>
<p><a href="https://80shihua-1251274653.cos.ap-shanghai.myqcloud.com/wp-content/uploads/2020/08/cgdblib.png"><img decoding="async" src="https://80shihua-1251274653.cos.ap-shanghai.myqcloud.com/wp-content/uploads/2020/08/cgdblib.png" alt="" /></a></p>

    // Use IntelliSense to learn about possible attributes.

            &quot;type&quot;: &quot;cppdbg&quot;,
            &quot;request&quot;: &quot;launch&quot;,
            &quot;program&quot;: &quot;${fileDirname}\\${fileBasenameNoExtension}.exe&quot;,
            &quot;args&quot;: [],
            &quot;stopAtEntry&quot;: false,
            &quot;cwd&quot;: &quot;${workspaceFolder}&quot;,

            &quot;miDebuggerPath&quot;: &quot;D:\\MinGW\\bin\\gdb.exe&quot;,
            &quot;setupCommands&quot;: [
                {
                    &quot;description&quot;: &quot;Enable pretty-printing for gdb&quot;,

<p>preLaunchTask: 表示我们在调试之前执行的任务<br />

miDebuggerPath:  表示gdb路径<br />
program： 表示当前路径的文件为调试文件</p>
<p>配置如下：</p>
<pre><code>{

        {

<p>上面的哪个task是它自动生成的，我们不用去管，在它下面添加一个task，配置如我们写的那样。</p>
<p>command为我们gcc的路径，args为我们编译调试的参数。</p>
<h2>注意事项</h2>
<p>gcc中关于sdl的开发需要配置-l 参数，就是配置lib,这里要注意它的顺序不能有误，也就是在命令行中的顺序为：</p>
<pre><code class="language-shell">gcc -o main.exe main.c -lmingw32 -lSDL2main -lSDL2</code></pre>
<p>需要注意的是-l这些参数需要放到源文件的后面，也就是main.c的后面，还需要注意是先SDL2main，然后才是-lSDL2。</p>
<p>调试的时候，一定要选择主文件也就是含有main函数的文件进行调试，否则会出现找不到入口。</p>
