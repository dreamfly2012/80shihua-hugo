python的发展日渐强大，我记得不计前我们讨论过js，那个时候js就像现在的python一样火，那个时候我们经常听到的一句话就是能用javascript实现的功能，最后都会用javascript来实现。

放到现在，能用python来做的功能，我们都会使用python来做，python的代码太简洁了，实现一个复杂的算法功能，只要调用封装好的库文件，只要几行就可以实现。

好了，废号少说，我们下面给出国内的几个主流python包源，使用的时·候，可以直接

```
<code class="language-shell">pip install 包名 -i 源</code>
```

> 阿里云 [http://mirrors.aliyun.com/pypi/simple/](http://mirrors.aliyun.com/pypi/simple/)
> 
> 豆瓣   [http://pypi.douban.com/simple/](http://pypi.douban.com/simple/)
> 
> 清华大学   [https://pypi.tuna.tsinghua.edu.cn/simple/](https://pypi.tuna.tsinghua.edu.cn/simple/)
> 
> 中国科技大学    [https://pypi.mirrors.ustc.edu.cn/simple/](https://pypi.mirrors.ustc.edu.cn/simple/)

使用方法就像上面的一样，比如安装pandas

pip install pandas -i [https://pypi.tuna.tsinghua.edu.cn/simple/](https://pypi.tuna.tsinghua.edu.cn/simple/)
