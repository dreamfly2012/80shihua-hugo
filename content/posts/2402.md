<p>上一讲我们讲到了wordpress主题开发中的<a href="https://www.80shihua.com/archives/2365">模板结构</a>,今天我们来讲一讲开发主题中我们经常使用到的模板函数。</p>
<p>我们都知道一个主题不仅仅有着好看的样式就行，还需要显示我们想要显示的内容才行。如何在模板中显示文章的内容，文章的标题，文章的各种信息?答案就是使用wordpress提供给我们的模板函数。</p>
<p>wordpress封装了很多模板函数，我们可以轻松的获取到我们想要的数据库中的各个字段。</p>
<h2>文章详情页</h2>
<p>比如我们想要获取文章标题,调用the_title()这个函数就可以。</p>
<pre><code class="language-php">the_title( string $before = &#039;&#039;, string $after = &#039;&#039;, bool $echo = true )</code></pre>
<p>想要获取文章的摘要，同理，我们只需要调用the_excerpt()这个函数就可以。</p>
<pre><code class="language-php">the_excerpt()</code></pre>
<p>同理，我们想要获取文章内容的话，调用the_content()这个函数就可以。</p>
<pre><code class="language-php">the_content( string $more_link_text = null, bool $strip_teaser = false )</code></pre>
<p>从中我们不难发现规律，只要the_xxx就可以获取数据库对应的字段，可以说记起来还是很容易的。</p>
<h2>单页面</h2>
<p>一个单页面中我们想要获取指定的文章数据，如何获取呢？通过get_post()函数就可以</p>
<pre><code class="language-php">
&lt;?php $post_7 = get_post(7); $title = $post_7-&gt;post_title; ?&gt; 
</code></pre>
<p>通过这个函数我们可以获取指定id的文章内容。</p>
<p>如果想要获取页面内容的话，我们需要使用get_page()函数来获取,传入page_id就可以获取page内容，而在wordpres中page也是存入到post表中的，只不过类型字段不一样。</p>
<pre><code class="language-php">&lt;?php 
$page_id = 123; 

$page_data = get_page( $page_id ); 

echo &#039;&lt;h3&gt;&#039;. $page_data-&gt;post_title .&#039;&lt;/h3&gt;&#039;;

echo apply_filters(&#039;the_content&#039;, $page_data-&gt;post_content); 
?&gt;</code></pre>
<h2>文章列表页</h2>
<p>文章列表页就是我们可以循环显示文章的页面。在文章列表页，我们主要通过循环来获取文章内容。</p>
<pre><code class="language-php">
&lt;ul&gt;
&lt;?php

global $post;

$args = array( &#039;posts_per_page&#039; =&gt; 5, &#039;offset&#039;=&gt; 1, &#039;category&#039; =&gt; 1 );

$myposts = get_posts( $args );

foreach( $myposts as $post ) : setup_postdata($post); ?&gt;
    &lt;li&gt;
          &lt;a href=&quot;&lt;?php the_permalink(); ?&gt;&quot;&gt;&lt;?php the_title(); ?&gt;&lt;/a&gt;
        &lt;/li&gt;
&lt;?php endforeach; ?&gt;

&lt;/ul&gt;</code></pre>
<p>通过get_posts 函数可以获取我们的文章列表。</p>
<p>还有一种方式是</p>
<pre><code class="language-php">&lt;?php while (have_posts()): the_post(); ?&gt;
&lt;article&gt;

        &lt;a class=&quot;title&quot; href=&quot;&lt;?php echo get_permalink(); ?&gt;&quot;&gt;
            &lt;h2&gt;&lt;?php the_title(); ?&gt;&lt;/h2&gt;
        &lt;/a&gt;

        &lt;div class=&quot;meta&quot;&gt;
            &lt;i class=&quot;icon&quot;&gt;&lt;?php echo get_the_date(&#039;Y-m-d&#039;); ?&gt;&lt;/i&gt;
            &lt;?php the_category(&#039;, &#039;, &#039;span&#039;); ?&gt;
        &lt;/div&gt;

        &lt;div class=&quot;excerpt&quot;&gt;
            &lt;?php the_excerpt(); ?&gt;

            &lt;a href=&quot;&lt;?php echo get_permalink(); ?&gt;&quot; class=&quot;readmore&quot;&gt;阅读全文 »&lt;/a&gt;
        &lt;/div&gt;
    &lt;/article&gt;
&lt;?php endwhile;?&gt;</code></pre>
<p>通过while, the_posts函数，我们也可以循环获取文章列表内容。</p>
<p>分页获取：the_posts_pagination()通过这个函数我们可以显示分页。</p>
<h2>小工具显示</h2>
<p>wordpress后台提供了小工具功能，可以方便我们显示导航，分类等信息，我们在模板中只需要使用get_sidebar（）函数，它就会自动加载后台设置的小工具，可以说非常方便。</p>
<h2>总结</h2>
<p>wordpress封装了各种调用函数，基本上我们想要的数据，都可以通过函数获取到，因此，wordpress模板开发，了解一些常用的自带函数还是非常重要的。</p>
