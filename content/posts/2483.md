<p>有时候我们在数据插入之后，会发现数据有问题，这个时候一般有两种解决办法，一种就是通过程序批量修改，一种就是通过mysql直接进行数据的替换。</p>
<h2>replace</h2>
<p>replace(object,search,replace)</p>
<p>repalce是mysql提供的默认字符串处理函数，根据函数定义，我们只需要传入对应参数即可。</p>
<pre><code class="language-mysql">insert into `test` set name = &#039;menghuiguli-666&#039;;
update `test` set name = repalce(name,&#039;-&#039;,&#039;_&#039;) where id = 1;</code></pre>
