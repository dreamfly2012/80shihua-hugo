## 前提条件

- 拥有一个微软账号
- 拥有一个azure云账号
- 安装了vsce工具（安装方法npm install -g vsce)
## 发布步骤

1. 登录[azure](https://go.microsoft.com/fwlink/?LinkId=307137)管理后台
2. 创建一个组织名称
![创建组织名称](https://docs.microsoft.com/en-us/azure/devops/media/select-new-organization.png)

1. 选中组织名称创建token
![token](https://code.visualstudio.com/assets/api/working-with-extensions/publishing-extension/token1.png)

1. 注意创建token的权限
![权限](https://code.visualstudio.com/assets/api/working-with-extensions/publishing-extension/token2.png)

1. vsce登录组织名
```
vsce login 组织名
```
发布

```
vsce publish
```
发布新版本的时候

```
vsce publish 新的版本号(如2.0.0)
```
