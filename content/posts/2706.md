wsl2配置zsh步骤

## 更新系统

```
<code class="language-shell">sudo apt update
sudo apt upgrade</code>
```
## 检查zsh是否安装

```
<code class="language-shell">cat /etc/shells</code>
```
如果没有安装的话

```
<code class="language-shell">sudo apt install zsh</code>
```
## 下载oh-my-zsh

国内的网络，可能需要配置下hosts,可以参考文章《[配置github.com的host访问](https://www.80shihua.com/archives/2708)》

```
<code class="language-shell">sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"</code>
```
## 安装PowerLevel10k主题

```
<code class="language-shell">git clone --depth=1 https://github.com/romkatv/powerlevel10k.git $ZSH_CUSTOM/themes/powerlevel10k</code>
```
## 配置主题

修改家目录.zshrc文件，设置主题为powerlevel10k

```
<code>ZSH_THEME="powerlevel10k/powerlevel10k"</code>
```
通过下面命令设置样式

```
<code>p10k configure</code>
```
![配置p10k样式](https://raw.githubusercontent.com/romkatv/powerlevel10k-media/master/configuration-wizard.gif)

安装字体,放入到c:\windows\fonts

字体下载地址:[github](https://github.com/romkatv/powerlevel10k-media)

```
<code>MesloLGS NF Regular.ttf
MesloLGS NF Bold.ttf
MesloLGS NF Italic.ttf
MesloLGS NF Bold Italic.ttf</code>
```
设置远程连接字体

```
<code>"fontFace": "MesloLGS NF"</code>
```
## 激活插件,修改.zshrc配置文件

```
<code>plugins = (git fasd)</code>
```
