<h2>消息队列</h2>
<p>顾名思义，消息队列就是消息传送接收的队列，既然是队列就是先进先出，前面的消息消费或者接收之后，后面的消息才能被接收或者消费。</p>
<h2>消息队列的用途</h2>
<ul>
<li>代码解耦</li>
<li>异步通知</li>
<li>流量削峰</li>
<li>日志处理</li>
</ul>
<h3>代码解耦</h3>
<p>通过消息队列，将彼此紧密关联的代码拆分开，彼此只需要依赖消息队列即可，不需要处理彼此之间的依赖。</p>
<h3>异步通知</h3>
<p>所有的消息只要发送到消息队列之后，就认为消息投递成功，至于消息接收者什么时候接收和处理消息，生产者不需要关心。也就是消息被消费了是异步通知到生产者的。</p>
<h3>流量削峰</h3>
<p>并发的时候，我们为了尽可能提高吞吐量，我们需要将耗时的操作尽量异步操作，比如发送短信，发送邮件，同步通知等内容，我们把他们放到消息队列中之后，我们的应用的吞吐量会大大提升。</p>
<h3>日志处理</h3>
<p>每个应用每时每刻都在产生大量的日志。而我们可能会有多个应用，面对着海量的日志，我们需要一个可以高吞吐量的存储分析系统，而消息队列就可以帮助我们进行日志处理。</p>
<h2>RabbitMQ安装</h2>
<h3>安装erlang</h3>
<p>rabbitmq的安装依赖erlang环境，所以我们需要先安装erlang环境，配置环境变量，当可以在命令行控制台通过erl访问eshell的时候，表明我们的erlang环境安装成功。</p>
<h3>安装rabbitmq</h3>
<p>在erlang安装之后，我们可以安装rabbitmq，rabbitmq的安装也是比较简单的，我们只需要去官网下载二进制文件包，解压之后，将sbin目录配置到环境变量中即可。当我们通过控制台输入rabbitmq-server可以启动的时候，表明我们的rabbitmq安装配置成功。</p>
<h2>PHP配置RabbitMQ依赖</h2>
<ul>
<li>安装socket扩展</li>
<li>使用composer进行rabbitmq依赖安装</li>
</ul>
<pre><code class="language-shell">composer require &quot;php-amqplib/php-amqplib&quot;</code></pre>
<h2>PHP操作rabbitmq的简单示例</h2>
<p>生产者</p>
<pre><code class="language-php">&lt;?php

require_once __DIR__ . &quot;/vendor/autoload.php&quot;;

//引入连接和消息类
use PhpAmqpLib\Connection\AMQPStreamConnection;
use PhpAmqpLib\Message\AMQPMessage;

//创建socket连接
$connection = new AMQPStreamConnection(&quot;localhost&quot;, 5672, &#039;guest&#039;, &#039;guest&#039;);

//创建连接频道
$channel = $connection-&gt;channel();

//声明队列
$channel-&gt;queue_declare(&#039;hello&#039;, false, false, false, false);

//创建消息
$msg = new AMQPMessage(&quot;测试中文~&quot;);

//发送消息到队列
$channel-&gt;basic_publish($msg, &#039;&#039;, &#039;hello&#039;);

echo &quot; [x] Sent &#039;Hello World!&#039;\n&quot;;

//关闭连接
$channel-&gt;close();
$connection-&gt;close();</code></pre>
<p>消费者</p>
<pre><code class="language-php">&lt;?php

require_once __DIR__ . &#039;/vendor/autoload.php&#039;;

//引入连接类
use PhpAmqpLib\Connection\AMQPStreamConnection;

//创建连接
$connection = new AMQPStreamConnection(&#039;localhost&#039;, 5672, &#039;guest&#039;, &#039;guest&#039;);

//创建频道
$channel = $connection-&gt;channel();

//声明队列
$channel-&gt;queue_declare(&#039;hello&#039;, false, false, false, false);

echo &quot; [*] Waiting for messages. To exit press CTRL+C\n&quot;;

$callback = function ($msg) {
    echo &#039; [x] Received &#039;, $msg-&gt;body, &quot;\n&quot;;
};

//监听队列，消费消息
$channel-&gt;basic_consume(&#039;hello&#039;, &#039;&#039;, false, true, false, false, $callback);

while ($channel-&gt;is_consuming()) {
    $channel-&gt;wait();
}</code></pre>
