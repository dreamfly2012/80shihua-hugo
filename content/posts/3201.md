虽然目前php的市场占有率在逐渐下降，然而这并不影响wordpress仍然是市场占有率排名第一的个人博客站点工具。

很多时候，我们习惯在vscode里面写代码，并且喜欢在它的上面使用markdown来写文章，但是这里有个问题，每次写完文章之后，我们还需要去我们的wordpress站点重新复制一遍，这样非常的麻烦，那么有没有方法让我们在vscode里面写的文章直接发布到wordpress的博客站点呢，答案是肯定的，我们只需要安装一个vscode插件即可，它就是 wordpress post 插件，有了这个插件我们就可以将vscode里面写的文章发布到wordpress里面。

## rest api

rest api 提供了一组接口，它可以让我们通过json来和网站进行交互，比如我们可以发送一组json创建一篇文章，修改一篇文章，删除一篇文章，总之，通过rest api，我们可以获取到站点内容，也可以修改站点内容。

有了rest api，我们就可以使用多种编程语言来和wordpress进行交互，即使没有使用过php的golang用户，也可以通过程序来实现对wordpress内容的编辑。

wordpress 4.4版本以上就默认提供了rest api接口，你可以通过在浏览器中访问下面的地址来查看是否支持rest api

```
https://sitename/wp-json/wp/v2/posts
```
## wordpress post

在插件商店搜索wordpress post 就可以安装了，之后我们需要在配置选项中配置下相关信息。

![Alt text](https://80shihua-1251274653.cos.ap-shanghai.myqcloud.com/wp-content/uploads/2023/03/index-2023-03-21-11-02-46-3.png)

最重要的是三个信息，一个是url，一个是用户名，一个是密码。

这里的密码需要注意，需要在wordpress管理后台，点击用户，最下面有个应用程序密码，这里创建才可以，不是管理员的登录密码。

## 最后

经过配置之后，我们就可以愉快地在vscode中写文章了，然后我们就可以将它发布到我们的博客上了。
