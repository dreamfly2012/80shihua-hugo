<p>无论是平时工作还是日常开发，我们都需要发送邮件，而在php中，对于邮件的发送，我们有非常好用的函数可以直接使用，下面就让我们看看php是如何发送邮件的。</p>
<pre><code class="language-php">&lt;?php
// multiple recipients
$to = &#039;aidan@example.com&#039; . &#039;, &#039;; // note the comma
$to .= &#039;wez@example.com&#039;;

// subject
$subject = &#039;Birthday Reminders for August&#039;;

// message
$message = &#039;
&lt;html&gt;
&lt;head&gt;
 &lt;title&gt;Birthday Reminders for August&lt;/title&gt;
&lt;/head&gt;
&lt;body&gt;
 &lt;p&gt;Here are the birthdays upcoming in August!&lt;/p&gt;
 &lt;table&gt;
 &lt;tr&gt;
 &lt;th&gt;Person&lt;/th&gt;&lt;th&gt;Day&lt;/th&gt;&lt;th&gt;Month&lt;/th&gt;&lt;th&gt;Year&lt;/th&gt;
 &lt;/tr&gt;
 &lt;tr&gt;
 &lt;td&gt;Joe&lt;/td&gt;&lt;td&gt;3rd&lt;/td&gt;&lt;td&gt;August&lt;/td&gt;&lt;td&gt;1970&lt;/td&gt;
 &lt;/tr&gt;
 &lt;tr&gt;
 &lt;td&gt;Sally&lt;/td&gt;&lt;td&gt;17th&lt;/td&gt;&lt;td&gt;August&lt;/td&gt;&lt;td&gt;1973&lt;/td&gt;
 &lt;/tr&gt;
 &lt;/table&gt;
&lt;/body&gt;
&lt;/html&gt;
&#039;;

// To send HTML mail, the Content-type header must be set
$headers = &#039;MIME-Version: 1.0&#039; . &quot;\\r\\n&quot;;
$headers .= &#039;Content-type: text/html; charset=iso-8859-1&#039; . &quot;\\r\\n&quot;;

// Additional headers
$headers .= &#039;To: Mary &lt;mary@example.com&gt;, Kelly &lt;kelly@example.com&gt;&#039; . &quot;\\r\\n&quot;;
$headers .= &#039;From: Birthday Reminder &lt;birthday@example.com&gt;&#039; . &quot;\\r\\n&quot;;
$headers .= &#039;Cc: birthdayarchive@example.com&#039; . &quot;\\r\\n&quot;;
$headers .= &#039;Bcc: birthdaycheck@example.com&#039; . &quot;\\r\\n&quot;;

// Mail it
mail($to, $subject, $message, $headers);</code></pre>
<p>下面主要介绍下mail函数的参数说明。</p>
<p>bool mail ( string<code>$to</code> , string<code>$subject</code> , string<code>$message</code> [, string<code>$additional_headers</code> [, string<code>$additional_parameters</code> ]] )</p>
<h3><code>additional_headers</code> (optional)</h3>
<p>这是一个可以插入到邮件头部的参数，这里的字符串会被插入到邮件头。</p>
<p>常用的头部比如 From, Cc, Bcc 等。</p>
<p>需要注意的是，如果有多个头部，需要使用CRLF（\r\n）进行分隔。</p>
<p>当发送邮件的时候， 邮件必须包含一个From头部，这个可以通过<code>additional_headers</code> 来指定。否则可能在windows上会出现发送失败的错误。</p>
<p>需要注意的是，发送的邮件的内容最好只使用LF分隔，这样不会出现无法接收的问题。</p>
