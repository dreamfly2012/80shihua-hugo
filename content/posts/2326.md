<h2>spring boot</h2>
<p>spring boot 是基于spring 开发的脚手架，它可以快速配置spring,简化新Spring应用的初始搭建以及开发过程。该框架使用了特定的方式来进行配置，从而使开发人员不再需要定义样板化的配置。</p>
<h2>vscode</h2>
<p>vscode是微软推出的基于electronic 开发的代码编辑器，可以开发多种语言。</p>
<h2>安装插件</h2>

<h2>maven</h2>
<p>我们使用maven来构建我们的spring项目，所以我们需要先安装maven.<br />
<a href="https://maven.apache.org/">https://maven.apache.org/</a><br />
可以在maven官网找到对应操作系统的版本，安装非常简单，需要注意的是添加环境变量。</p>
<p>添加环境变量就是将maven的执行目录放入到系统环境中，这样系统在任何目录下都可以执行maven的命令。</p>

<h2>配置vscode的maven变量</h2>
<p>找到vscode的个人变量配置文件，添加下面的配置。</p>
<pre><code>&quot;maven.excludedFolders&quot;: [
        &quot;**/.*&quot;,
        &quot;**/node_modules&quot;,
        &quot;**/target&quot;,
        &quot;**/bin&quot;
    ], 
    &quot;java.home&quot;:&quot;D:\\Program Files\\Java\\jdk1.8.0_181&quot;,jdk目录
    &quot;java.configuration.maven.userSettings&quot;: &quot;D:\\apache-maven-3.6.3\\conf\\settings.xml&quot;,//maven配置文件目录
    &quot;maven.executable.path&quot;: &quot;D:\\apache-maven-3.6.3\\bin\\mvn.cmd&quot;,//maven执行命令
    &quot;maven.terminal.useJavaHome&quot;: true,
    &quot;maven.terminal.customEnv&quot;: [
        {
            &quot;environmentVariable&quot;: &quot;JAVA_HOME&quot;,
            &quot;value&quot;: &quot;D:\\Program Files\\Java\\jdk1.8.0_181&quot;//jdk目录
        }
    ],</code></pre>
