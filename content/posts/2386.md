<h2>nginx服务器</h2>
<p>nginx是非常出色web服务器，对于静态文件的处理非常高效，同时它的代理转发功能和其它后台服务器搭配起来也非常的简单高效。</p>
<h2>location</h2>
<p>我们知道nginx会对请求进行解析，然后回得到关于请求的url等信息，我们只需要对url进行匹配，然后拦截即可。</p>
<h2>匹配规则</h2>
<pre><code class="language-shell">location / {
    if ($request_uri ~* ^/\?http(.*)$) {
                 return 404;
          }
    }</code></pre>
<p>经过这样的匹配，我们就可以拦截所有请求根目录的网址并且参数为?httpxxx类似的请求都会显示404.</p>
<h2>防盗链</h2>
<p>返回http代码，例如设置nginx防盗链：</p>
<pre><code class="language-shell">location ~* \.(gif|jpg|png|swf|flv)$ {
    valid_referers none blocked www.80shihua.com www.menghuiguli.com;
    if ($invalid_referer) {
        return 404;
    }
}</code></pre>
