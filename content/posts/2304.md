<h2>首先检查或者卸载残留docker程序</h2>
<pre><code class="language-shell">sudo apt-get remove docker docker-engine docker.io containerd runc</code></pre>
<h2>更新软件仓库</h2>
<pre><code class="language-shell">sudo apt-get update</code></pre>
<h2>安装所需依赖环境</h2>
<pre><code class="language-shell">sudo apt-get install \
    apt-transport-https \
    ca-certificates \
    curl \
    gnupg-agent \
    software-properties-common</code></pre>
<h2>安装密钥</h2>
<pre><code class="language-shell">curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo apt-key add -</code></pre>
<h2>验证密钥是否正确</h2>
<pre><code class="language-shell">sudo apt-key fingerprint 0EBFCD88</code></pre>
<p>显示如下就是安装正确</p>
<pre><code>pub   rsa4096 2017-02-22 [SCEA]
      9DC8 5822 9FC7 DD38 854A  E2D8 8D81 803C 0EBF CD88
uid           [ unknown] Docker Release (CE deb) &lt;docker@docker.com&gt;
sub   rsa4096 2017-02-22 [S]</code></pre>
<h2>添加稳定镜像源</h2>
<pre><code>sudo add-apt-repository \
   &quot;deb [arch=amd64] https://download.docker.com/linux/ubuntu \
   $(lsb_release -cs) \
   stable&quot;</code></pre>
<h2>安装docker</h2>
<pre><code class="language-shell">sudo apt-get install docker-ce docker-ce-cli containerd.io</code></pre>
<h2>测试安装是否成功</h2>
<pre><code class="language-shell">service docker status</code></pre>
<h2>启动docker服务</h2>
<pre><code class="language-shell">sudo service docker start</code></pre>
<h2>运行hello-world 镜像</h2>
<pre><code class="language-shell">docker run hello-world</code></pre>
