## 首先检查或者卸载残留docker程序

```
<code class="language-shell">sudo apt-get remove docker docker-engine docker.io containerd runc</code>
```
## 更新软件仓库

```
<code class="language-shell">sudo apt-get update</code>
```
## 安装所需依赖环境

```
<code class="language-shell">sudo apt-get install \
    apt-transport-https \
    ca-certificates \
    curl \
    gnupg-agent \
    software-properties-common</code>
```
## 安装密钥

```
<code class="language-shell">curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo apt-key add -</code>
```
## 验证密钥是否正确

```
<code class="language-shell">sudo apt-key fingerprint 0EBFCD88</code>
```
显示如下就是安装正确

```
<code>pub   rsa4096 2017-02-22 [SCEA]
      9DC8 5822 9FC7 DD38 854A  E2D8 8D81 803C 0EBF CD88
uid           [ unknown] Docker Release (CE deb) <docker@docker.com>
sub   rsa4096 2017-02-22 [S]</code>
```
## 添加稳定镜像源

```
<code>sudo add-apt-repository \
   "deb [arch=amd64] https://download.docker.com/linux/ubuntu \
   $(lsb_release -cs) \
   stable"</code>
```
## 安装docker

```
<code class="language-shell">sudo apt-get install docker-ce docker-ce-cli containerd.io</code>
```
## 测试安装是否成功

```
<code class="language-shell">service docker status</code>
```
## 启动docker服务

```
<code class="language-shell">sudo service docker start</code>
```
## 运行hello-world 镜像

```
<code class="language-shell">docker run hello-world</code>
```
