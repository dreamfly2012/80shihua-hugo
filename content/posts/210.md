<p><strong><a title="Apache" href="http://codebucket.co.in/tag/apache/">Apache</a></strong> is the most common and famous webserver. Everyone knows about apache and most of us also have hands on experience with apache. But few of us know that apcahe2 comes with 2 <strong>multi processing modules</strong>(MPMs):</p>
<p>1. <a title="Prefork" href="http://codebucket.co.in/tag/prefork/">Prefork</a><br />
2. <a title="Worker" href="http://codebucket.co.in/tag/worker/">Worker</a></p>
<p>&nbsp;</p>
<p><strong>What is the difference between this two?</strong></p>
<p><strong>Prefork MPM</strong> uses multiple child processes with one thread each and each process handles one connection at a time.</p>
<p><strong>Worker MPM</strong> uses multiple child processes with many threads each. Each thread handles one connection at a time.</p>
<p>On most of the systems, speed of both the MPMs is comparable but prefork uses more memory than worker.</p>
<p>&nbsp;</p>
<p><strong>Which one to use?</strong></p>
<p>On high traffic websites worker is preferable because of low memory usage as comparison to prefork MPM but prefork is more safe if you are using libraries which are not thread safe.</p>
<p><strong>For example</strong> you cannot use mod_php(not thread safe) with worker MPM but can use with prefork.</p>
<p>So if you are using all thread safe libraries then go with worker and if you are not sure then use default prefork MPM, you may have to increase your RAM in case of high traffic.</p>
<p>If you are on <a title="linux" href="http://codebucket.co.in/category/linux/">linux</a> then run following command to check which MPM is on your machine</p>
<p>/usr/sbin/apache2 -V | grep MPM</p>
