## ubuntu

安装ffmpeg

```bash
sudo apt install ffmpeg
```
安装软件源

```bash
sudo add-apt-repository ppa:obsproject/obs-studio
```
更新软件源

```bash
sudo apt update
```
安装obs

```bash
sudo apt install obs-studio
```
