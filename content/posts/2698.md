## ubuntu

安装ffmpeg

```
<code class="language-bash">sudo apt install ffmpeg</code>
```
安装软件源

```
<code class="language-bash">sudo add-apt-repository ppa:obsproject/obs-studio</code>
```
更新软件源

```
<code class="language-bash">sudo apt update</code>
```
安装obs

```
<code class="language-bash">sudo apt install obs-studio</code>
```
