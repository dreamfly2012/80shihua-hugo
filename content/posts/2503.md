<h2>伪静态</h2>
<p>看起来是静态的html页面，但是实际上是动态处理的页面。</p>
<h2>静态页面</h2>
<p>html页面属于静态页面，就是网页内容是固定的，如果想要动态显示一些内容，可以通过ajax来实现。</p>
<h2>伪静态 vs 静态页面</h2>
<ul>
<li>从URL结构以及页面名称看，伪静态和静态页面是一样的。伪静态的页面后缀可以是html htm 或者是目录格式</li>
<li>伪静态只是改变了URL的表现形式，实际上还是动态页面</li>
<li>静态页面可以节省服务器资源，而伪静态严格说是增加服务器资源消耗的</li>
</ul>
<h2>apache 伪静态</h2>
<p>apache通过开启mod_rewrite模块就可以实现伪静态。</p>
<ul>
<li>修改配置文件， AllowOverride None =&gt; AllowOverride All</li>
<li>添加.htaccess文件，编写rewrite规则</li>
</ul>
<h2>.htaccess文件</h2>
<p>apache实现伪静态的配置文件，通过此文件不仅可以实现伪静态，还可以修改一些php的配置，比如修改默认上传文件的大小，可以设置是否开启缓存，可以控制防盗链，设置错误页面</p>
<pre><code class="language-bash">php_value post_max_size 12m
php_value upload_max_filesize 12m
php_value max_execution_time 120
php_value max_input_time 240

&lt;FilesMatch &quot;.(gif|jpg|jpeg|png|ico)$&quot;&gt;
Header set Cache-Control &quot;max-age=86400&quot;
&lt;/FilesMatch&gt;

RewriteEngine on
RewriteCond %{HTTP_REFERER} !^$
RewriteCond %{HTTP_REFERER} !^http://(www\.)?baidu.com(/)?.*$     [NC]
RewriteRule .*\.(gif|jpg|jpeg|bmp|png)$ https://www.baidu.com [R,NC,L]

ErrorDocument 404 404.html
ErrorDocument 500 error.html
</code></pre>

<ul>
<li>RewriteCond （条件判断）</li>
</ul>
<pre><code class="language-shell">RewriteCond TestString CondPattern </code></pre>
<ol>
<li>!表示取反</li>
<li>使用逻辑运算符&lt;,&gt;,=,&lt;=,&gt;=</li>
<li>数字比较 -eq,-gt,-ge,-le,-lt,-ne</li>
<li>文件属性比较</li>
</ol>
<p>-f 是否是文件<br />
-d 是否是目录<br />
-h 是否是链接<br />
-l 是否是链接<br />
-U 是否是存在的URL<br />
-x 是否有可执行权限</p>
<pre><code class="language-shell">RewriteCond %{HTTP_USER_AGENT} &quot;=This Robot/1.0&quot;

RewriteCond /var/www/%{REQUEST_URI} !-f</code></pre>
<p>判断一个文件是否在指定目录存在，如果存在进行rewrite</p>
<pre><code>RewriteCond %{DOCUMENT_ROOT}/html/%{HTTP_HOST}/$1.html -f
RewriteRule ^(.*)$ html/%{HTTP_HOST}/$1.html </code></pre>
<p>thinkcmf伪静态，pathinfo模式处理</p>
<pre><code>RewriteRule ^(.*)?$ index.php  [E=PATH_INFO:$1,QSA,PT,L]</code></pre>
