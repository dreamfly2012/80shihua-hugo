<h1>链式操作</h1>
<p>链式操作顾名思义就是所有的操作是一个链，所有的操作是通过链条串接起来的。<br />
我们经常在各个语言中都能看到链式操作的身影。</p>
<p>js-jquery中</p>
<pre><code class="language-js">$(this).addClass(&quot;dark&quot;).removeClass(&quot;black&quot;).css(&quot;display&quot;,&quot;block&quot;);</code></pre>
<p>php-数据库操作</p>
<pre><code class="language-php">$model-&gt;field(&#039;name&#039;)-&gt;where(array(&#039;id&#039;=&gt;3))-&gt;get();</code></pre>
<p>java中构造器模式</p>
<pre><code class="language-java">Request request = new Request.Builder()
        .url(&quot;https://api.github.com/markdown/raw&quot;)
        .post(RequestBody.create(mediaType, requestBody))
        .build();</code></pre>
<h1>实现原理</h1>
<p>链式操作的实现原理就是每次进行操作的时候，都将对象返回。笔者以php语言为例，进行简单的示范。</p>
<pre><code class="language-php">class Demo
{
    private $result = 0;

    public function __construct($result)
    {
        $this-&gt;result = $result;
    }

    public function add($a){
        $this-&gt;result = $this-&gt;result + $a;
        return $this;
    }

    public function sub($a){
        $this-&gt;result = $this-&gt;result - $a;
        return $this;
    }

    public function mul($a){
        $this-&gt;result = $this-&gt;result * $a;
        return $this;
    }

    public function div($a){
        $this-&gt;result = intval($this-&gt;result / $a);
        return $this;
    }

    public function get(){
        return $this-&gt;result;
    }
}

$demo = new Demo(4);

$result = $demo-&gt;add(3)-&gt;mul(10)-&gt;div(5)-&gt;sub(4)-&gt;get();

var_dump($result);</code></pre>
<p>上面就是一个链式操作，我们只要每次调用对象的方法的时候，最后都返回对象，就可以继续调用对象的方法，这就是链式操作的核心原理。</p>
