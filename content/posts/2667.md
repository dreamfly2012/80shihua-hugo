<h2>安装包下载</h2>
<p>去官网选择对应的操作系统，复制下载链接。<br />
<a href="https://www.mongodb.com/try/download/community">下载地址</a></p>
<h2>wget服务器下载</h2>
<p>根据获取到的下载链接，在服务器上使用wget进行文件的下载。<br />
wget -c <a href="https://repo.mongodb.org/yum/redhat/7/mongodb-org/4.4/x86_64/RPMS/mongodb-org-server-4.4.2-1.el7.x86_64.rpm">https://repo.mongodb.org/yum/redhat/7/mongodb-org/4.4/x86_64/RPMS/mongodb-org-server-4.4.2-1.el7.x86_64.rpm</a></p>
<h2>rpm安装</h2>
<p>rpm -ivh xx.rpm </p>
<h2>设置开机启动</h2>
<p>systemctl enable mongod</p>
<h2>启动服务</h2>
<p>systemctl start mongod</p>
<h2>注意事项</h2>
<p>目前4.4版本的mongodb的客户端和服务器是分开的，如果想要使用命令行客户端操作数据库，需要单独下载mongoshell</p>
<h2>配置mongodb的配置</h2>
<p>配置端口和ip访问，0.0.0.0表示任意ip都可以访问，port表示端口是27000,security表示安全配置，authorization: enabled 表示授权访问，需要具有权限才能访问和操作数据库。storage表示数据库内容存放的位置，systemLog表示日志存放的位置。</p>
<pre><code>net:
  port: 27777
  bindIp: 0.0.0.0 

security:
  authorization: enabled

storage:
  dbPath: /var/lib/mongo
  journal:
    enabled: true 

systemLog:
  destination: file
  logAppend: true
  path: /var/log/mongodb/mongod.log </code></pre>
<h2>mongosh操作数据库</h2>
<p>修改配置之后，重启数据库，然后使用mongosh进行连接，如果是本地的话</p>
<p>mongosh 就会连接上，当然如果修改了端口需要使用&#8211;port进行传入</p>
<pre><code>mongosh --host xxx.xxx.xxx.xx --port xxxxx</code></pre>
<h2>创建用户</h2>
<pre><code>db.createUser(
{
　　user: &quot;root&quot;,
　　pwd: &quot;root&quot;,
　　roles: [ { role: &quot;userAdminAnyDatabase&quot;, db: &quot;admin&quot; } ]
} )</code></pre>
<p>连接之后，需要通过db.auth进行授权</p>
<pre><code>db.auth(&quot;username&quot;,&quot;password&quot;)</code></pre>
<h2>创建新的数据库，并添加管理员</h2>
<ol>
<li>输入use admin，进入admin数据库，root用户需要在admin数据库中认证。</li>
<li>输入db.auth(&#8216;root&#8217;,&#8217;root&#8217;)超级用户进行认证</li>
<li>输入db.createUser({user: &quot;movie&quot;,pwd: &quot;123456&quot;,roles: [ { role: &quot;readWrite&quot;, db: &quot;movie&quot; } ]} )创建movie用户，并为它指定数据库为movie。</li>
<li>输入db.auth(&#8216;movie&#8217;,&#8217;123456&#8242;)切换认证用。</li>
<li>输入use movie切换至movie数据库</li>
<li>输入db.items.insert({&quot;title&quot;:&quot;一秒钟&quot;,&quot;desc&quot;:&quot;不短也不长&quot;})，创建一条数据。</li>
</ol>
