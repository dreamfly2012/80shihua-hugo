<h2 class="title" style="line-height: 3rem; margin: 0px 0px 1.5rem; overflow: hidden; text-rendering: optimizeLegibility; font-size: 1.5rem; font-weight: 500; color: rgb(121, 56, 98); position: relative; clear: both;"><var class="filename">php.ini</var>&nbsp;配置段列表</h2>
<p class="para" style="margin-top: 0px; margin-bottom: 1.5rem;">This list includes the&nbsp;<var class="filename" style="border-radius: 2px; padding: 2px 4px; white-space: nowrap; font-style: normal; font-stretch: normal; font-size: 14px; line-height: 1.46; font-family: &#39;Source Code Pro&#39;, monospace; background-color: rgb(230, 230, 230);">php.ini</var>&nbsp;sections you can set to configure your PHP setup on a per Host or Path basis. These sections are optional.</p>
<p class="para" style="margin-top: 0px; margin-bottom: 1.5rem;">These sections don&#39;t directly affect PHP. They are used to group other&nbsp;<var class="filename" style="border-radius: 2px; padding: 2px 4px; white-space: nowrap; font-style: normal; font-stretch: normal; font-size: 14px; line-height: 1.46; font-family: &#39;Source Code Pro&#39;, monospace; background-color: rgb(230, 230, 230);">php.ini</var>&nbsp;directives together and to get them to act upon a particular host or on a particular path.</p>
<p class="para" style="margin-top: 0px; margin-bottom: 1.5rem;">These sections are used only in CGI/FastCGI mode and they can not set&nbsp;<a href="http://php.net/manual/zh/ini.core.php#ini.extension" class="link" style="border-bottom-width: 1px; border-bottom-style: solid; text-decoration: none; color: rgb(51, 102, 153);">extension</a>&nbsp;and&nbsp;<a href="http://php.net/manual/zh/ini.core.php#ini.zend-extension" class="link" style="border-bottom-width: 1px; border-bottom-style: solid; text-decoration: none; color: rgb(51, 102, 153);">zend_extension</a>&nbsp;directives.</p>

</li>
<li>
<p class="para" style="margin-top: 0px; margin-bottom: 1.5rem;">This section allows you to define a set of&nbsp;<var class="filename" style="border-radius: 2px; padding: 2px 4px; white-space: nowrap; font-style: normal; font-stretch: normal; font-size: 14px; line-height: 1.46; font-family: &#39;Source Code Pro&#39;, monospace; background-color: rgb(230, 230, 230);">php.ini</var>&nbsp;directives that will take effect on the named host.</p>

<p><span class="default" style="color: rgb(51, 102, 153); background-color: transparent;">&lt;?php</p>
<p></span><span class="comment" style="color: rgb(79, 91, 147); background-color: transparent;"># Disable eAccelerator by default<br /></span><span class="default" style="color: rgb(51, 102, 153); background-color: transparent;">eaccelerator</span><span class="keyword" style="color: rgb(102, 153, 51); background-color: transparent;">.</span><span class="default" style="color: rgb(51, 102, 153); background-color: transparent;">enable&nbsp;</span><span class="keyword" style="color: rgb(102, 153, 51); background-color: transparent;">=&nbsp;</span><span class="default" style="color: rgb(51, 102, 153); background-color: transparent;">0</p>
<p></span><span class="comment" style="color: rgb(79, 91, 147); background-color: transparent;"># Now, to prevent incompatibilities with Zend Optimizer+, we<br /># want to enable eAccelerator only in PHP 5.2 or lower.<br /></span><span class="keyword" style="color: rgb(102, 153, 51); background-color: transparent;">[</span><span class="default" style="color: rgb(51, 102, 153); background-color: transparent;">HOST</span><span class="keyword" style="color: rgb(102, 153, 51); background-color: transparent;">=*]<br /></span><span class="default" style="color: rgb(51, 102, 153); background-color: transparent;">eaccelerator</span><span class="keyword" style="color: rgb(102, 153, 51); background-color: transparent;">.</span><span class="default" style="color: rgb(51, 102, 153); background-color: transparent;">enable&nbsp;</span><span class="keyword" style="color: rgb(102, 153, 51); background-color: transparent;">=&nbsp;</span><span class="default" style="color: rgb(51, 102, 153); background-color: transparent;">1</p>

<p><a href="http://www.php.net/manual/en/ini.sections.php" rel="nofollow" target="_blank" style="border-bottom-width: 1px; border-bottom-style: solid; text-decoration: none; color: rgb(51, 102, 153);">http://www.php.net/manual/en/ini.sections.php</a></p>
<p>These sections only work in CGI/FastCGI mode, however there still seems to be a difference in how the php.ini file is parsed in PHP 5.2 and PHP 5.3 when using mod_php: PHP 5.3 ignores everything below the line [HOST=*], whereas PHP 5.2 does not.</p>
<p>In the above example, PHP 5.3 only reads &quot;eaccelerator.enable = 0&quot; and then stops at the invalid command [HOST=*]. However, PHP 5.2 seems to ignore the invalid command and parses the whole configuration file, ending up with &quot;eaccelerator.enable = 1&quot;.</span></code></div>

<div class="phpcode"><code style="font-stretch: normal; font-size: 0.875rem; line-height: 1.5rem; font-family: &#39;Fira Mono&#39;, &#39;Source Code Pro&#39;, monospace; word-wrap: break-word; display: block;"><span class="html" style="color: black; background-color: transparent;">If you have a system which uses separated PHP inis for loading extensions (Debian, Fedora and most other distributions do so), [PATH=] or [HOST=] will prevent loading extensions defined in those ini files (extension= and zend_extension=).</p>
<p>I had some headache, when I added a hosts.ini to /etc/php5/cgi/conf.d (Debians default), where I wanted to define some defaults for a host name. The manual says extension= and zend_extension= aren&#39;t allowed in [HOST=] and [PATH=] (see above). I figured out that you can easily fix that with adding [PHP] after your definitions.</p>
<p>For example hosts.ini:<br />[HOST=dev.example.com]<br />display_errors = on</p>
<p>[PHP]</p>
<p>this will change the section back to [PHP] where extension= and zend_extension= is allowed.</span></code></div>
