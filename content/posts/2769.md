## vim分屏

vim可以水平分屏和垂直分屏，分屏命令

```
<code>:split
:vsplit
:sp
:vs</code>
```
可以通过下面的命令调整分屏窗口尺寸

```
<code>:resize -3
:resize +3
:vertical resize -3
:vertical resize +3</code>
```
上面分别实现减少高度3，增加高度3，减少宽度3，增加宽度3

最后我们可以将上述命令绑定按键

```
<code>nmap   w-  :resize -3<CR>
nmap   w=  :resize +3<CR>
nmap   w,  :vertical resize -3<CR>
nmap   w.  :vertical resize +3<CR>
</code>
```
