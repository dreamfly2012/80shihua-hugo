## 问题描述

当执行下面映射的时候

```bash
docker run -d -p 9998:80 --name php-nginx -v /g/code:/app webdevops/php-nginx
```
可能会发生下面的错误

错误 docker: Error response from daemon: status code not OK but 500: {"Message":"Unhandled exception: Drive has not been shared"}.

这是权限的问题

## 解决办法

[![Resources sharing](https://80shihua-1251274653.cos.ap-shanghai.myqcloud.com/wp-content/uploads/2020/07/无标题.png)](https://80shihua-1251274653.cos.ap-shanghai.myqcloud.com/wp-content/uploads/2020/07/无标题.png)

修改设置，添加对应磁盘的分享权限，就可以使用了。
