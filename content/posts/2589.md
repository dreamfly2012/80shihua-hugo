<h2>问题描述</h2>
<p>当执行下面映射的时候</p>
<pre><code class="language-shell">docker run -d -p 9998:80 --name php-nginx -v /g/code:/app webdevops/php-nginx</code></pre>
<p>可能会发生下面的错误<br />
错误 docker: Error response from daemon: status code not OK but 500: {&quot;Message&quot;:&quot;Unhandled exception: Drive has not been shared&quot;}.</p>
<p>这是权限的问题</p>
<h2>解决办法</h2>
<p><a href="https://80shihua-1251274653.cos.ap-shanghai.myqcloud.com/wp-content/uploads/2020/07/无标题.png"><img decoding="async" src="https://80shihua-1251274653.cos.ap-shanghai.myqcloud.com/wp-content/uploads/2020/07/无标题.png" alt="Resources sharing" /></a></p>
<p>修改设置，添加对应磁盘的分享权限，就可以使用了。</p>
