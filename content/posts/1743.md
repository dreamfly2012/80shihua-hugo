PIL是python中强大的图片处理模块，有了它我们可以肆意妄为。可以说有了它，图片美化的工作基本可以放弃ps，专注使用它了。

但是我们python3中却不能直接使用pip install PIL来安装这个模块，因为PIL是python2中的库，那么我们python3就不能用了，当然不是，我们python的强大社区在，有人已经写好了python3的pil处理模块，他就是pillow.

命令行执行pip install pillow 就可以使用PIL了。
