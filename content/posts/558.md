<h2 class="title" style="line-height: 3rem; margin: 0px 0px 1.5rem; overflow: hidden; text-rendering: optimizeLegibility; font-size: 1.5rem; font-weight: 500; color: rgb(121, 56, 98); position: relative; clear: both; font-family: &#39;Fira Sans&#39;, &#39;Source Sans Pro&#39;, Helvetica, Arial, sans-serif; white-space: normal; background-color: rgb(242, 242, 242);">.user.ini 文件</h2>
<p class="simpara" style="margin-top: 0px; margin-bottom: 1.5rem; color: rgb(51, 51, 51); font-family: &#39;Fira Sans&#39;, &#39;Source Sans Pro&#39;, Helvetica, Arial, sans-serif; line-height: 24px; white-space: normal; background-color: rgb(242, 242, 242);">自 PHP 5.3.0 起，PHP 支持基于每个目录的 .htaccess 风格的 INI 文件。此类文件<em class="emphasis" style="text-rendering: optimizeLegibility;">仅</em>被 CGI／FastCGI SAPI 处理。此功能使得 PECL 的 htscanner 扩展作废。如果使用 Apache，则用&nbsp;<var class="filename" style="border-radius: 2px; padding: 2px 4px; white-space: nowrap; font-style: normal; font-stretch: normal; font-size: 14px; line-height: 1.46; font-family: &#39;Source Code Pro&#39;, monospace; background-color: rgb(230, 230, 230);">.htaccess</var>&nbsp;文件有同样效果。</p>
<p class="simpara" style="margin-top: 0px; margin-bottom: 1.5rem; color: rgb(51, 51, 51); font-family: &#39;Fira Sans&#39;, &#39;Source Sans Pro&#39;, Helvetica, Arial, sans-serif; line-height: 24px; white-space: normal; background-color: rgb(242, 242, 242);">除了主&nbsp;<var class="filename" style="border-radius: 2px; padding: 2px 4px; white-space: nowrap; font-style: normal; font-stretch: normal; font-size: 14px; line-height: 1.46; font-family: &#39;Source Code Pro&#39;, monospace; background-color: rgb(230, 230, 230);">php.ini</var>&nbsp;之外，PHP 还会在每个目录下扫描 INI 文件，从被执行的 PHP 文件所在目录开始一直上升到 web 根目录（<var class="varname" style="border-radius: 2px; padding: 2px 4px; white-space: nowrap; font-style: normal; font-stretch: normal; font-size: 14px; line-height: 1.46; font-family: &#39;Source Code Pro&#39;, monospace; background-color: rgb(230, 230, 230);"></var><var class="varname" style="border-radius: 2px; padding: 2px 4px; font-style: normal; font-stretch: normal; line-height: 1.46;"><a href="http://php.net/manual/zh/reserved.variables.server.php" class="classname" style="border-bottom-width: 1px; border-bottom-style: solid; text-decoration: none; color: rgb(51, 102, 153);">$_SERVER[&#39;DOCUMENT_ROOT&#39;]</a></var>&nbsp;所指定的）。如果被执行的 PHP 文件在 web 根目录之外，则只扫描该目录。</p>
<p class="simpara" style="margin-top: 0px; margin-bottom: 1.5rem; color: rgb(51, 51, 51); font-family: &#39;Fira Sans&#39;, &#39;Source Sans Pro&#39;, Helvetica, Arial, sans-serif; line-height: 24px; white-space: normal; background-color: rgb(242, 242, 242);">在 .user.ini 风格的 INI 文件中只有具有&nbsp;<span style="text-rendering: optimizeLegibility;"><code style="font-weight: 700; font-stretch: normal; font-size: 0.875rem; line-height: 1.375rem; font-family: &#39;Fira Mono&#39;, &#39;Source Code Pro&#39;, monospace; word-wrap: break-word;">PHP_INI_PERDIR</code></span>&nbsp;和&nbsp;<span style="text-rendering: optimizeLegibility;"><code style="font-weight: 700; font-stretch: normal; font-size: 0.875rem; line-height: 1.375rem; font-family: &#39;Fira Mono&#39;, &#39;Source Code Pro&#39;, monospace; word-wrap: break-word;">PHP_INI_USER</code></span>&nbsp;模式的 INI 设置可被识别。</p>
<p class="simpara" style="margin-top: 0px; margin-bottom: 1.5rem; color: rgb(51, 51, 51); font-family: &#39;Fira Sans&#39;, &#39;Source Sans Pro&#39;, Helvetica, Arial, sans-serif; line-height: 24px; white-space: normal; background-color: rgb(242, 242, 242);">两个新的 INI 指令，<em style="text-rendering: optimizeLegibility;">user_ini.filename</em>&nbsp;和&nbsp;<em style="text-rendering: optimizeLegibility;">user_ini.cache_ttl</em>&nbsp;控制着用户 INI 文件的使用。</p>
<p class="simpara" style="margin-top: 0px; margin-bottom: 1.5rem; color: rgb(51, 51, 51); font-family: &#39;Fira Sans&#39;, &#39;Source Sans Pro&#39;, Helvetica, Arial, sans-serif; line-height: 24px; white-space: normal; background-color: rgb(242, 242, 242);"><em style="text-rendering: optimizeLegibility;">user_ini.filename</em>&nbsp;设定了 PHP 会在每个目录下搜寻的文件名；如果设定为空字符串则 PHP 不会搜寻。默认值是&nbsp;<em style="text-rendering: optimizeLegibility;">.user.ini</em>。</p>
<p class="simpara" style="margin-top: 0px; margin-bottom: 1.5rem; color: rgb(51, 51, 51); font-family: &#39;Fira Sans&#39;, &#39;Source Sans Pro&#39;, Helvetica, Arial, sans-serif; line-height: 24px; white-space: normal; background-color: rgb(242, 242, 242);"><em style="text-rendering: optimizeLegibility;">user_ini.cache_ttl</em>&nbsp;控制着重新读取用户 INI 文件的间隔时间。默认是 300 秒（5 分钟）。</p>
