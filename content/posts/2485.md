<h2>安装php-fpm容器</h2>
<pre><code class="language-shell">docker pull bitnami/php-fpm
docker run --name php7-fpm  -v ~/nginx/www:/www -d bitnami/php-fpm</code></pre>
<p>-d 后台运行<br />
-v 目录映射 主机的~/nginx/www目录映射到容器的www目录<br />
&#8211;name 给容器一个名字</p>
<h2>安装nginx容器</h2>
<pre><code class="language-shell">docker pull nginx
docker run -p 80:80 --name nginx -v ~/nginx/www:/usr/share/nginx/html -v ~/nginx/conf/conf.d:/etc/nginx/conf.d --link php7-fpm:php -d nginx</code></pre>
<p>-p将容器80端口映射到服务器的80端口</p>
<h2>配置nginx文件</h2>
<p>将配置文件放到服务器的~/nginx/conf/conf.d/ 文件夹中，文件内容如下:</p>
<pre><code class="language-shell">server {
    listen       80;
    server_name  localhost;

    location / {
        root   /usr/share/nginx/html;
        index  index.html index.htm index.php;
    }

    error_page   500 502 503 504  /50x.html;
    location = /50x.html {
        root   /usr/share/nginx/html;
    }

    location ~ \.php$ {
        fastcgi_pass   php:9000;
        fastcgi_index  index.php;
        fastcgi_param  SCRIPT_FILENAME  /www/$fastcgi_script_name;
        include        fastcgi_params;
    }
}</code></pre>
<p>fastcgi_pass 这里的php对应的是之前的php7-fpm进程，端口9000是php7-fpm默认进程.</p>
<h2>重启nginx容器</h2>
<pre><code class="language-shell">docker restart nginx</code></pre>
<h2>配置swoole扩展</h2>
<p>1.首先进入容器的shell环境</p>
<pre><code class="language-shell">docker exec -it php7-fpm /bin/bash</code></pre>
<p>2.更新源</p>
<pre><code class="language-shell">apt update</code></pre>
<p>3.安装需要的编译环境和文本编辑器</p>
<pre><code class="language-shell">apt install -y gcc g++ autoconf libtool make vim</code></pre>
<p>4.使用pecl安装swoole扩展</p>
<pre><code class="language-shell">pecl install swoole</code></pre>
<p>5.配置php.ini文件</p>
<pre><code class="language-shell">cd  /opt/bitnami/php/bin/php
vim php.ini
添加swoole扩展，就是添加
extension=swoole</code></pre>
<p>6.退出<br />
exit<br />
7.重启php7-fpm容器</p>
<pre><code class="language-shell">docker restart php7-fpm</code></pre>
<h2>注意事项</h2>
<p>由于swoole提供了http服务器，所以我们可以不使用php-fpm，我们可以直接使用php来运行我们的文件index.php文件如下：</p>
<pre><code class="language-php">&lt;?php

error_reporting(E_ALL);

$http = new Swoole\Http\Server(&quot;0.0.0.0&quot;, 9999);

$http-&gt;on(&#039;request&#039;, function ($request,Swoole\Http\Response $response) {

$response-&gt;end(&quot;&lt;h1&gt;hello&lt;/h1&gt;&quot;);

});

$http-&gt;start();</code></pre>
<p><strong>需要提到的一点，我们都是通过映射来进行和容器的文件交互的。</strong></p>
<p>当我们对php安装了扩展之后，我们可以把我们的容器进行打包成镜像，这样下次运行的时候，就需要重复安装扩展，这也是容器的一个优点。</p>
<pre><code class="language-shell">docker commit php7-fpm swoole</code></pre>
<p>启动容器的方法</p>
<pre><code class="language-shell">docker run --name swoole -it -p 8888:8888 -v /www:/app -d swoole php index.php</code></pre>
<p>运行上面的语句之前，我们本地服务器需要在/www目录下面存在index.php,就是上面我们提到的那个index.php文件，如果不存在，容器就会启动失败。<br />
查看容器的id,然后可以查询到容器的logs</p>
<pre><code class="language-shell">docker ps -a
docker logs id[xxxxxxxxxxxxxxxxx]</code></pre>
<p>而且我们可以进入容器的shell中查看/app目录中是否有同步的index.php</p>
<pre><code>docker exec -it swoole /bin/bash
cd /app
ls</code></pre>
<h2>总结</h2>
<p>我们的数据最后都是会放入到容器中执行的，那么如何和容器打交道或者通信是我们需要研究的<br />
其中-v这个是一个同步的方法，还有一个就是通过scp 把文件存入到容器中，不管那种方法，最后容器执行的时候，数据都是在容器中运行的，而不是在本地运行的，这也是容器的好处，就是保证了隔离性。</p>
