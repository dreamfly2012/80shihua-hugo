django中我们可以使用模板来构建页面，那么模板中标签如何使用，以及如何引入css,js，图片文件等。

extends标签用来继承模板。

block标签用来占位（占坑）

for标签用来循环变量

static标签用来引入静态文件

include标签用来引入其他模板文件

具体代码如下：

{% load static %}

&lt;link rel="stylesheet" href="{% static 'css/common.css' %}">

{% block title %} {% endblock %}

{% block nav %} {% include "index/nav.html" %} {% endblock %}

{% for article in articles %}

{{ article.title }}

{% endfor %}

{% extends "index/base.html" %}
