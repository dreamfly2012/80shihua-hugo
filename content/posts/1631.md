解决Gradle:download特别慢或卡主不动的问题

Gradle 在project创建的时候的时候会出现connect refused：connect或者卡在building gradle download https：等情况。

大多数的原因是因为我们Google对我们国内网络的限制：

解决办法：

使用阿里云的国内镜像仓库地址，就可以快速的下载需要的文件修改项目根目录下的文件 build.gradle ：

buildscript {

repositories {

maven{ url ‘https://maven.aliyun.com/nexus/content/groups/public/’}

}

}

allprojects {

repositories {

maven{ url ‘https://maven.aliyun.com/nexus/content/groups/public/’}

}

}

然后一定要记得选择重新构建项目(Rebuild project)。
