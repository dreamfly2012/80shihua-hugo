<p>php在应付高并发的时候，需要内存数据库，这时候redis就派上了用场。下面说下如何安装和使用redis.</p>
<p></p>
<p>yum install redis/apt-get install redis 就可以非常方便的安装好reids.</p>
<p></p>
<p>service redis start /systemctl start redis 就可以启动redis服务器</p>
<p></p>
<p>redis-cli verison 可以用来查看redis的版本，同时redis-cli也是和服务器交互的命令行客户端。</p>
<p></p>
<p>下面介绍下php-redis下原生操作方法。</p>
<pre class="brush:php;toolbar:false">1，connect

描述：实例连接到一个Redis.

参数：host:&nbsp;string，port:&nbsp;int

返回值：BOOL&nbsp;成功返回：TRUE;失败返回：FALSE

示例：

&lt;?php&nbsp;&nbsp;

$redis&nbsp;=&nbsp;new&nbsp;redis();&nbsp;&nbsp;

$result&nbsp;=&nbsp;$redis-&gt;connect(&#39;127.0.0.1&#39;,&nbsp;6379);&nbsp;&nbsp;

var_dump($result);&nbsp;//结果：bool(true)&nbsp;&nbsp;

?&gt;&nbsp;&nbsp;

2，set

描述：设置key和value的值

参数：Key&nbsp;Value

返回值：BOOL&nbsp;成功返回：TRUE;失败返回：FALSE

示例：

&lt;?php&nbsp;&nbsp;

$redis&nbsp;=&nbsp;new&nbsp;redis();&nbsp;&nbsp;

$redis-&gt;connect(&#39;127.0.0.1&#39;,&nbsp;6379);&nbsp;&nbsp;

$result&nbsp;=&nbsp;$redis-&gt;set(&#39;test&#39;,&quot;11111111111&quot;);&nbsp;&nbsp;

var_dump($result);&nbsp;&nbsp;&nbsp;&nbsp;//结果：bool(true)&nbsp;&nbsp;

?&gt;&nbsp;&nbsp;

3，get

描述：获取有关指定键的值

参数：key

返回值：string或BOOL&nbsp;如果键不存在，则返回&nbsp;FALSE。否则，返回指定键对应的value值。

范例：

&lt;?php&nbsp;&nbsp;

$redis&nbsp;=&nbsp;new&nbsp;redis();&nbsp;&nbsp;

$redis-&gt;connect(&#39;127.0.0.1&#39;,&nbsp;6379);&nbsp;&nbsp;

$result&nbsp;=&nbsp;$redis-&gt;get(&#39;test&#39;);&nbsp;&nbsp;

var_dump($result);&nbsp;&nbsp;&nbsp;//结果：string(11)&nbsp;&quot;11111111111&quot;&nbsp;&nbsp;

?&gt;&nbsp;&nbsp;

4，delete

描述：删除指定的键

参数：一个键，或不确定数目的参数，每一个关键的数组：key1&nbsp;key2&nbsp;key3&nbsp;…&nbsp;keyN

返回值：删除的项数

范例：

&lt;?php&nbsp;&nbsp;

$redis&nbsp;=&nbsp;new&nbsp;redis();&nbsp;&nbsp;

$redis-&gt;connect(&#39;127.0.0.1&#39;,&nbsp;6379);&nbsp;&nbsp;

$redis-&gt;set(&#39;test&#39;,&quot;1111111111111&quot;);&nbsp;&nbsp;

echo&nbsp;$redis-&gt;get(&#39;test&#39;);&nbsp;&nbsp;&nbsp;//结果：1111111111111&nbsp;&nbsp;

$redis-&gt;delete(&#39;test&#39;);&nbsp;&nbsp;

var_dump($redis-&gt;get(&#39;test&#39;));&nbsp;&nbsp;//结果：bool(false)&nbsp;&nbsp;

?&gt;&nbsp;&nbsp;

5，setnx

描述：如果在数据库中不存在该键，设置关键值参数

参数：key&nbsp;value

返回值：BOOL&nbsp;成功返回：TRUE;失败返回：FALSE

范例：

&lt;?php&nbsp;&nbsp;

$redis&nbsp;=&nbsp;new&nbsp;redis();&nbsp;&nbsp;

$redis-&gt;connect(&#39;127.0.0.1&#39;,&nbsp;6379);&nbsp;&nbsp;

$redis-&gt;set(&#39;test&#39;,&quot;1111111111111&quot;);&nbsp;&nbsp;

$redis-&gt;setnx(&#39;test&#39;,&quot;22222222&quot;);&nbsp;&nbsp;

echo&nbsp;$redis-&gt;get(&#39;test&#39;);&nbsp;&nbsp;//结果：1111111111111&nbsp;&nbsp;

$redis-&gt;delete(&#39;test&#39;);&nbsp;&nbsp;

$redis-&gt;setnx(&#39;test&#39;,&quot;22222222&quot;);&nbsp;&nbsp;

echo&nbsp;$redis-&gt;get(&#39;test&#39;);&nbsp;&nbsp;//结果：22222222&nbsp;&nbsp;

?&gt;&nbsp;&nbsp;

6，exists

描述：验证指定的键是否存在

参数key

返回值：Bool&nbsp;成功返回：TRUE;失败返回：FALSE

范例：

&lt;?php&nbsp;&nbsp;

$redis&nbsp;=&nbsp;new&nbsp;redis();&nbsp;&nbsp;

$redis-&gt;connect(&#39;127.0.0.1&#39;,&nbsp;6379);&nbsp;&nbsp;

$redis-&gt;set(&#39;test&#39;,&quot;1111111111111&quot;);&nbsp;&nbsp;

var_dump($redis-&gt;exists(&#39;test&#39;));&nbsp;&nbsp;//结果：bool(true)&nbsp;&nbsp;

?&gt;&nbsp;&nbsp;

7，incr

描述：数字递增存储键值键.

参数：key&nbsp;value：将被添加到键的值

返回值：INT&nbsp;the&nbsp;new&nbsp;value

实例：

&lt;?php&nbsp;&nbsp;

$redis&nbsp;=&nbsp;new&nbsp;redis();&nbsp;&nbsp;

$redis-&gt;connect(&#39;127.0.0.1&#39;,&nbsp;6379);&nbsp;&nbsp;

$redis-&gt;set(&#39;test&#39;,&quot;123&quot;);&nbsp;&nbsp;

var_dump($redis-&gt;incr(&quot;test&quot;));&nbsp;&nbsp;//结果：int(124)&nbsp;&nbsp;

var_dump($redis-&gt;incr(&quot;test&quot;));&nbsp;&nbsp;//结果：int(125)&nbsp;&nbsp;

?&gt;

&nbsp;&nbsp;

8，decr

描述：数字递减存储键值。

参数：key&nbsp;value：将被添加到键的值

返回值：INT&nbsp;the&nbsp;new&nbsp;value

实例：

&lt;?php&nbsp;&nbsp;

$redis&nbsp;=&nbsp;new&nbsp;redis();&nbsp;&nbsp;

$redis-&gt;connect(&#39;127.0.0.1&#39;,&nbsp;6379);&nbsp;&nbsp;

$redis-&gt;set(&#39;test&#39;,&quot;123&quot;);&nbsp;&nbsp;

var_dump($redis-&gt;decr(&quot;test&quot;));&nbsp;&nbsp;//结果：int(122)&nbsp;&nbsp;

var_dump($redis-&gt;decr(&quot;test&quot;));&nbsp;&nbsp;//结果：int(121)&nbsp;&nbsp;

?&gt;

9，getMultiple

描述：取得所有指定键的值。如果一个或多个键不存在，该数组中该键的值为假

参数：其中包含键值的列表数组

返回值：返回包含所有键的值的数组

实例：

&lt;?php&nbsp;&nbsp;

$redis&nbsp;=&nbsp;new&nbsp;redis();&nbsp;&nbsp;

$redis-&gt;connect(&#39;127.0.0.1&#39;,&nbsp;6379);&nbsp;&nbsp;

$redis-&gt;set(&#39;test1&#39;,&quot;1&quot;);&nbsp;&nbsp;

$redis-&gt;set(&#39;test2&#39;,&quot;2&quot;);&nbsp;&nbsp;

$result&nbsp;=&nbsp;$redis-&gt;getMultiple(array(&#39;test1&#39;,&#39;test2&#39;));&nbsp;&nbsp;

print_r($result);&nbsp;&nbsp;&nbsp;//结果：Array&nbsp;(&nbsp;[0]&nbsp;=&gt;&nbsp;1&nbsp;[1]&nbsp;=&gt;&nbsp;2&nbsp;)&nbsp;&nbsp;

?&gt;

10，lpush

描述：由列表头部添加字符串值。如果不存在该键则创建该列表。如果该键存在，而且不是一个列表，返回FALSE。

参数：key,value

返回值：成功返回数组长度，失败false

实例：

&lt;?php&nbsp;&nbsp;

$redis&nbsp;=&nbsp;new&nbsp;redis();&nbsp;&nbsp;

$redis-&gt;connect(&#39;127.0.0.1&#39;,&nbsp;6379);&nbsp;&nbsp;

$redis-&gt;delete(&#39;test&#39;);&nbsp;&nbsp;

var_dump($redis-&gt;lpush(&quot;test&quot;,&quot;111&quot;));&nbsp;&nbsp;&nbsp;//结果：int(1)&nbsp;&nbsp;

var_dump($redis-&gt;lpush(&quot;test&quot;,&quot;222&quot;));&nbsp;&nbsp;&nbsp;//结果：int(2)&nbsp;&nbsp;

?&gt;

11，rpush

描述：由列表尾部添加字符串值。如果不存在该键则创建该列表。如果该键存在，而且不是一个列表，返回FALSE。

参数：key,value

返回值：成功返回数组长度，失败false

范例：

&lt;?php&nbsp;&nbsp;

$redis&nbsp;=&nbsp;new&nbsp;redis();&nbsp;&nbsp;

$redis-&gt;connect(&#39;127.0.0.1&#39;,&nbsp;6379);&nbsp;&nbsp;

$redis-&gt;delete(&#39;test&#39;);&nbsp;&nbsp;

var_dump($redis-&gt;lpush(&quot;test&quot;,&quot;111&quot;));&nbsp;&nbsp;&nbsp;//结果：int(1)&nbsp;&nbsp;

var_dump($redis-&gt;lpush(&quot;test&quot;,&quot;222&quot;));&nbsp;&nbsp;&nbsp;//结果：int(2)&nbsp;&nbsp;

var_dump($redis-&gt;rpush(&quot;test&quot;,&quot;333&quot;));&nbsp;&nbsp;&nbsp;//结果：int(3)&nbsp;&nbsp;

var_dump($redis-&gt;rpush(&quot;test&quot;,&quot;444&quot;));&nbsp;&nbsp;&nbsp;//结果：int(4)&nbsp;&nbsp;

?&gt;

12，lpop

描述：返回和移除列表的第一个元素

参数：key

返回值：成功返回第一个元素的值&nbsp;，失败返回false

范例：

&lt;?php&nbsp;&nbsp;

$redis&nbsp;=&nbsp;new&nbsp;redis();&nbsp;&nbsp;

$redis-&gt;connect(&#39;127.0.0.1&#39;,&nbsp;6379);&nbsp;&nbsp;

$redis-&gt;delete(&#39;test&#39;);&nbsp;&nbsp;

$redis-&gt;lpush(&quot;test&quot;,&quot;111&quot;);&nbsp;&nbsp;

$redis-&gt;lpush(&quot;test&quot;,&quot;222&quot;);&nbsp;&nbsp;

$redis-&gt;rpush(&quot;test&quot;,&quot;333&quot;);&nbsp;&nbsp;

$redis-&gt;rpush(&quot;test&quot;,&quot;444&quot;);&nbsp;&nbsp;

var_dump($redis-&gt;lpop(&quot;test&quot;));&nbsp;&nbsp;//结果：string(3)&nbsp;&quot;222&quot;&nbsp;&nbsp;

?&gt;

13，lsize,llen

描述：返回的列表的长度。如果列表不存在或为空，该命令返回0。如果该键不是列表，该命令返回FALSE。

参数：Key

返回值：成功返回数组长度，失败false

范例：

&lt;?php&nbsp;&nbsp;

$redis&nbsp;=&nbsp;new&nbsp;redis();&nbsp;&nbsp;

$redis-&gt;connect(&#39;127.0.0.1&#39;,&nbsp;6379);&nbsp;&nbsp;

$redis-&gt;delete(&#39;test&#39;);&nbsp;&nbsp;

$redis-&gt;lpush(&quot;test&quot;,&quot;111&quot;);&nbsp;&nbsp;

$redis-&gt;lpush(&quot;test&quot;,&quot;222&quot;);&nbsp;&nbsp;

$redis-&gt;rpush(&quot;test&quot;,&quot;333&quot;);&nbsp;&nbsp;

$redis-&gt;rpush(&quot;test&quot;,&quot;444&quot;);&nbsp;&nbsp;

var_dump($redis-&gt;lsize(&quot;test&quot;));&nbsp;&nbsp;//结果：int(4)&nbsp;&nbsp;

?&gt;

14，lget

描述：返回指定键存储在列表中指定的元素。&nbsp;0第一个元素，1第二个…&nbsp;-1最后一个元素，-2的倒数第二…错误的索引或键不指向列表则返回FALSE。

参数：key&nbsp;index

返回值：成功返回指定元素的值，失败false

范例：

&lt;?php&nbsp;&nbsp;

$redis&nbsp;=&nbsp;new&nbsp;redis();&nbsp;&nbsp;

$redis-&gt;connect(&#39;127.0.0.1&#39;,&nbsp;6379);&nbsp;&nbsp;

$redis-&gt;delete(&#39;test&#39;);&nbsp;&nbsp;

$redis-&gt;lpush(&quot;test&quot;,&quot;111&quot;);&nbsp;&nbsp;

$redis-&gt;lpush(&quot;test&quot;,&quot;222&quot;);&nbsp;&nbsp;

$redis-&gt;rpush(&quot;test&quot;,&quot;333&quot;);&nbsp;&nbsp;

$redis-&gt;rpush(&quot;test&quot;,&quot;444&quot;);&nbsp;&nbsp;

var_dump($redis-&gt;lget(&quot;test&quot;,3));&nbsp;&nbsp;//结果：string(3)&nbsp;&quot;444&quot;&nbsp;&nbsp;

?&gt;

15，lset

描述：为列表指定的索引赋新的值,若不存在该索引返回false.

参数：key&nbsp;index&nbsp;value

返回值：成功返回true,失败false

范例：

&lt;?php&nbsp;&nbsp;

$redis&nbsp;=&nbsp;new&nbsp;redis();&nbsp;&nbsp;

$redis-&gt;connect(&#39;127.0.0.1&#39;,&nbsp;6379);&nbsp;&nbsp;

$redis-&gt;delete(&#39;test&#39;);&nbsp;&nbsp;

$redis-&gt;lpush(&quot;test&quot;,&quot;111&quot;);&nbsp;&nbsp;

$redis-&gt;lpush(&quot;test&quot;,&quot;222&quot;);&nbsp;&nbsp;

var_dump($redis-&gt;lget(&quot;test&quot;,1));&nbsp;&nbsp;//结果：string(3)&nbsp;&quot;111&quot;&nbsp;&nbsp;

var_dump($redis-&gt;lset(&quot;test&quot;,1,&quot;333&quot;));&nbsp;&nbsp;//结果：bool(true)&nbsp;&nbsp;

var_dump($redis-&gt;lget(&quot;test&quot;,1));&nbsp;&nbsp;//结果：string(3)&nbsp;&quot;333&quot;&nbsp;&nbsp;

?&gt;

16，lgetrange

描述：

返回在该区域中的指定键列表中开始到结束存储的指定元素，lGetRange(key,&nbsp;start,&nbsp;end)。0第一个元素，1第二个元素…&nbsp;-1最后一个元素，-2的倒数第二…

参数：key&nbsp;start&nbsp;end

返回值：成功返回查找的值，失败false

范例：

&lt;?php&nbsp;&nbsp;

$redis&nbsp;=&nbsp;new&nbsp;redis();&nbsp;&nbsp;

$redis-&gt;connect(&#39;127.0.0.1&#39;,&nbsp;6379);&nbsp;&nbsp;

$redis-&gt;delete(&#39;test&#39;);&nbsp;&nbsp;

$redis-&gt;lpush(&quot;test&quot;,&quot;111&quot;);&nbsp;&nbsp;

$redis-&gt;lpush(&quot;test&quot;,&quot;222&quot;);&nbsp;&nbsp;

print_r($redis-&gt;lgetrange(&quot;test&quot;,0,-1));&nbsp;&nbsp;//结果：Array&nbsp;(&nbsp;[0]&nbsp;=&gt;&nbsp;222&nbsp;[1]&nbsp;=&gt;&nbsp;111&nbsp;)&nbsp;&nbsp;

?&gt;

17,lremove

描述：从列表中从头部开始移除count个匹配的值。如果count为零，所有匹配的元素都被删除。如果count是负数，内容从尾部开始删除。

参数：key&nbsp;count&nbsp;value

返回值：成功返回删除的个数，失败false

范例：

&lt;?php&nbsp;&nbsp;

$redis&nbsp;=&nbsp;new&nbsp;redis();&nbsp;&nbsp;

$redis-&gt;connect(&#39;127.0.0.1&#39;,&nbsp;6379);&nbsp;&nbsp;

$redis-&gt;delete(&#39;test&#39;);&nbsp;&nbsp;

$redis-&gt;lpush(&#39;test&#39;,&#39;a&#39;);&nbsp;&nbsp;

$redis-&gt;lpush(&#39;test&#39;,&#39;b&#39;);&nbsp;&nbsp;

$redis-&gt;lpush(&#39;test&#39;,&#39;c&#39;);&nbsp;&nbsp;

$redis-&gt;rpush(&#39;test&#39;,&#39;a&#39;);&nbsp;&nbsp;

print_r($redis-&gt;lgetrange(&#39;test&#39;,&nbsp;0,&nbsp;-1));&nbsp;//结果：Array&nbsp;(&nbsp;[0]&nbsp;=&gt;&nbsp;c&nbsp;[1]&nbsp;=&gt;&nbsp;b&nbsp;[2]&nbsp;=&gt;&nbsp;a&nbsp;[3]&nbsp;=&gt;&nbsp;a&nbsp;)&nbsp;&nbsp;

var_dump($redis-&gt;lremove(&#39;test&#39;,&#39;a&#39;,2));&nbsp;&nbsp;&nbsp;//结果：int(2)&nbsp;&nbsp;

print_r($redis-&gt;lgetrange(&#39;test&#39;,&nbsp;0,&nbsp;-1));&nbsp;//结果：Array&nbsp;(&nbsp;[0]&nbsp;=&gt;&nbsp;c&nbsp;[1]&nbsp;=&gt;&nbsp;b&nbsp;)&nbsp;&nbsp;

?&gt;

18，sadd

描述：为一个Key添加一个值。如果这个值已经在这个Key中，则返回FALSE。

参数：key&nbsp;value

返回值：成功返回true,失败false

范例：

&lt;?php&nbsp;&nbsp;

$redis&nbsp;=&nbsp;new&nbsp;redis();&nbsp;&nbsp;

$redis-&gt;connect(&#39;127.0.0.1&#39;,&nbsp;6379);&nbsp;&nbsp;

var_dump($redis-&gt;sadd(&#39;test&#39;,&#39;333&#39;));&nbsp;&nbsp;&nbsp;//结果：bool(true)&nbsp;&nbsp;

print_r($redis-&gt;sort(&#39;test&#39;));&nbsp;//结果：Array&nbsp;(&nbsp;[0]&nbsp;=&gt;&nbsp;111&nbsp;[1]&nbsp;=&gt;&nbsp;333&nbsp;)&nbsp;&nbsp;

?&gt;

19，sremove

描述：删除Key中指定的value值

参数：key&nbsp;member

返回值：true&nbsp;or&nbsp;false

范例：

&lt;?php&nbsp;&nbsp;

$redis&nbsp;=&nbsp;new&nbsp;redis();&nbsp;&nbsp;

$redis-&gt;connect(&#39;127.0.0.1&#39;,&nbsp;6379);&nbsp;&nbsp;

?&gt;

20,smove

描述：将Key1中的value移动到Key2中

参数：srcKey&nbsp;dstKey&nbsp;member

返回值：true&nbsp;or&nbsp;false

范例

&lt;?php&nbsp;&nbsp;

$redis&nbsp;=&nbsp;new&nbsp;redis();&nbsp;&nbsp;

$redis-&gt;connect(&#39;127.0.0.1&#39;,&nbsp;6379);&nbsp;&nbsp;

$redis-&gt;delete(&#39;test&#39;);&nbsp;&nbsp;

$redis-&gt;delete(&#39;test1&#39;);&nbsp;&nbsp;

$redis-&gt;sadd(&#39;test&#39;,&#39;111&#39;);&nbsp;&nbsp;

$redis-&gt;sadd(&#39;test&#39;,&#39;333&#39;);&nbsp;&nbsp;

$redis-&gt;sadd(&#39;test1&#39;,&#39;222&#39;);&nbsp;&nbsp;

$redis-&gt;sadd(&#39;test1&#39;,&#39;444&#39;);&nbsp;&nbsp;

$redis-&gt;smove(&#39;test&#39;,&quot;test1&quot;,&#39;111&#39;);&nbsp;&nbsp;

print_r($redis-&gt;sort(&#39;test1&#39;));&nbsp;&nbsp;&nbsp;&nbsp;//结果：Array&nbsp;(&nbsp;[0]&nbsp;=&gt;&nbsp;111&nbsp;[1]&nbsp;=&gt;&nbsp;222&nbsp;[2]&nbsp;=&gt;&nbsp;444&nbsp;)&nbsp;&nbsp;

?&gt;

21，scontains

返回值：true&nbsp;or&nbsp;false

范例：

var_dump($redis-&gt;scontains(&#39;test&#39;,&nbsp;&#39;111&#39;));&nbsp;//结果：bool(true)&nbsp;&nbsp;

?&gt;

22,ssize

描述：返回集合中存储值的数量

参数：key

&lt;?php&nbsp;&nbsp;

$redis&nbsp;=&nbsp;new&nbsp;redis();&nbsp;&nbsp;

范例：

&lt;?php&nbsp;&nbsp;

24,sinter

描述：返回一个所有指定键的交集。如果只指定一个键，那么这个命令生成这个集合的成员。如果不存在某个键，则返回FALSE。

参数：key1,&nbsp;key2,&nbsp;keyN

返回值：成功返回数组交集，失败false

范例：

&lt;?php&nbsp;&nbsp;

$redis&nbsp;=&nbsp;new&nbsp;redis();&nbsp;&nbsp;

$redis-&gt;connect(&#39;127.0.0.1&#39;,&nbsp;6379);&nbsp;&nbsp;

$redis-&gt;delete(&#39;test&#39;);&nbsp;&nbsp;

$redis-&gt;sadd(&quot;test&quot;,&quot;111&quot;);&nbsp;&nbsp;

$redis-&gt;sadd(&quot;test&quot;,&quot;222&quot;);&nbsp;&nbsp;
