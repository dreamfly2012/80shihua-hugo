smarty2中，我按照正常循环写的

```
{foreach from="$commments" item="com"}
```
```
{foreach from="$com.images" item="pic"}
{$pic.url}
```
```
{/foreach}
{/foreach}
不能输出图片url,后来发现，去掉双引号可以解决问题。
{foreach from=$commments item=com}
{foreach from=$com.images item=pic}
{$pic.url}
{/foreach}
{/foreach}
```
