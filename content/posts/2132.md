<h1 class="postTitle" style="margin: 0px; padding: 0px 64px 0px 10px; list-style-type: none; list-style-image: none; font-size: 20px; font-weight: normal; border-left: 3px solid rgb(33, 117, 188); font-family: Tahoma, Arial, Helvetica, sans-serif; white-space: normal; background-color: rgb(255, 255, 255);"><a id="cb_post_title_url" class="postTitle2" href="https://www.cnblogs.com/xiaoliangup/p/9175932.html" style="outline: 0px; text-decoration-line: none; color: black;">nginx location指令详解</a></h1>
<div class="postBody" style="clear: both; margin-top: 26px; font-size: 14px; color: rgb(68, 68, 68); line-height: 1.8; font-family: Tahoma, Arial, Helvetica, sans-serif; white-space: normal; background-color: rgb(255, 255, 255);">
<div id="cnblogs_post_body" class="blogpost-body" style="margin-bottom: 20px; word-break: break-word;">
<p style="margin: 10px auto; padding: 0px; list-style-type: none; list-style-image: none;">通过指定模式来与客户端请求的URI相匹配，基本语法如下：<strong>location [=|~|~*|^~|@] pattern{……}</strong></p>
<p style="margin: 10px auto; padding: 0px; list-style-type: none; list-style-image: none;">1、没有修饰符模糊匹配 ：以指定模式开始：</p>
<pre class="brush:bash;toolbar:false">server&nbsp;{

　　server_name&nbsp;www.80shihua.com;

　　location&nbsp;/aabbcc&nbsp;{

　　　　……

　　}

}



那么，如下是对的：

http://www.80shihua.com/aabbcc

http://www.80shihua.com/aabbcc?s=1

http://www.80shihua.com/aabbcc/

http://www.80shihua.com/aabbccc</pre>
<p style="margin: 10px auto; padding: 0px; list-style-type: none; list-style-image: none;">2、=<span style="color: rgb(68, 68, 68); font-family: Tahoma, Arial, Helvetica, sans-serif; font-size: 14px; background-color: rgb(255, 255, 255);">精确匹配</span>：</p>
<pre style="margin-top: 0px; margin-bottom: 0px; padding: 0px; font-size: 12px; white-space: pre-wrap; word-wrap: break-word; list-style-type: none; list-style-image: none; font-family: &quot;Courier New&quot; !important;">server&nbsp;{

server_name&nbsp;www.80shihua.com

　　location&nbsp;=&nbsp;/aabbcc&nbsp;{

　　　　……

　　}

}

正确：

http://www.80shihua.com/aabbcc

http://www.80shihua.com/aabbcc?s=1</pre>
<pre style="margin-top: 0px; margin-bottom: 0px; padding: 0px; font-size: 12px; white-space: pre-wrap; word-wrap: break-word; list-style-type: none; list-style-image: none; font-family: &quot;Courier New&quot; !important;">&nbsp;

错误:

http://www.80shihua.com/aabbcc/

http://www.80shihua.com/aabbcc</pre>
<p><span style="color: rgb(68, 68, 68); font-family: Tahoma, Arial, Helvetica, sans-serif; font-size: 14px; background-color: rgb(255, 255, 255);">3、~区分大小写匹配 ：</span></p>
<pre class="brush:bash;toolbar:false">server&nbsp;{

server_name&nbsp;baidu.com;

　　location&nbsp;~&nbsp;^/aabbcc$&nbsp;{

　　　　……

　　}

}

正确：

http://www.80shihua.com/aabbcc

http://www.80shihua.com/aabbcc?s=1

&nbsp;

错误:

http://www.80shihua.com/Aabbcc/

http://www.80shihua.com/AaBbcc</pre>
<p><span style="color: rgb(68, 68, 68); font-family: Tahoma, Arial, Helvetica, sans-serif; font-size: 14px; background-color: rgb(255, 255, 255);"></span></p>
<p style="margin: 10px auto; padding: 0px; list-style-type: none; list-style-image: none;">4、~* 表示：指定的正则表达式不区分大小写</p>
<pre class="brush:bash;toolbar:false">server&nbsp;{

server_name&nbsp;baidu.com;

　　location&nbsp;~*&nbsp;^/aabbcc$&nbsp;{

　　　　……

　　}

}

正确：

http://www.80shihua.com/Aabbcc

http://www.80shihua.com/Aabbcc?s=1

http://www.80shihua.com/aaBbcc

http://www.80shihua.com/aAbbCc</pre>
<p style="margin: 10px auto; padding: 0px; list-style-type: none; list-style-image: none;"><span style="font-size: 15px;"><span style="color: rgb(68, 68, 68); font-family: Tahoma, Arial, Helvetica, sans-serif; font-size: 14px; background-color: rgb(255, 255, 255);"><span style="color: rgb(68, 68, 68); font-family: Tahoma, Arial, Helvetica, sans-serif; font-size: 14px; background-color: rgb(255, 255, 255);">5、root 、alias指令区别</span></span></span></p>
<div class="cnblogs_code" style="background-color: rgb(245, 245, 245); border: 1px solid rgb(204, 204, 204); padding: 5px; overflow: auto; margin: 5px 0px; color: rgb(0, 0, 0); font-family: &quot;Courier New&quot; !important; font-size: 12px !important;">
<pre style="margin-top: 0px; margin-bottom: 0px; white-space: pre-wrap; word-wrap: break-word; padding: 0px; list-style-type: none; list-style-image: none; font-family: &quot;Courier New&quot; !important;">location&nbsp;/img/&nbsp;{

&nbsp;&nbsp;&nbsp;&nbsp;alias&nbsp;/var/www/image/;

}</pre>
</div>
<pre style="margin-top: 0px; margin-bottom: 0px; white-space: pre-wrap; word-wrap: break-word; padding: 0px; list-style-type: none; list-style-image: none; font-family: &quot;Courier New&quot;, Courier, monospace;">#若按照上述配置的话，则访问/img/目录里面的文件时，ningx会自动去/var/www/image/目录找文件</pre>
<div class="cnblogs_code" style="background-color: rgb(245, 245, 245); border: 1px solid rgb(204, 204, 204); padding: 5px; overflow: auto; margin: 5px 0px; color: rgb(0, 0, 0); font-family: &quot;Courier New&quot; !important; font-size: 12px !important;">
<pre style="margin-top: 0px; margin-bottom: 0px; white-space: pre-wrap; word-wrap: break-word; padding: 0px; list-style-type: none; list-style-image: none; font-family: &quot;Courier New&quot; !important;">location&nbsp;/img/&nbsp;{

&nbsp;&nbsp;&nbsp;&nbsp;root&nbsp;/var/www/image;

}</pre>
</div>
<pre style="margin-top: 0px; margin-bottom: 0px; white-space: pre-wrap; word-wrap: break-word; padding: 0px; list-style-type: none; list-style-image: none; font-family: &quot;Courier New&quot;, Courier, monospace;">#若按照这种配置的话，则访问/img/目录下的文件时，nginx会去/var/www/image/img/目录下找文件。</pre>
<p style="margin: 10px auto; padding: 0px; list-style-type: none; list-style-image: none;">alias是一个目录别名的定义，root则是最上层目录的定义。</p>
