当我们本地新创建了几个文件和文件夹，我们不希望使用

```plain
$git add a.txt
$git add b.txt
$git add c.txt
$git add f
```
这些命令一个个添加，我们希望批量添加所有的文件，我们可以使用命令

```plain
$git add .
```
后面添加. 就是表示匹配所有未添加的文件。
