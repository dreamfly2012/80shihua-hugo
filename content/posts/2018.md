<p>php5即将停止维护，现在我们应该都切换到php7上面。</p>
<p></p>
<p>php7不仅比php5有更好的官方支持，它的性能提升，它的代码健壮性，可维护性都提升了不止一个档次。</p>
<p></p>
<p>下面主要介绍php7在linux上是如何配置的。一般来说有两种方式。</p>
<p></p>
<p><strong>第一种，通过系统的包管理工具安装。</strong></p>
<p>比如你是centos，redhat系统，你可以通过yum命令来安装。</p>
<p>yum install php7</p>
<p>如果你是ubuntu系统，你可以通过apt-get命令来安装。</p>
<p>apt-get install php7</p>
<p></p>
<p>第二种，通过源码包编译安装。</p>
<p></p>
<p><img loading="lazy" decoding="async" src="/ueditor/php/upload/image/20190221/1550725171601976.png" title="php7" alt="php7" width="530" height="192" style="width: 530px; height: 192px;" border="0" vspace="0"/></p>
<p></p>
<p>前往官方网站<a href="http://www.php.net" _src="http://www.php.net">http://www.php.net</a>，下载源码包.</p>
<ol class=" list-paddingleft-2" style="list-style-type: decimal;">
<li>
<p>wget&nbsp;<a href="http://59.80.44.98/cn2.php.net/distributions/php-7.3.2.tar.gz" _src="http://59.80.44.98/cn2.php.net/distributions/php-7.3.2.tar.gz">http://59.80.44.98/cn2.php.net/distributions/php-7.3.2.tar.gz</a></p>
</li>
<li>
<p>tar -xvf php7-7.3.2.tar.gz</p>
</li>
<li>
<p>./configue</p>
</li>
<li>
<p>make &amp;&amp; make install</p>
</li>
<li>
<p>service php-fpm start&nbsp;</p>
</li>
</ol>
<p></p>
<p>经过上面5步，php就已经安装好了，可以说非常简单。</p>
