php5即将停止维护，现在我们应该都切换到php7上面。

php7不仅比php5有更好的官方支持，它的性能提升，它的代码健壮性，可维护性都提升了不止一个档次。

下面主要介绍php7在linux上是如何配置的。一般来说有两种方式。

**第一种，通过系统的包管理工具安装。**

比如你是centos，redhat系统，你可以通过yum命令来安装。

yum install php7

如果你是ubuntu系统，你可以通过apt-get命令来安装。

apt-get install php7

第二种，通过源码包编译安装。

![php7](/uploads/ueditor/php/upload/image/20190221/1550725171601976.png)

前往官方网站[http://www.php.net](http://www.php.net)，下载源码包.

wget [http://59.80.44.98/cn2.php.net/distributions/php-7.3.2.tar.gz](http://59.80.44.98/cn2.php.net/distributions/php-7.3.2.tar.gz)

tar -xvf php7-7.3.2.tar.gz

./configue

make && make install

service php-fpm start

经过上面5步，php就已经安装好了，可以说非常简单。
