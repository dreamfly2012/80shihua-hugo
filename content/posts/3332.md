<p>PyPI 镜像在每次同步成功后间隔 5 分钟同步一次。</p>
<p>pip<br />
临时使用</p>
<pre><code class="language-python">pip install -i https://pypi.tuna.tsinghua.edu.cn/simple some-package</code></pre>
<p>注意，simple 不能少, 是 https 而不是 http</p>
<p>设为默认<br />
升级 pip 到最新的版本 (&gt;=10.0.0) 后进行配置：</p>
<pre><code class="language-python">python -m pip install --upgrade pip
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple</code></pre>
<p>如果您到 pip 默认源的网络连接较差，临时使用本镜像站来升级 pip：</p>
<pre><code class="language-python">python -m pip install -i https://pypi.tuna.tsinghua.edu.cn/simple --upgrade pip</code></pre>
<p>配置多个镜像源<br />
如果您想配置多个镜像源平衡负载，可在已经替换 index-url 的情况下通过以下方式继续增加源站：</p>
<pre><code class="language-python">pip config set global.extra-index-url &quot;&lt;url1&gt; &lt;url2&gt;...&quot;</code></pre>
<p>请自行替换引号内的内容，源地址之间需要有空格</p>
<p>可用的 pypi 源列表（校园网联合镜像站）：<a href="https://mirrors.cernet.edu.cn/list/pypi">https://mirrors.cernet.edu.cn/list/pypi</a></p>
<p>PDM<br />
通过如下命令设置默认镜像：</p>
<pre><code class="language-python">pdm config pypi.url https://pypi.tuna.tsinghua.edu.cn/simple</code></pre>
<p>Poetry<br />
通过以下命令设置首选镜像：</p>
<p>poetry source add &#8211;priority=primary mirrors <a href="https://pypi.tuna.tsinghua.edu.cn/simple/">https://pypi.tuna.tsinghua.edu.cn/simple/</a><br />
通过以下命令设置补充镜像：</p>
<pre><code class="language-python">poetry source add --priority=supplemental mirrors https://pypi.tuna.tsinghua.edu.cn/simple/</code></pre>
