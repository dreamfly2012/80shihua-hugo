<p>我们安装ueditor之后，使用ueditorfield的时候，我们在生成模型的时候，可能会遇到&nbsp;No module named &#39;shortuuid&#39;这样的错误。这是因为ueditor使用了这个模块，我们只需要</p>
<p>pip install shortuuid 安装这个模块之后，再执行makegirations 就可以了。</p>
<p></p>
<p>很多类似的错误，比如no moudule named xxx 都可以通过尝试安装pip&nbsp; install xxx来尝试。</p>
