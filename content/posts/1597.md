<p>1.首先在项目目录新建2个配置文件，一个tasks.json文件，一个launch.json文件</p>
<p>2.launch.json文件如下</p>
<pre><code class="language-shell">{
    // 使用 IntelliSense 了解相关属性。 
    // 悬停以查看现有属性的描述。
    // 欲了解更多信息，请访问: https://go.microsoft.com/fwlink/?linkid=830387
    &quot;version&quot;: &quot;0.2.0&quot;,
    &quot;configurations&quot;: [

        {
            &quot;name&quot;: &quot;(gdb) Launch&quot;,
            &quot;type&quot;: &quot;cppdbg&quot;,
            &quot;request&quot;: &quot;launch&quot;,
            &quot;program&quot;: &quot;${workspaceFolder}/main.exe&quot;,
            &quot;args&quot;: [],
            &quot;stopAtEntry&quot;: false,
            &quot;cwd&quot;: &quot;${workspaceFolder}&quot;,
            &quot;environment&quot;: [],
            &quot;externalConsole&quot;: true,
            &quot;MIMode&quot;: &quot;gdb&quot;,
            &quot;miDebuggerPath&quot;: &quot;D:\\MinGW\\bin\\gdb.exe&quot;,
            &quot;setupCommands&quot;: [
                {
                    &quot;description&quot;: &quot;Enable pretty-printing for gdb&quot;,
                    &quot;text&quot;: &quot;-enable-pretty-printing&quot;,
                    &quot;ignoreFailures&quot;: true
                }
            ],
            &quot;preLaunchTask&quot;: &quot;build-debug&quot;
        }
    ]
}
</code></pre>
<p>其中program:${workspaceFolder}/debug.exe 是要调用的程序，<br />
MIMode:&quot;gdb&quot;是调试的程序，这里采用gdb进行调试，<br />
&quot;miDebuggerPath&quot;: &quot;D:\MinGW\bin\gdb.exe&quot;,是调试程序的路径<br />
&quot;preLaunchTask&quot;:&quot;build-debug&quot;是调试之前的任务名称。</p>
<p>这里build-debug是和下面的tasks.json中的任务名对应的。</p>
<p>意思是我们在调试之前，先调用任务生成main.exe文件</p>
<p>3.tasks.json文件内容</p>
<pre><code class="language-shell">{
    &quot;version&quot;: &quot;2.0.0&quot;,
    &quot;tasks&quot;: [
        {
            &quot;label&quot;: &quot;build-debug&quot;,
            &quot;type&quot;: &quot;shell&quot;,
            &quot;command&quot;: &quot;g++&quot;,
            &quot;problemMatcher&quot;: [],
            &quot;args&quot;: [
                &quot;-g&quot;,
                &quot;main.cpp&quot;,
                &quot;-o&quot;,
                &quot;main.exe&quot;
            ]
        }
    ]
}</code></pre>
<ol start="4">
<li>注意事项</li>
</ol>
<p>program:中的调试程序名称需要和args中生成的exe名称一致。</p>
<p>miDebuggerPath:需要配置成绝对路径，否则可能出现路径非法问题。</p>
<p>这里label是任务名称，这是最新版vscode的写法，之前是采用taskName来定义的。</p>
<p>type:&quot;shell&quot;指的是调用方式。</p>
<p>commond:&quot;g++&quot;这里指调用任务的程序，这里是通过g++来编译生成debug.exe文件.</p>
<p>args:[]这里是g++命令的后面提供的参数。</p>
<p>g++的完整命令是：</p>
<p>g++ -g main.cpp -o main.exe </p>
<p>所以我们在args中配置了4个参数作为g++调用使用。</p>
<p>通过以上配置就可以在vscode中调试c++了，但是着些都是在你已经配置好g++,gdb等环境变量的前提下，如何配置g++,gdb等环境变量，请参考<br />
