<p>Go作为构建Web应用程序的首选语言正变得越来越流行。</p>
<p>这在很大程度上要归功于它的速度，应用程序性能以及可移植性。互联网上有很多资源可以教您如何在Go中构建端到端Web应用程序，但是在大多数情况下，它们要么散布在孤立的博客文章中，要么散布在书籍中。</p>
<p>这里将从0开始搭建一个完整的项目。</p>
<h2>项目效果</h2>
<p>我们将建立鸟类社区百科全书。该网站将：</p>
<ul>
<li>显示社区提交的不同条目，以及它们找到的鸟的名称和详细信息。</li>
<li>允许任何人张贴关于他们看见的鸟的新条目。</li>
</ul>
<p>此应用程序将需要三个组件：</p>
<ul>
<li>Web服务器</li>
<li>前端（客户端）应用</li>
<li>数据库</li>
</ul>
<h2>设置环境</h2>
<p>配置GOPATH,就是将GOPATH添加到系统的环境变量中去。</p>
<h2>设置目录</h2>
<p>gopath目录设置三个子目录，没有创建，分别是src,bin,pkg</p>
<ul>
<li>src 所有 Go源代码的去向,包括我们自己要创建的代码</li>
<li>bin go编译之后的可执行文件</li>
<li>pkg 包含由库制作的包对象（您现在不必担心）</li>
</ul>
<h2>创建项目目录</h2>
<p>src目录中的项目文件夹应遵循与远程存储库所在位置相同的位置结构。因此，例如，如果我要创建一个名为&quot;birdpedia&quot;的新项目，并在github上以我的名字创建该项目的存储库，这样我的项目存储库的位置将在&quot;github.com/dream2012/birdwiki&quot;上，则该项目在我的计算机上的位置为：$GOPATH/src/github.com/dream2012/birdwiki</p>
<h2>启动http服务器</h2>
<p>现在几乎所有语言都实现了内置的服务器功能，golang亦是如此。</p>

<h2>设置路由</h2>
<p>现在我们无论如何修改url,看到的都是hello world，这是因为我们没有设置路由，就是根据不同url进行不同的操作处理。</p>
<p>安装mux路由</p>
<pre><code class="language-go">go get github.com/gorilla/mux</code></pre>
<pre><code class="language-go">package main

import (
    // Import the gorilla/mux library we just installed
    &quot;fmt&quot;
    &quot;net/http&quot;

    &quot;github.com/gorilla/mux&quot;
)

func main() {
    // Declare a new router
    r := mux.NewRouter()

    // This is where the router is useful, it allows us to declare methods that
    // this path will be valid for
    r.HandleFunc(&quot;/hello&quot;, handler).Methods(&quot;GET&quot;)

    // We can then pass our router (after declaring all our routes) to this method
    // (where previously, we were leaving the secodn argument as nil)
    http.ListenAndServe(&quot;:8080&quot;, r)
}

func handler(w http.ResponseWriter, r *http.Request) {
    fmt.Fprintf(w, &quot;Hello World!&quot;)
}</code></pre>
<p>这回我们只有访问http://127.0.0.1/hello 才能看到hello world,其它地址会看到404</p>
<h2>测试</h2>
<p>好的项目是需要有测试的，这里我们新建一个测试文件1_test.go<br />
这里命名规则采取*_test.go<br />
当我们执行go test 的时候，它会自动搜索_test.go文件进行测试</p>
<pre><code class="language-go">package main

import (
    &quot;net/http&quot;
    &quot;net/http/httptest&quot;
    &quot;testing&quot;
)

func TestHandler(t *testing.T) {
    //Here, we form a new HTTP request. This is the request that&#039;s going to be
    // passed to our handler.
    // The first argument is the method, the second argument is the route (which
    //we leave blank for now, and will get back to soon), and the third is the
    //request body, which we don&#039;t have in this case.
    req, err := http.NewRequest(&quot;GET&quot;, &quot;&quot;, nil)

    // In case there is an error in forming the request, we fail and stop the test
    if err != nil {
        t.Fatal(err)
    }

    // We use Go&#039;s httptest library to create an http recorder. This recorder
    // will act as the target of our http request
    // (you can think of it as a mini-browser, which will accept the result of
    // the http request that we make)
    recorder := httptest.NewRecorder()

    // Create an HTTP handler from our handler function. &quot;handler&quot; is the handler
    // function defined in our main.go file that we want to test
    hf := http.HandlerFunc(handler)

    // Serve the HTTP request to our recorder. This is the line that actually
    // executes our the handler that we want to test
    hf.ServeHTTP(recorder, req)

    // Check the status code is what we expect.
    if status := recorder.Code; status != http.StatusOK {
        t.Errorf(&quot;handler returned wrong status code: got %v want %v&quot;,
            status, http.StatusOK)
    }

    // Check the response body is what we expect.
    expected := `Hello World!`
    actual := recorder.Body.String()
    if actual != expected {
        t.Errorf(&quot;handler returned unexpected body: got %v want %v&quot;, actual, expected)
    }
}

<pre><code class="language-go">// This is the name of our package
// Everything with this package name can see everything
// else inside the same package, regardless of the file they are in
package main

// These are the libraries we are going to use
// Both &quot;fmt&quot; and &quot;net&quot; are part of the Go standard library
import (
    // &quot;fmt&quot; has methods for formatted I/O operations (like printing to the console)
    &quot;encoding/json&quot;
    &quot;fmt&quot;
    // The &quot;net/http&quot; library has methods to implement HTTP clients and servers
    &quot;net/http&quot;

    &quot;github.com/gorilla/mux&quot;
)

type Bird struct {
    Species     string `json:&quot;species&quot;`
    Description string `json:&quot;description&quot;`
}

var birds []Bird

func getBirdHandler(w http.ResponseWriter, r *http.Request) {
    //Convert the &quot;birds&quot; variable to json
    birdListBytes, err := json.Marshal(birds)

    // If there is an error, print it to the console, and return a server
    // error response to the user
    if err != nil {
        fmt.Println(fmt.Errorf(&quot;Error: %v&quot;, err))
        w.WriteHeader(http.StatusInternalServerError)
        return
    }
    // If all goes well, write the JSON list of birds to the response
    w.Write(birdListBytes)
}

func createBirdHandler(w http.ResponseWriter, r *http.Request) {
    // Create a new instance of Bird
    bird := Bird{}

    // We send all our data as HTML form data
    // the `ParseForm` method of the request, parses the
    // form values
    err := r.ParseForm()

    // In case of any error, we respond with an error to the user
    if err != nil {
        fmt.Println(fmt.Errorf(&quot;Error: %v&quot;, err))
        w.WriteHeader(http.StatusInternalServerError)
        return
    }

    // Get the information about the bird from the form info
    bird.Species = r.Form.Get(&quot;species&quot;)
    bird.Description = r.Form.Get(&quot;description&quot;)

    // Append our existing list of birds with a new entry
    birds = append(birds, bird)

    //Finally, we redirect the user to the original HTMl page
    // (located at `/assets/`), using the http libraries `Redirect` method
    http.Redirect(w, r, &quot;/assets/&quot;, http.StatusFound)
}

func main() {
    // import router

    r := mux.NewRouter()
    r.HandleFunc(&quot;/hello&quot;, handler).Methods(&quot;GET&quot;)

    staticFileDirectory := http.Dir(&quot;./static/&quot;)

    staticFileHandler := http.StripPrefix(&quot;/static/&quot;, http.FileServer(staticFileDirectory))
    // The &quot;PathPrefix&quot; method acts as a matcher, and matches all routes starting
    // with &quot;/assets/&quot;, instead of the absolute route itself
    r.PathPrefix(&quot;/static/&quot;).Handler(staticFileHandler).Methods(&quot;GET&quot;)

    r.HandleFunc(&quot;/bird&quot;, getBirdHandler).Methods(&quot;GET&quot;)
    r.HandleFunc(&quot;/bird&quot;, createBirdHandler).Methods(&quot;POST&quot;)

    // However, the handler function has to have the appropriate signature (as described by the &quot;handler&quot; function below)

    // and the handler defined above (in &quot;HandleFunc&quot;) is used
    http.ListenAndServe(&quot;:8080&quot;, r)
}
