<p>Metasploit 是用于渗透测试和漏洞利用的强大工具。它包含一个名为 MSFConsole 的命令行界面，可用于执行各种安全评估任务。</p>
<p>本文将介绍如何在 Ubuntu 上安装 MSFConsole。</p>
<h3>1. 更新系统</h3>
<p>首先，确保您的系统已更新到最新版本。</p>
<pre><code>sudo apt update &amp;&amp; sudo apt upgrade</code></pre>
<h3>2. 安装依赖项</h3>
<p>MSFConsole 需要一些依赖项才能正常工作。</p>
<pre><code>sudo apt install build-essential ruby-dev libpcap-dev libexpat-dev zlib1g-dev
</code></pre>
<h3>3. 克隆 MSFConsole 代码库(为了减小体积，可以只保存最近一次提交)</h3>
<pre><code>git clone --depth=1 https://github.com/rapid7/metasploit-framework.git</code></pre>
<h3>4. 安装 MSFConsole(需要先安装bundle)</h3>
<pre><code>cd metasploit-framework
gem install bundler
bundle install</code></pre>
<h2>5. 使用MSFConsole</h2>
<p>在安装目录调用可执行文件即可使用。</p>
<pre><code>./msfconsole</code></pre>
