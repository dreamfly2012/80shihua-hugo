Metasploit 是用于渗透测试和漏洞利用的强大工具。它包含一个名为 MSFConsole 的命令行界面，可用于执行各种安全评估任务。

本文将介绍如何在 Ubuntu 上安装 MSFConsole。

### 1. 更新系统

首先，确保您的系统已更新到最新版本。

```bash
sudo apt update && sudo apt upgrade
```
### 2. 安装依赖项

MSFConsole 需要一些依赖项才能正常工作。

```bash
sudo apt install build-essential ruby-dev libpcap-dev libexpat-dev zlib1g-dev
```
### 3. 克隆 MSFConsole 代码库(为了减小体积，可以只保存最近一次提交)

```bash
git clone --depth=1 https://github.com/rapid7/metasploit-framework.git
```
### 4. 安装 MSFConsole(需要先安装bundle)

```bash
cd metasploit-framework
gem install bundler
bundle install
```
## 5. 使用MSFConsole

在安装目录调用可执行文件即可使用。

```bash
./msfconsole
```
