<p>有时候我们想测试百万数据的时候，我们的sql语句查询性能，我们就需要构建一个百万数据的测试环境，如何快速构建一个百万测试数据的环境呢，可以通过其它语言程序遍历循环写入，不过这些都有点慢，我们可以直接通过创建存储过程库快速写入百万数据。</p>
<p></p>
<ol class=" list-paddingleft-2" style="list-style-type: decimal;">
<li>
<p>创建一个测试数据表</p>
</li>
</ol>
<p>CREATE TABLE `email` (</p>
<p><span style="white-space:pre">	</span>`id` INT(11) NOT NULL,</p>
<p><span style="white-space:pre">	</span>`email` VARCHAR(50) NULL DEFAULT NULL COMMENT &#39;邮箱&#39; COLLATE &#39;utf8_unicode_ci&#39;,</p>
<p><span style="white-space:pre">	</span>PRIMARY KEY (`id`)</p>
<p>)</p>
<p>COMMENT=&#39;百万email测试表&#39;</p>
<p>COLLATE=&#39;utf8_unicode_ci&#39;</p>
<p>ENGINE=MyISAM</p>
<p>;</p>
<p>&nbsp; 2.创建存储过程，需要注意的是需要将msyql的执行分隔符暂时替换。</p>
<p>delimiter $&nbsp;</p>
<p>DROP PROCEDURE IF EXISTS my_insert;</p>
<p>CREATE PROCEDURE my_insert_126()</p>
<p>BEGIN</p>
<p>&nbsp; &nbsp;<span style="white-space:pre">	</span>DECLARE n int DEFAULT 1;</p>
<p><span style="white-space:pre">	</span>loopname:LOOP</p>
<p><span style="white-space:pre">	</span>&nbsp; &nbsp; INSERT INTO `email`(`email`) VALUES ( n + &#39;@126.com&#39;);</p>
<p><span style="white-space:pre">	</span>&nbsp; &nbsp; SET n=n+1;</p>
<p><span style="white-space:pre">	</span>IF n=5000000 THEN</p>
<p><span style="white-space:pre">	</span>&nbsp; &nbsp; LEAVE loopname;</p>
<p><span style="white-space:pre">	</span>END IF;</p>
<p><span style="white-space:pre">	</span>END LOOP loopname;</p>
<p>END;$</p>
<p></p>
<p>3.执行存储过程即可</p>
<p>call&nbsp;my_insert_126()</p>
<p></p>
<p>这样一个百万数据的测试环境就搭建好了。</p>
<p>大概需要执行40多秒左右的时间。</p>
