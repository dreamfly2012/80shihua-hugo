# mingw

Minimalist GNUfor Windows的缩写。它是一个可自由使用和自由发布的Windows特定头文件和使用GNU工具集导入库的集合，允许你在GNU/Linux和Windows平台生成本地的Windows程序而不需要第三方C运行时（C Runtime）库。MinGW 是一组包含文件和端口库，其功能是允许控制台模式的程序使用微软的标准C运行时（C Runtime）库.

# 使用方法

官网下载，然后安装即可，需要注意的是需要将c:/mingw/bin（mingw是安装目录）添加到环境目录中去。

默认情况它会在桌面创建一个快捷方式，我们通过勾选中需要的开发环境，就可以安装好使用它了，它本质上是一个包管理工具，方便我们下载所需要的c/c++等库。

# 用途

有了它，我们就可以使用任意编辑器进行c语言的开发，如果你不怕麻烦，我们的记事本也可以进行开发。

# 编译一个c语言

```c
include "stdio.h"
int main(int argc, *char argv[])
{
    printf("this is my first c program");
    return 0;
}
```
保存文件格式为utf-8的后缀为.c的文件，例如main.c

在命令行执行下面的命令，就成功编译好c语言文件了。

```bash
gcc -o main mian.c
```
