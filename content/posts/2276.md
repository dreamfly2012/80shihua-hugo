<h1>组件</h1>
<p>vue中使用component来表示组件，通过封装组件，我们可以将代码最大程度的复用，可以说组件是vue中的核心。</p>
<h1>通信交互</h1>
<p>定义了组件之后，我们需要使用它，一般情况我们都是通过在vue中使用compoment方法来引入它，当然有时候也会使用vue.use来引入组件。</p>
<p>组件交互分为两种，一种是父组件的信息传递给子组件，一种是子组件的信息传递给父组件。</p>
<ul>
<li>父传子<br />
父类组件的信息传递给子组件是通过props来传递的。</li>
</ul>
<pre><code class="language-html">&lt;!--父组件--&gt;
&lt;template&gt;
  &lt;div id=&quot;app&quot;&gt;
    &lt;child-compoment :data=&quot;data&quot;&gt;&lt;/child-compoment&gt;  
  &lt;/div&gt;
&lt;/template&gt;
&lt;script&gt;
import child-compoment from &#039;./components/children.vue&#039;

export default {
  name: &#039;App&#039;,
  components: {
    child-compoment
  },
  data:function(){
    return {
        data:&quot;hello world&quot;
    }
  }
&lt;/script&gt;

&lt;!--子组件--&gt;
&lt;template&gt;
    &lt;div class=&quot;content&quot;&gt;
        {{data}}
    &lt;/div&gt;
&lt;/template&gt;
&lt;script&gt;
export default{
    name : &quot;child-compoment&quot;,
    props:{
        data:String
    }
}
&lt;/script&gt;</code></pre>
<ul>
<li>子传父<br />
子组件传递消息给父组件是通过$emit来实现的,$emit有两个参数，一个是event,一个是param,也就是说传递是通过事件进行传递的。</li>
</ul>
<pre><code class="language-html">&lt;!--父组件--&gt;
&lt;template&gt;
&lt;div id=&quot;app&quot;&gt;
    &lt;children-compoment @jump=&quot;getinfo&quot;&gt;&lt;/children-compoment&gt;
    &lt;p&gt;
        {{msg}}
    &lt;/p&gt;
    &lt;/div&gt;
&lt;/template&gt;
&lt;script&gt;
import child-compoment from &#039;./components/children.vue&#039;

export default {
  name: &#039;App&#039;,
  components: {
    &quot;child-compoment&quot;
  },
  data:function{
    return{
        msg : &quot;&quot;
    }
  }
  methods:{
    getinfo:function(value){
        this.msg = value
    }
  }
&lt;/script&gt;

&lt;!--子组件--&gt;
&lt;template&gt;
    &lt;div class=&quot;content&quot;&gt;
        &lt;button @click=&quot;jump&quot;&gt;
            点我传值
        &lt;/button&gt;
    &lt;/div&gt;
&lt;/template&gt;

&lt;script&gt;
export default{
    name:&quot;children-compoment&quot;,
    methods:{
        click:function(){
            this.$emit(&#039;jump&#039;,&quot;传递的值&quot;)
        }
    }
}
&lt;/script&gt;</code></pre>
