windows10 是一款非常优秀的操作系统，不仅有着出色性能，还有这华丽的外表。自身集成WSL，可以非常方便我们进行linux环境下的编程开发。

而它还有非常好用的一些快捷键功能，今天我们就来讲解一下。

| 快捷键 | 功能 |
| --- | --- |
| win+q | 快速搜索 |
| win+w | 白板和截图 |
| win+e | 打开电脑文件夹 |
| win +r | 快速运行 |
| win+i | 打开设置 |
| win+p | 打开第二屏幕 |
| win+l | 快速锁定桌面 |
| win+k | 投影设备 |
| win+g | 游戏录制 |
| win+d | 快速回到桌面 |
| win+s | 快速搜索 |
| win+a | 打开操作中心 |
| win+x | 打开操作面板 |
| win+v | 粘贴板 |
| win+m | 全部应用最小化 |
| win+ctrl+d | 新建虚拟桌面 |
| win+ctrl+箭头 | 切换虚拟桌面 |
| win+tab | 任务视图预览 |
| win+shift+s | 截图 |
| alt+tab | 快速切换任务 |
| Alt + F4 | 关闭窗口 |
| ctrl+home | 文档最顶部 |
| ctrl+end | 文档最底部 |
| ctrl+shift+esc | 任务管理器 |
| ctrl+a | 全选 |
| ctrl+c | 复制 |
| ctrl+v | 粘贴 |
| ctrl+z | 撤销 |
| ctrl+y | 重做，取消撤销 |
| ctrl+f | 查找 |
| ctrl+s | 保存 |
| ctrl+shift+f | 繁体切换 |
