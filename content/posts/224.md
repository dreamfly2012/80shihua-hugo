/**<br />
btnPrev : 上一张按钮<br />
btnNext : 下一张按钮<br />
btnGo : 标签控制，也就是用’1,2,3,4…’来控制<br />
mouseWheel : 是否支持鼠标滑轮滚动，属性值：false / true；默认为false 打开此项需要jQuery UI插件支持<br />
auto : 设置自动播放的速度，默认自动播放是关闭的，格式 auto: 800 (为播放速度)<br />
speed : 动画效果速度<br />
easing : 动画效果优化，姑且这么里面 需要外部插件支持<br />
vertical : 动画方向，如果设置为true，则表示垂直滚动，默认为false<br />
circular : 是否重复播放，如果设置为false，则到最后一个下一张按钮就点不动了，到第一张上一张按钮就点不动<br />
visible : 设置默认显示几个li，默认是3个<br />
start : 效果从第几个开始，默认为0<br />
scroll : 一次滑动几个li，默认是2<br />
beforeStart : 这个是接口，每次滑动效果执行之前执行的自定义函数<br />
afterEnd : 这个是接口，每次滑动效果执行之后执行的自定义函数<br />
*/</p>
<p>/**<br />
* Creates a carousel-style navigation widget for images/any-content from a simple HTML markup.<br />
*<br />
* The HTML markup that is used to build the carousel can be as simple as&#8230;<br />
*<br />
* &lt;div class=&#8221;carousel&#8221;&gt;<br />
* &lt;ul&gt;<br />
* &lt;li&gt;&lt;img src=&#8221;image/1.jpg&#8221; alt=&#8221;1&#8243;&gt;&lt;/li&gt;<br />
* &lt;li&gt;&lt;img src=&#8221;image/2.jpg&#8221; alt=&#8221;2&#8243;&gt;&lt;/li&gt;<br />
* &lt;li&gt;&lt;img src=&#8221;image/3.jpg&#8221; alt=&#8221;3&#8243;&gt;&lt;/li&gt;<br />
* &lt;/ul&gt;<br />
* &lt;/div&gt;<br />
*<br />
* As you can see, this snippet is nothing but a simple div containing an unordered list of images.<br />
* You don&#8217;t need any special &#8220;class&#8221; attribute, or a special &#8220;css&#8221; file for this plugin.<br />
* I am using a class attribute just for the sake of explanation here.<br />
*<br />
* To navigate the elements of the carousel, you need some kind of navigation buttons.<br />
* For example, you will need a &#8220;previous&#8221; button to go backward, and a &#8220;next&#8221; button to go forward.<br />
* This need not be part of the carousel &#8220;div&#8221; itself. It can be any element in your page.<br />
* Lets assume that the following elements in your document can be used as next, and prev buttons&#8230;<br />
*<br />
* &lt;button class=&#8221;prev&#8221;&gt;&amp;lt;&amp;lt;&lt;/button&gt;<br />
* &lt;button class=&#8221;next&#8221;&gt;&amp;gt;&amp;gt;&lt;/button&gt;<br />
*<br />
* Now, all you need to do is call the carousel component on the div element that represents it, and pass in the<br />
* navigation buttons as options.<br />
*<br />
* $(&#8220;.carousel&#8221;).jCarouselLite({<br />
* btnNext: &#8220;.next&#8221;,<br />
* btnPrev: &#8220;.prev&#8221;<br />
* });<br />
*<br />
* That&#8217;s it, you would have now converted your raw div, into a magnificient carousel.<br />
*<br />
* There are quite a few other options that you can use to customize it though.<br />
* Each will be explained with an example below.<br />
*<br />
* @param an options object &#8211; You can specify all the options shown below as an options object param.<br />
*<br />
* @option btnPrev, btnNext : string &#8211; no defaults<br />
* @example<br />
* $(&#8220;.carousel&#8221;).jCarouselLite({<br />
* btnNext: &#8220;.next&#8221;,<br />
* btnPrev: &#8220;.prev&#8221;<br />
* });<br />
* @desc Creates a basic carousel. Clicking &#8220;btnPrev&#8221; navigates backwards and &#8220;btnNext&#8221; navigates forward.<br />
*<br />
* @option btnGo &#8211; array &#8211; no defaults<br />
* @example<br />
* $(&#8220;.carousel&#8221;).jCarouselLite({<br />
* btnNext: &#8220;.next&#8221;,<br />
* btnPrev: &#8220;.prev&#8221;,<br />
* btnGo: [&#8220;.0&#8221;, &#8220;.1&#8221;, &#8220;.2&#8221;]<br />
* });<br />
* @desc If you don&#8217;t want next and previous buttons for navigation, instead you prefer custom navigation based on<br />
* the item number within the carousel, you can use this option. Just supply an array of selectors for each element<br />
* in the carousel. The index of the array represents the index of the element. What i mean is, if the<br />
* first element in the array is &#8220;.0&#8221;, it means that when the element represented by &#8220;.0&#8221; is clicked, the carousel<br />
* will slide to the first element and so on and so forth. This feature is very powerful. For example, i made a tabbed<br />
* interface out of it by making my navigation elements styled like tabs in css. As the carousel is capable of holding<br />
* any content, not just images, you can have a very simple tabbed navigation in minutes without using any other plugin.<br />
* The best part is that, the tab will &#8220;slide&#8221; based on the provided effect. 🙂<br />
*<br />
* @option mouseWheel : boolean &#8211; default is false<br />
* @example<br />
* $(&#8220;.carousel&#8221;).jCarouselLite({<br />
* mouseWheel: true<br />
* });<br />
* @desc The carousel can also be navigated using the mouse wheel interface of a scroll mouse instead of using buttons.<br />
* To get this feature working, you have to do 2 things. First, you have to include the mouse-wheel plugin from brandon.<br />
* Second, you will have to set the option &#8220;mouseWheel&#8221; to true. That&#8217;s it, now you will be able to navigate your carousel<br />
* using the mouse wheel. Using buttons and mouseWheel or not mutually exclusive. You can still have buttons for navigation<br />
* as well. They complement each other. To use both together, just supply the options required for both as shown below.<br />
* @example<br />
* $(&#8220;.carousel&#8221;).jCarouselLite({<br />
* btnNext: &#8220;.next&#8221;,<br />
* btnPrev: &#8220;.prev&#8221;,<br />
* mouseWheel: true<br />
* });<br />
*<br />
* @option auto : number &#8211; default is null, meaning autoscroll is disabled by default<br />
* @example<br />
* $(&#8220;.carousel&#8221;).jCarouselLite({<br />
* auto: 800,<br />
* speed: 500<br />
* });<br />
* @desc You can make your carousel auto-navigate itself by specfying a millisecond value in this option.<br />
* The value you specify is the amount of time between 2 slides. The default is null, and that disables auto scrolling.<br />
* Specify this value and magically your carousel will start auto scrolling.<br />
*<br />
* @option speed : number &#8211; 200 is default<br />
* @example<br />
* $(&#8220;.carousel&#8221;).jCarouselLite({<br />
* btnNext: &#8220;.next&#8221;,<br />
* btnPrev: &#8220;.prev&#8221;,<br />
* speed: 800<br />
* });<br />
* @desc Specifying a speed will slow-down or speed-up the sliding speed of your carousel. Try it out with<br />
* different speeds like 800, 600, 1500 etc. Providing 0, will remove the slide effect.<br />
*<br />
* @option easing : string &#8211; no easing effects by default.<br />
* @example<br />
* $(&#8220;.carousel&#8221;).jCarouselLite({<br />
* btnNext: &#8220;.next&#8221;,<br />
* btnPrev: &#8220;.prev&#8221;,<br />
* easing: &#8220;bounceout&#8221;<br />
* });<br />
* @desc You can specify any easing effect. Note: You need easing plugin for that. Once specified,<br />
* the carousel will slide based on the provided easing effect.<br />
*<br />
* @option vertical : boolean &#8211; default is false<br />
* @example<br />
* $(&#8220;.carousel&#8221;).jCarouselLite({<br />
* btnNext: &#8220;.next&#8221;,<br />
* btnPrev: &#8220;.prev&#8221;,<br />
* vertical: true<br />
* });<br />
* @desc Determines the direction of the carousel. true, means the carousel will display vertically. The next and<br />
* prev buttons will slide the items vertically as well. The default is false, which means that the carousel will<br />
* display horizontally. The next and prev items will slide the items from left-right in this case.<br />
*<br />
* @option circular : boolean &#8211; default is true<br />
* @example<br />
* $(&#8220;.carousel&#8221;).jCarouselLite({<br />
* btnNext: &#8220;.next&#8221;,<br />
* btnPrev: &#8220;.prev&#8221;,<br />
* circular: false<br />
* });<br />
* @desc Setting it to true enables circular navigation. This means, if you click &#8220;next&#8221; after you reach the last<br />
* element, you will automatically slide to the first element and vice versa. If you set circular to false, then<br />
* if you click on the &#8220;next&#8221; button after you reach the last element, you will stay in the last element itself<br />
* and similarly for &#8220;previous&#8221; button and first element.<br />
*<br />
* @option visible : number &#8211; default is 3<br />
* @example<br />
* $(&#8220;.carousel&#8221;).jCarouselLite({<br />
* btnNext: &#8220;.next&#8221;,<br />
* btnPrev: &#8220;.prev&#8221;,<br />
* visible: 4<br />
* });<br />
* @desc This specifies the number of items visible at all times within the carousel. The default is 3.<br />
* You are even free to experiment with real numbers. Eg: &#8220;3.5&#8221; will have 3 items fully visible and the<br />
* last item half visible. This gives you the effect of showing the user that there are more images to the right.<br />
*<br />
* @option start : number &#8211; default is 0<br />
* @example<br />
* $(&#8220;.carousel&#8221;).jCarouselLite({<br />
* btnNext: &#8220;.next&#8221;,<br />
* btnPrev: &#8220;.prev&#8221;,<br />
* start: 2<br />
* });<br />
* @desc You can specify from which item the carousel should start. Remember, the first item in the carousel<br />
* has a start of 0, and so on.<br />
*<br />
* @option scrool : number &#8211; default is 1<br />
* @example<br />
* $(&#8220;.carousel&#8221;).jCarouselLite({<br />
* btnNext: &#8220;.next&#8221;,<br />
* btnPrev: &#8220;.prev&#8221;,<br />
* scroll: 2<br />
* });<br />
* @desc The number of items that should scroll/slide when you click the next/prev navigation buttons. By<br />
* default, only one item is scrolled, but you may set it to any number. Eg: setting it to &#8220;2&#8221; will scroll<br />
* 2 items when you click the next or previous buttons.<br />
*<br />
* @option beforeStart, afterEnd : function &#8211; callbacks<br />
* @example<br />
* $(&#8220;.carousel&#8221;).jCarouselLite({<br />
* btnNext: &#8220;.next&#8221;,<br />
* btnPrev: &#8220;.prev&#8221;,<br />
* beforeStart: function(a) {<br />
* alert(&#8220;Before animation starts:&#8221; + a);<br />
* },<br />
* afterEnd: function(a) {<br />
* alert(&#8220;After animation ends:&#8221; + a);<br />
* }<br />
* });<br />
* @desc If you wanted to do some logic in your page before the slide starts and after the slide ends, you can<br />
* register these 2 callbacks. The functions will be passed an argument that represents an array of elements that<br />
* are visible at the time of callback.<br />
*<br />
*<br />
* @cat Plugins/Image Gallery<br />
* @author Ganeshji Marwaha/ganeshread@gmail.com<br />
*/</p>
<p>(function($) { // Compliant with jquery.noConflict()<br />
$.fn.jCarouselLite = function(o) {<br />
o = $.extend({<br />
btnPrev: null,<br />
btnNext: null,<br />
btnGo: null,<br />
mouseWheel: false,<br />
auto: null,</p>
<p>speed: 200,<br />
easing: null,</p>
<p>vertical: false,<br />
circular: true,<br />
visible: 3,<br />
start: 0,<br />
scroll: 1,</p>
<p>beforeStart: null,<br />
afterEnd: null<br />
}, o || {});</p>
<p>return this.each(function() { // Returns the element collection. Chainable.</p>
<p>var running = false, animCss=o.vertical?&#8221;top&#8221;:&#8221;left&#8221;, sizeCss=o.vertical?&#8221;height&#8221;:&#8221;width&#8221;;<br />
var div = $(this), ul = $(&#8220;ul&#8221;, div), tLi = $(&#8220;li&#8221;, ul), tl = tLi.size(), v = o.visible;</p>
<p>if(o.circular) {<br />
ul.prepend(tLi.slice(tl-v-1+1).clone())<br />
.append(tLi.slice(0,v).clone());<br />
o.start += v;<br />
}</p>
<p>var li = $(&#8220;li&#8221;, ul), itemLength = li.size(), curr = o.start;<br />
div.css(&#8220;visibility&#8221;, &#8220;visible&#8221;);</p>
<p>li.css({overflow: &#8220;hidden&#8221;, float: o.vertical ? &#8220;none&#8221; : &#8220;left&#8221;});<br />
ul.css({margin: &#8220;0&#8221;, padding: &#8220;0&#8221;, position: &#8220;relative&#8221;, &#8220;list-style-type&#8221;: &#8220;none&#8221;, &#8220;z-index&#8221;: &#8220;1&#8221;});<br />
div.css({overflow: &#8220;hidden&#8221;, position: &#8220;relative&#8221;, &#8220;z-index&#8221;: &#8220;2&#8221;, left: &#8220;0px&#8221;});</p>
<p>var liSize = o.vertical ? height(li) : width(li); // Full li size(incl margin)-Used for animation<br />
var ulSize = liSize * itemLength; // size of full ul(total length, not just for the visible items)<br />
var divSize = liSize * v; // size of entire div(total length for just the visible items)</p>
<p>li.css({width: li.width(), height: li.height()});<br />
ul.css(sizeCss, ulSize+&#8221;px&#8221;).css(animCss, -(curr*liSize));</p>
<p>div.css(sizeCss, divSize+&#8221;px&#8221;); // Width of the DIV. length of visible images</p>
<p>if(o.btnPrev)<br />
$(o.btnPrev).click(function() {<br />
return go(curr-o.scroll);<br />
});</p>
<p>if(o.btnNext)<br />
$(o.btnNext).click(function() {<br />
return go(curr+o.scroll);<br />
});</p>
<p>if(o.btnGo)<br />
$.each(o.btnGo, function(i, val) {<br />
$(val).click(function() {<br />
return go(o.circular ? o.visible+i : i);<br />
});<br />
});</p>
<p>if(o.mouseWheel &amp;&amp; div.mousewheel)<br />
div.mousewheel(function(e, d) {<br />
return d&gt;0 ? go(curr-o.scroll) : go(curr+o.scroll);<br />
});</p>
<p>if(o.auto)<br />
setInterval(function() {<br />
go(curr+o.scroll);<br />
}, o.auto+o.speed);</p>
<p>function vis() {<br />
return li.slice(curr).slice(0,v);<br />
};</p>
<p>function go(to) {<br />
if(!running) {</p>
<p>if(o.beforeStart)<br />
o.beforeStart.call(this, vis());</p>
<p>if(o.circular) { // If circular we are in first or last, then goto the other end<br />
if(to&lt;=o.start-v-1) { // If first, then goto last<br />
ul.css(animCss, -((itemLength-(v*2))*liSize)+&#8221;px&#8221;);<br />
// If &#8220;scroll&#8221; &gt; 1, then the &#8220;to&#8221; might not be equal to the condition; it can be lesser depending on the number of elements.<br />
curr = to==o.start-v-1 ? itemLength-(v*2)-1 : itemLength-(v*2)-o.scroll;<br />
} else if(to&gt;=itemLength-v+1) { // If last, then goto first<br />
ul.css(animCss, -( (v) * liSize ) + &#8220;px&#8221; );<br />
// If &#8220;scroll&#8221; &gt; 1, then the &#8220;to&#8221; might not be equal to the condition; it can be greater depending on the number of elements.<br />
curr = to==itemLength-v+1 ? v+1 : v+o.scroll;<br />
} else curr = to;<br />
} else { // If non-circular and to points to first or last, we just return.<br />
if(to&lt;0 || to&gt;itemLength-v) return;<br />
else curr = to;<br />
} // If neither overrides it, the curr will still be &#8220;to&#8221; and we can proceed.</p>
<p>running = true;</p>
<p>ul.animate(<br />
animCss == &#8220;left&#8221; ? { left: -(curr*liSize) } : { top: -(curr*liSize) } , o.speed, o.easing,<br />
function() {<br />
if(o.afterEnd)<br />
o.afterEnd.call(this, vis());<br />
running = false;<br />
}<br />
);<br />
// Disable buttons when the carousel reaches the last/first, and enable when not<br />
if(!o.circular) {<br />
$(o.btnPrev + &#8220;,&#8221; + o.btnNext).removeClass(&#8220;disabled&#8221;);<br />
$( (curr-o.scroll&lt;0 &amp;&amp; o.btnPrev)<br />
||<br />
(curr+o.scroll &gt; itemLength-v &amp;&amp; o.btnNext)<br />
||<br />
[]<br />
).addClass(&#8220;disabled&#8221;);<br />
}</p>
<p>}<br />
return false;<br />
};<br />
});<br />
};</p>
<p>function css(el, prop) {<br />

};<br />
function width(el) {<br />
return el[0].offsetWidth + css(el, &#8216;marginLeft&#8217;) + css(el, &#8216;marginRight&#8217;);<br />
};<br />
function height(el) {<br />
