<h2>docker</h2>
<p>docker 是一种容器，可以将应用进行打包，然后可以发布到任何装有docker环境的系统中，从而实现不依赖系统的镜像文件。</p>
<p>docker使用的是虚拟化技术，所有的镜像都运行在沙盒环境，彼此隔离，不会影响彼此。</p>
<h2>docker 组添加成员</h2>
<p>我们一般使用的是非root用户，每次执行docker都需要sudo,解决办法是将当前用户添加到docker组中</p>
<pre><code class="language-shell">sudo groupadd docker
sudo usermod -aG docker $USER
newgrp docker</code></pre>
<p>上面的命令就将当前用户添加到了docker组中，以后就可以直接使用docker命令，而不需要加上sudo</p>
<h2>docker 镜像</h2>
<p>docker是通过一个个镜像来实现各个功能的，我们一般使用docker search xxx来搜索可用的镜像，但是由于国内的网络问题，我们一般需要先配置下国内docker镜像仓库地址。</p>
<ul>
<li>镜像加速<br />
网易：<a href="https://hub-mirror.c.163.com/">https://hub-mirror.c.163.com/</a><br />
阿里云：https://&lt;你的ID&gt;.mirror.aliyuncs.com<br />
七牛云加速器：<a href="https://reg-mirror.qiniu.com">https://reg-mirror.qiniu.com</a><br />
阿里云的镜像地址需要登陆阿里云后台，访问网址https://cr.console.aliyun.com/cn-hangzhou/instances/mirrors 来查看。<br />
腾讯云：<a href="https://mirror.ccs.tencentyun.com">https://mirror.ccs.tencentyun.com</a></li>
</ul>
<p><strong>对于使用 systemd 的系统，请在 /etc/docker/daemon.json 中写入如下内容（如果文件不存在请新建该文件）：</strong></p>
<pre><code class="language-shell">{&quot;registry-mirrors&quot;:[&quot;https://reg-mirror.qiniu.com/&quot;]}</code></pre>
<p>然后执行命令</p>
<pre><code class="language-shell">$ sudo systemctl daemon-reload
$ sudo systemctl restart docker</code></pre>
<ul>
<li>镜像拉取</li>
</ul>
<p>通过search查找到具体的镜像之后，可以拉取镜像</p>
<pre><code class="language-shell">docker pull ubuntu</code></pre>
<ul>
<li>镜像运行</li>
</ul>
<pre><code class="language-shell">docker run -it ubuntu /bin/bash</code></pre>
<p>i = interactive交互<br />
t = terminal  终端<br />
d = dameon 守护，后台运行的意思</p>
<ul>
<li>查看镜像运行状态</li>
</ul>
<pre><code class="language-shell"> docker ps -a</code></pre>
<ul>
<li>运行停止的镜像</li>
</ul>
<pre><code class="language-shell">docker start xxx(镜像id，可以短id)</code></pre>
<ul>
<li>停止镜像</li>
</ul>
<pre><code class="language-shell">docker stop xxx(镜像id，可以短id)</code></pre>
<ul>
<li>导出镜像</li>
</ul>
<pre><code class="language-shell">docker export xxx &gt; ubuntu.tar</code></pre>
<ul>
<li>导入镜像</li>
</ul>
<pre><code class="language-shell">cat ubuntu.tar | docker import - test/ubuntu:v1</code></pre>
<ul>
<li>删除镜像</li>
</ul>
<pre><code class="language-shell">docker rm -f xxx(镜像短id)</code></pre>
<ul>
<li>运行一个web镜像</li>
</ul>
<pre><code class="language-shell">docker pull training/webapp  # 载入镜像
docker run -d -p 5000:5000 training/webapp python app.py</code></pre>
<ul>
<li>查看镜像运行日志</li>
</ul>
<pre><code class="language-shell">docker logs -f bf08b7f2cd89</code></pre>
