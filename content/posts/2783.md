## linux图形界面

我们知道linux内核是没有图形界面的，所有的linux图形界面都是通过client->server形式构建的，那么我们就可以让本地的机器充当server来显示服务器客户端要显示的图形界面。

## 服务器软件需求

Xorg

Xorg是X11的一个实现，而X Window System是一个C/S结构的程序，Xorg只是提供了一个X Server，负责底层的操作当你运行一个程序的时候，这个程序会连接到X server上，由X server接收键盘鼠标输入和负责屏幕输出窗口的移动，窗口标题的样式等等，都是由一种叫做窗口管理器的程序来完成的，你看到的这些，不但有Xorg，有那三个窗口对应的程序，还有个窗口管理器：Xorg自带的twm如果你想要很好的使用图形界面，那你需要根据自己的情况安装窗口管理器，并进行相应的配置。如果为了省事的话，最好装上KDE或者Gnome之类的桌面环境比较好。

```
 yum -y install xorg-x11-xauth
```
服务器需要打开x11转发

修改 /etc/ssh/sshd_config

确保 ForwardX11Trusted 为 yes

## 本地软件安装

本地安装xming

当您运行应用程序时，Xming 会立即启动 X Windows Server。它等待将不同的应用程序添加到系统的 X 桌面。Xlaunch 被证明是一种方便快捷的启动应用程序的媒介。它包含在 Xming 下载包中。Xlaunch 采用向导式的方法开始在 X 桌面上运行程序。

要自定义程序的显示设置，您可以单击指定的单选按钮。可以从四个不同的选项中进行选择并相应地设置参数。完成后，程序会在选择应用程序作为简单桌面或打开在 X 桌面上运行的客户端时提供一些选择。虽然默认选项只打开桌面，但它让没有经验的用户对特性、功能和使用一无所知。
