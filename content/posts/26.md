<p>dialog boxes in JavaScript always return string. Use isNaN() to determine, like this:</p>
<pre id="pre2" lang="xml"><span class="code-keyword">var</span> ask= prompt(<span class="code-string">"</span><span class="code-string">Please insert number or string"</span>);

<span class="code-keyword">if</span> (isNaN(ask)){

    alert(<span class="code-string">"</span><span class="code-string">You enter a string"</span>);

} <span class="code-keyword">else</span> {

    alert(<span class="code-string">"</span><span class="code-string">You enter a Number"</span>);

}</pre>
