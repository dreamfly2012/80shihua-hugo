<h2>tmux</h2>
<p>tmux是终端多路复用器。它使您可以轻松地在一个终端中的多个程序之间切换，分离它们（它们在后台继续运行），然后将它们重新连接到另一个终端。</p>
<h2>常用命令</h2>
<ul>
<li>
<p>创建新的session</p>
<pre><code>tmux new -s name</code></pre>
</li>
<li>
<p>重命名session</p>
<pre><code>tmux rename-session newname</code></pre>
</li>
<li>
<p>显示全部session</p>
<pre><code>tmux ls</code></pre>
</li>
<li>
<p>切换session</p>
<pre><code>Ctrl+b s</code></pre>
</li>
<li>
<p>退出session</p>
<pre><code>ctrl+b  d</code></pre>
</li>
<li>
<p>关闭session</p>
<pre><code>ctrl +d</code></pre>
</li>
<li>
<p>创建新的窗口</p>
<pre><code>tmux new-window
Ctrl+b c</code></pre>
</li>
<li>
<p>切换窗口</p>
<pre><code>Ctrl+b p
Ctrl+b n
Ctrl+b &lt;number&gt;
Ctrl+b w</code></pre>
</li>
<li>
<p>重命名窗口</p>
<pre><code>tmux rename-window &lt;new-name&gt;
Ctrl+b ,</code></pre>
</li>
<li>
<p>创建窗格</p>
<pre><code>Ctrl+b % 
Ctrl+b &quot;</code></pre>
</li>
<li>
<p>窗格切换</p>
<pre><code>Ctrl+b o</code></pre>
</li>
<li>
<p>关闭窗格</p>
<pre><code>Ctrl+b x</code></pre>
</li>
<li>
<p>窗格全屏切换</p>
<pre><code>Ctrl+b z</code></pre>
</li>
<li>
<p>进入翻页模式</p>
<pre><code>Ctrl+b [</code></pre>
</li>
<li>
<p>退出翻页模式</p>
<pre><code>q</code></pre>
</li>
</ul>
