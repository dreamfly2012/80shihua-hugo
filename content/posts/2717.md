## tmux

tmux是终端多路复用器。它使您可以轻松地在一个终端中的多个程序之间切换，分离它们（它们在后台继续运行），然后将它们重新连接到另一个终端。

## 常用命令

创建新的session

```
<code>tmux new -s name</code>
```
重命名session

```
<code>tmux rename-session newname</code>
```
显示全部session

```
<code>tmux ls</code>
```
切换session

```
<code>Ctrl+b s</code>
```
退出session

```
<code>ctrl+b  d</code>
```
关闭session

```
<code>ctrl +d</code>
```
创建新的窗口

```
<code>tmux new-window
Ctrl+b c</code>
```
切换窗口

```
<code>Ctrl+b p
Ctrl+b n
Ctrl+b <number>
Ctrl+b w</code>
```
重命名窗口

```
<code>tmux rename-window <new-name>
Ctrl+b ,</code>
```
创建窗格

```
<code>Ctrl+b %
Ctrl+b "</code>
```
窗格切换

```
<code>Ctrl+b o</code>
```
关闭窗格

```
<code>Ctrl+b x</code>
```
窗格全屏切换

```
<code>Ctrl+b z</code>
```
进入翻页模式

```
<code>Ctrl+b [</code>
```
退出翻页模式

```
<code>q</code>
```
