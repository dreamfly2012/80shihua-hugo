一个web开发框架，没有路由和模板处理是不应该的，作为python中的重量级框架，django显然这两个都给我们提供好了，下面介绍下如何使用它们。

**路由：**

使用路由很简单，就是在web目录中的urls.py文件中配置即可。

```
django.contrib admin
django.urls path,include,re_path
web.settings MEDIA_ROOT
django.views.static serve
urlpatterns = [
    path(,include()),
    path(, admin.site.urls),
    re_path(,include()),
    re_path(, serve, {: MEDIA_ROOT})
]
```
可以通过include来配置项目目录中的路由处理，也可以直接使用app.views.index (其中app是对应的项目名，index是对应的方法函数)

**模板：**

1. 在项目目录中新建一个templates模板文件夹。

2. ```
在settings.py配置文件中配置模板目录

```

3. ```
在视图中引入render来显示模板

```
