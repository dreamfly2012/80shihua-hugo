<h2>问题</h2>
<p>给出两个 非空 的链表用来表示两个非负的整数。其中，它们各自的位数是按照 逆序 的方式存储的，并且它们的每个节点只能存储 一位 数字。</p>
<p>如果，我们将这两个数相加起来，则会返回一个新的链表来表示它们的和。</p>
<p>您可以假设除了数字 0 之外，这两个数都不会以 0 开头。</p>
<p>示例：</p>
<p>输入：(2 -&gt; 4 -&gt; 3) + (5 -&gt; 6 -&gt; 4)<br />
输出：7 -&gt; 0 -&gt; 8<br />
原因：342 + 465 = 807</p>
<h2>解答</h2>
<pre><code class="language-php">&lt;?php

class ListNode {
    public $val = 0;
    public $next = null;
    function __construct($val) { $this-&gt;val = $val; }
}

$l1 = new ListNode(2);
$l1-&gt;next = new ListNode(4);
$l1-&gt;next-&gt;next = new ListNode(3);

$l2 = new ListNode(5);
$l2-&gt;next = new ListNode(6);
$l2-&gt;next-&gt;next = new ListNode(4);

class Solution
{

    /**
     * @param ListNode $l1
     * @param ListNode $l2
     * @return ListNode
     */
    function addTwoNumbers($l1, $l2)
    {
        $obj = null;

        $additional = 0;
        do {
            $value = $l1-&gt;val + $l2-&gt;val + $additional;
            if ($value &lt; 10) {
                $additional = 0;
            } else {
                $value -= 10;
                $additional = 1;
            }

            $tmp_obj = new ListNode($value);

            if (is_null($obj)) {
                $obj = $tmp_obj;
            } else {
                $next-&gt;next = $tmp_obj;
            }
            $next = $tmp_obj;

            $l1 = $l1-&gt;next;
            $l2 = $l2-&gt;next;
        } while ($l1 || $l2 || $additional);

        return $obj;
    }
}

$solution  = new Solution();

$result = $solution-&gt;addTwoNumbers($l1, $l2);

print_r($result);
