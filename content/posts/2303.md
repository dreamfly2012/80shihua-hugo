<h2>原因</h2>
<p>由于某些原因，再加上github是海外服务器，所以github在国内访问有时候会很慢，这个时候如果想要快速下载，唯一的办法就是使用代理。</p>
<h2>办法</h2>
<p>使用代理进行管理下载，如果你有一个比较快速的代理，那么你可以配置git的变量来使用代理进行下载。</p>
<h2>步骤</h2>
<p>git config &#8211;global proxy.http <a href="http://127.0.0.1:1080">http://127.0.0.1:1080</a></p>
<p>git config &#8211;global proxy.https <a href="http://127.0.0.1:1080">http://127.0.0.1:1080</a></p>
<p>其中1080为代理的端口号，需要和自己配置的一样。</p>
<h2>高级解决办法</h2>
<p>有些时候我们只是希望访问的速度快，而访问国内的时候不走代理，这个时候我们可以配置对于某个网站的代理</p>
<p>git config &#8211;global http.<a href="https://github.com.proxy">https://github.com.proxy</a>  <a href="http://127.0.0.1:1080">http://127.0.0.1:1080</a></p>
<p>git config &#8211;global https.<a href="https://github.com.proxy">https://github.com.proxy</a>  <a href="http://127.0.0.1:1080">http://127.0.0.1:1080</a></p>
<p>我们进行的这些操作实际上是修改的.gitconfig 这个文件。</p>
<p>git config &#8211;global http.<a href="https://domain.com.sslVerify">https://domain.com.sslVerify</a> false</p>
<p>使用https<url>.sslVerify false可以让我们忽略ssl认证。</url></p></p>
