<p>启用REWRITE的伪静态功能的时候，首页可以访问，而访问内页的时候，就提示：“No input file specified.”</p>
<p>原因在于使用的PHP是fast_cgi模式，而在某些情况下，不能正确识别path_info所造成的错误，Wordpress的伪静态也有一样的问题。</p>
<p>WordPress程序默认的.htaccess里面的规则：</p>
<pre>RewriteEngine&nbsp;On

RewriteBase&nbsp;/

RewriteCond&nbsp;%{REQUEST_FILENAME}&nbsp;!-f

RewriteCond&nbsp;%{REQUEST_FILENAME}&nbsp;!-d

RewriteRule&nbsp;^(.*)$&nbsp;/index.php/$1&nbsp;[L]</pre>
<p>“No input file specified.”，是没有得到有效的文件路径造成的。</p>
<p>修改伪静态规则，如下：</p>
<pre>RewriteEngine&nbsp;On

RewriteBase&nbsp;/

RewriteCond&nbsp;%{REQUEST_FILENAME}&nbsp;!-f

RewriteCond&nbsp;%{REQUEST_FILENAME}&nbsp;!-d

RewriteRule&nbsp;^(.*)$&nbsp;/index.php?/$1&nbsp;[L]</pre>
<p>有没有发现不同？</p>
<p>其实就是在正则结果“/$1”前面多加了一个“?”号，问题也就随之解决了。</p>
