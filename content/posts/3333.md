<p>scoop 是windows上的程序管理工具，可以非常方便的在命令行进行程序的安装，管理，卸载等。</p>



<p>下面简单介绍下如如何安装。</p>

<p><strong>需要powershell5.1版本以上</strong></p>



<h2 class="wp-block-heading">安装</h2>



<ol class="wp-block-list">
<li>配置权限</li>
</ol>



<pre class="wp-block-code"><code>Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser</code></pre>



<ol start="2" class="wp-block-list">
<li>安装脚本</li>
</ol>



<pre class="wp-block-code"><code>iwr -useb get.scoop.sh | iex</code></pre>



<ol start="3" class="wp-block-list">
<li>如果是管理员的话</li>
</ol>



<pre class="wp-block-code"><code>iex "&amp; {$(irm get.scoop.sh)} -RunAsAdmin"</code></pre>



<h2 class="wp-block-heading">配置</h2>



<p>列出所有的命令</p>



<pre class="wp-block-code"><code>scoop help </code></pre>



<p>添加常用bucket，可以安装常用软件</p>



<p>Scoop 默认软件仓库（main bucket）软件数量是有限的，但是可以进行额外的添加。通过 <code>scoop bucket known</code> 命令可以查看官方认可的 bucket。</p>



<pre class="wp-block-code"><code></code><code>main - Default bucket for the most common (mostly CLI) apps
extras - Apps that don't fit the main bucket's criteria
games - Open source/freeware games and game-related tools
nerd-fonts - Nerd Fonts
nirsoft - Almost all of the 250+ apps from Nirsoft
sysinternals - Sysinternals Suite and all individual application from Microsoft
java - A collection of Java development kits (JDKs), Java runtime engines (JREs), Java's virtual machine debugging tools and Java based runtime engines.
nonportable - Non-portable apps (may require UAC)
php - Installers for most versions of PHP
versions - Alternative versions of apps found in other buckets</code></pre>



<p>查看已经添加的库 scoop bucket list，以上官方认可的 bucket 可以通过下面这个命令直接添加 scoop bucket add 。</p>



<p>extras 涵盖了大部分因为种种原因不能被收录进主仓库的常用软件，这个是强推荐添加的。</p>



<pre class="wp-block-code"><code>scoop bucket add &lt;bucket&gt;</code></pre>
