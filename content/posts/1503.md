```
curl_setopt($ch,CURLOPT_URL,$this->upload_url);
curl_setopt($ch,CURLOPT_POST,1);
curl_setopt($ch,CURLOPT_POSTFIELDS, $file_fields);
curl_setopt($ch,CURLOPT_SAFE_UPLOAD, false);
```

```
curl_setopt($ch,CURLOPT_POSTFIELDS, $file_fields);
curl_setopt($ch,CURLOPT_SAFE_UPLOAD, false);
curl_setopt($ch,CURLOPT_URL,$this->upload_url);
curl_setopt($ch,CURLOPT_POST,1);
```

上面是2条使用curl上传文件的代码，虽然只是顺序发生了变化，但是下面的却不好用，主要是

```
CURLOPT_POSTFIELDS必须在CURLOPT_URL，CURLOPT_POST前面才能使用，这个应该是源代码中对文件上传做了一些处理导致的
```
