<h2>zephir</h2>
<p>zephir是一个更高级别的编译语言，它通过使用php的语法，来编写php的扩展。<br />
它最后生成的是c代码，是可以被gcc编译优化的，因此它有着出色的性能，和方便编写维护的特点。</p>
<h2>准备工作</h2>
<ol>
<li>需要下载php的源码</li>
<li>需要安装编译环境,如果缺少其它环境，在安装报错后，再安装缺少的依赖（autoconf,automake 都是需要的）
<pre><code class="language-shell">sudo apt-get install git gcc make re2c php php-json php-dev libpcre3-dev build-essential</code></pre>
</li>
</ol>
<h2>安装（需要安装zephir和php-zephir-parser）</h2>
<ul>
<li>可以直接下载zephir</li>
</ul>
<pre><code class="language-shell">git clone https://github.com/phalcon/zephir</code></pre>
<ul>
<li>通过composer安装
<pre><code class="language-shell">composer global require phalcon/zephir</code></pre>
</li>
</ul>
<p><strong>注意</strong><br />
<strong>zephir是php的脚本程序，需要使用php zephir才能运行，不过我们可以在.bashrc中添加配置</strong><br />
比如：</p>
<pre><code class="language-shell">alias zephir=&#039;php /path/zephir&#039;</code></pre>
<pre><code class="language-shell">source .bashrc</code></pre>
<p>我们就可以通过输入zephir来查看安装是否成功。</p>
<pre><code class="language-shell">git clone git://github.com/phalcon/php-zephir-parser.git</code></pre>
<p>安装php-zephir-parse过程</p>
<pre><code class="language-shell">phpize
./configure
make 
make install</code></pre>
<h2>开发一个扩展</h2>
<ol>
<li>使用zephir init kuozhanname创建一个扩展（kuozhanname是扩展名）</li>
<li>进入到kuozhanname文件夹下面，创建一个zep扩展名的文件</li>
<li>引入命名空间</li>
<li>编写扩展代码</li>
<li>zephir build生成扩展</li>
<li>修改php.ini引入扩展</li>
</ol>
