<p>mysql插入有多种方式，下面简单介绍一下</p>
<h2>insert value 插入</h2>
<pre><code>insert into test(name,age) values(&quot;张三&quot;,20);</code></pre>
<h2>insert select 插入</h2>
<pre><code>insert into test(name,age) select name,age from test2;</code></pre>
<h2>insert set 插入</h2>
<pre><code>insert into test set name = &quot;张三&quot;, age = 20;</code></pre>
<h2>replace into 插入</h2>
<pre><code>REPLACE INTO test (name,age) VALUES (&quot;张三&quot;, 15);</code></pre>
<h2>insert ingore into</h2>
<pre><code>INSERT IGNORE INTO test VALUES(1,&quot;张三&quot;,20),(6,&quot;张三&quot;, 15);</code></pre>
<h2>批量插入</h2>
<pre><code>insert into test values(&quot;张三&quot;,20),(&quot;李四&quot;,20)m(&quot;王五&quot;, 18);</code></pre>
