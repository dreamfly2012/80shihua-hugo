mysql插入有多种方式，下面简单介绍一下

## insert value 插入

```
<code>insert into test(name,age) values("张三",20);</code>
```
## insert select 插入

```
<code>insert into test(name,age) select name,age from test2;</code>
```
## insert set 插入

```
<code>insert into test set name = "张三", age = 20;</code>
```
## replace into 插入

```
<code>REPLACE INTO test (name,age) VALUES ("张三", 15);</code>
```
## insert ingore into

```
<code>INSERT IGNORE INTO test VALUES(1,"张三",20),(6,"张三", 15);</code>
```
## 批量插入

```
<code>insert into test values("张三",20),("李四",20)m("王五", 18);</code>
```
