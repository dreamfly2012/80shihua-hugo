<p>配置80端口的时候，需要写成server name <a href="http://www.80shihua.com" _src="http://www.80shihua.com">www.80shihua.com</a> </p>
<p></p>
<p>配置443端口的时候，需要写成server_name <a href="http://www.80shihua.com" _src="http://www.80shihua.com">www.80shihua.com</a> </p>
<p></p>
<p></p>
<p>server{</p>
<p>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; &nbsp; listen 80;</p>
<p>&nbsp; &nbsp; &nbsp; &nbsp; server name www.80shihua.com</p>
<p>}</p>
<p></p>
<p>server{</p>
<p>&nbsp; &nbsp; &nbsp; &nbsp; listen 443 ssl;</p>
<p>&nbsp; &nbsp; &nbsp; &nbsp; server_name www.80shihua.com;</p>
<p>}</p>
