<div class="section" style="margin: -1.2em 0px 0px 60px; padding: 0px; color: rgb(0, 51, 102); font-family: Arial, Helvetica, sans-serif; font-size: 14px; white-space: normal; background-color: rgb(255, 255, 255);">
<h2 style="padding: 0.2em 0px 0.2em 0.7em; margin: 0px 0px 0.5em; font-size: 18px; color: rgb(255, 255, 255); background-color: rgb(64, 88, 113);"><a id="purename" style="color: inherit; background-color: inherit;" name="purename"></a>Running several name-based web sites on a single IP address.</h2>
<p style="line-height: 1.3em; margin-top: 0px; margin-bottom: 1em; padding: 0px;">Your server has a single IP address, and multiple aliases (CNAMES) point to this machine in DNS. You want to run a web server for&nbsp;<code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 1em;">www.example1.com</code>&nbsp;and&nbsp;<code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 1em;">www.example2.org</code>&nbsp;on this machine.</p>
<div class="note" style="padding: 0.5em; margin: 1em 2em 1em 1em; background-color: rgb(238, 238, 238);">
<h3 style="font-size: 14px; margin: 0px 0px 0.5em; padding: 0px; background-color: inherit;">Note</h3>
<p style="margin-top: 0.5em; margin-bottom: 0px; line-height: 1.3em; padding: 0px;">Creating virtual host configurations on your Apache server does not magically cause DNS entries to be created for those host names. You&nbsp;<em>must</em>&nbsp;have the names in DNS, resolving to your IP address, or nobody else will be able to see your web site. You can put entries in your&nbsp;<code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 1em;">hosts</code>&nbsp;file for local testing, but that will work only from the machine with those hosts entries.</p>
</div>
<div class="example" style="color: rgb(0, 0, 0); padding: 0.5em; margin: 1em 2em 1em 1em; background-color: rgb(229, 236, 243);">
<h3 style="color: rgb(0, 51, 102); font-size: 14px; margin: 0px 0px 0.5em; padding: 0px; background-color: inherit;">Server configuration</h3>
<p style="margin-top: 0px; margin-bottom: 0px; line-height: 1em; padding: 0px;"><code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 13px;"># Ensure that Apache listens on port 80<br />Listen 80</p>
<p># Listen for virtual host requests on all IP addresses<br />NameVirtualHost *:80</p>
<p>&lt;VirtualHost *:80&gt;<br /><span class="indent" style="padding-left: 1.5em; display: block;">DocumentRoot /www/example1<br />ServerName www.example1.com</p>
<p># Other directives here</p>
<p></span>&lt;/VirtualHost&gt;</p>
<p>&lt;VirtualHost *:80&gt;<br /><span class="indent" style="padding-left: 1.5em; display: block;">DocumentRoot /www/example2<br />ServerName www.example2.org</p>
<p># Other directives here</p>
<p></span>&lt;/VirtualHost&gt;</code></p>
</div>
<p style="line-height: 1.3em; margin-top: 0px; margin-bottom: 1em; padding: 0px;">The asterisks match all addresses, so the main server serves no requests. Due to the fact that&nbsp;<code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 1em;">www.example1.com</code>&nbsp;is first in the configuration file, it has the highest priority and can be seen as the&nbsp;<cite>default</cite>&nbsp;or&nbsp;<cite>primary</cite>server. That means that if a request is received that does not match one of the specified&nbsp;<code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 1em;">ServerName</code>&nbsp;directives, it will be served by this first&nbsp;<code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 1em;">VirtualHost</code>.</p>
<div class="note" style="padding: 0.5em; margin: 1em 2em 1em 1em; background-color: rgb(238, 238, 238);">
<h3 style="font-size: 14px; margin: 0px 0px 0.5em; padding: 0px; background-color: inherit;">Note</h3>
<p style="margin-top: 0.5em; margin-bottom: 0px; line-height: 1.3em; padding: 0px;">You can, if you wish, replace&nbsp;<code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 1em;">*</code>&nbsp;with the actual IP address of the system. In that case, the argument to&nbsp;<code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 1em;">VirtualHost</code>&nbsp;<em>must</em>&nbsp;match the argument to&nbsp;<code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 1em;">NameVirtualHost</code>:</p>
<div class="example" style="color: inherit; padding: 0.5em; margin: 1em; border: 1px solid rgb(170, 170, 170); background-color: transparent;">
<p style="line-height: 1em; margin-top: 0.5em; margin-bottom: 0px; padding: 0px;"><code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 13px;">NameVirtualHost 172.20.30.40</p>
<p>&lt;VirtualHost 172.20.30.40&gt;<br /># etc ...</code></p>
</div>
<p style="line-height: 1.3em; margin-top: 0.5em; margin-bottom: 0px; padding: 0px;">However, it is additionally useful to use&nbsp;<code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 1em;">*</code>&nbsp;on systems where the IP address is not predictable &#8211; for example if you have a dynamic IP address with your ISP, and you are using some variety of dynamic DNS solution. Since&nbsp;<code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 1em;">*</code>&nbsp;matches any IP address, this configuration would work without changes whenever your IP address changes.</p>
</div>
<p style="line-height: 1.3em; margin-top: 0px; margin-bottom: 1em; padding: 0px;">The above configuration is what you will want to use in almost all name-based virtual hosting situations. The only thing that this configuration will not work for, in fact, is when you are serving different content based on differing IP addresses or ports.</p>
</div>
<div class="top" style="width: 30px; padding: 0px 0px 0px 30px; margin: 0px; color: rgb(0, 51, 102); font-family: Arial, Helvetica, sans-serif; font-size: 14px; white-space: normal; background-color: rgb(255, 255, 255);"><a href="http://httpd.apache.org/docs/2.0/vhosts/examples.html#page-header" style="color: rgb(90, 136, 181); background-color: inherit;"><img decoding="async" alt="top" src="http://httpd.apache.org/docs/2.0/images/up.gif" style="margin-top: 0.5em; vertical-align: bottom; width: 11px; height: 11px; border-style: none;"/></a></div>
<div class="section" style="margin: -1.2em 0px 0px 60px; padding: 0px; color: rgb(0, 51, 102); font-family: Arial, Helvetica, sans-serif; font-size: 14px; white-space: normal; background-color: rgb(255, 255, 255);">
<h2 style="padding: 0.2em 0px 0.2em 0.7em; margin: 0px 0px 0.5em; font-size: 18px; color: rgb(255, 255, 255); background-color: rgb(64, 88, 113);"><a id="twoips" style="color: inherit; background-color: inherit;" name="twoips"></a>Name-based hosts on more than one IP address.</h2>
<div class="note" style="padding: 0.5em; margin: 1em 2em 1em 1em; background-color: rgb(238, 238, 238);">
<h3 style="font-size: 14px; margin: 0px 0px 0.5em; padding: 0px; background-color: inherit;">Note</h3>
<p style="margin-top: 0.5em; margin-bottom: 0px; line-height: 1.3em; padding: 0px;">Any of the techniques discussed here can be extended to any number of IP addresses.</p>
</div>
<p style="line-height: 1.3em; margin-top: 0px; margin-bottom: 1em; padding: 0px;">The server has two IP addresses. On one (<code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 1em;">172.20.30.40</code>), we will serve the &quot;main&quot; server,&nbsp;<code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 1em;">server.domain.com</code>&nbsp;and on the other (<code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 1em;">172.20.30.50</code>), we will serve two or more virtual hosts.</p>
<div class="example" style="color: rgb(0, 0, 0); padding: 0.5em; margin: 1em 2em 1em 1em; background-color: rgb(229, 236, 243);">
<h3 style="color: rgb(0, 51, 102); font-size: 14px; margin: 0px 0px 0.5em; padding: 0px; background-color: inherit;">Server configuration</h3>
<p style="margin-top: 0px; margin-bottom: 0px; line-height: 1em; padding: 0px;"><code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 13px;">Listen 80</p>
<p># This is the &quot;main&quot; server running on 172.20.30.40<br />ServerName server.domain.com<br />DocumentRoot /www/mainserver</p>
<p># This is the other address<br />NameVirtualHost 172.20.30.50</p>
<p>&lt;VirtualHost 172.20.30.50&gt;<br /><span class="indent" style="padding-left: 1.5em; display: block;">DocumentRoot /www/example1<br />ServerName www.example1.com</p>
<p># Other directives here ...</p>
<p></span>&lt;/VirtualHost&gt;</p>
<p>&lt;VirtualHost 172.20.30.50&gt;<br /><span class="indent" style="padding-left: 1.5em; display: block;">DocumentRoot /www/example2<br />ServerName www.example2.org</p>
<p># Other directives here ...</p>
<p></span>&lt;/VirtualHost&gt;</code></p>
</div>
<p style="line-height: 1.3em; margin-top: 0px; margin-bottom: 1em; padding: 0px;">Any request to an address other than&nbsp;<code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 1em;">172.20.30.50</code>&nbsp;will be served from the main server. A request to&nbsp;<code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 1em;">172.20.30.50</code>&nbsp;with an unknown hostname, or no&nbsp;<code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 1em;">Host:</code>&nbsp;header, will be served from&nbsp;<code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 1em;">www.example1.com</code>.</p>
</div>
<div class="top" style="width: 30px; padding: 0px 0px 0px 30px; margin: 0px; color: rgb(0, 51, 102); font-family: Arial, Helvetica, sans-serif; font-size: 14px; white-space: normal; background-color: rgb(255, 255, 255);"><a href="http://httpd.apache.org/docs/2.0/vhosts/examples.html#page-header" style="color: rgb(90, 136, 181); background-color: inherit;"><img decoding="async" alt="top" src="http://httpd.apache.org/docs/2.0/images/up.gif" style="margin-top: 0.5em; vertical-align: bottom; width: 11px; height: 11px; border-style: none;"/></a></div>
<div class="section" style="margin: -1.2em 0px 0px 60px; padding: 0px; color: rgb(0, 51, 102); font-family: Arial, Helvetica, sans-serif; font-size: 14px; white-space: normal; background-color: rgb(255, 255, 255);">
<h2 style="padding: 0.2em 0px 0.2em 0.7em; margin: 0px 0px 0.5em; font-size: 18px; color: rgb(255, 255, 255); background-color: rgb(64, 88, 113);"><a id="intraextra" style="color: inherit; background-color: inherit;" name="intraextra"></a>Serving the same content on different IP addresses (such as an internal and external address).</h2>
<p style="line-height: 1.3em; margin-top: 0px; margin-bottom: 1em; padding: 0px;">The server machine has two IP addresses (<code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 1em;">192.168.1.1</code>&nbsp;and&nbsp;<code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 1em;">172.20.30.40</code>). The machine is sitting between an internal (intranet) network and an external (internet) network. Outside of the network, the name<code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 1em;">server.example.com</code>&nbsp;resolves to the external address (<code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 1em;">172.20.30.40</code>), but inside the network, that same name resolves to the internal address (<code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 1em;">192.168.1.1</code>).</p>
<p style="line-height: 1.3em; margin-top: 0px; margin-bottom: 1em; padding: 0px;">The server can be made to respond to internal and external requests with the same content, with just one&nbsp;<code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 1em;">VirtualHost</code>&nbsp;section.</p>
<div class="example" style="color: rgb(0, 0, 0); padding: 0.5em; margin: 1em 2em 1em 1em; background-color: rgb(229, 236, 243);">
<h3 style="color: rgb(0, 51, 102); font-size: 14px; margin: 0px 0px 0.5em; padding: 0px; background-color: inherit;">Server configuration</h3>
<p style="margin-top: 0px; margin-bottom: 0px; line-height: 1em; padding: 0px;"><code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 13px;">NameVirtualHost 192.168.1.1<br />NameVirtualHost 172.20.30.40</p>
<p>&lt;VirtualHost 192.168.1.1 172.20.30.40&gt;<br /><span class="indent" style="padding-left: 1.5em; display: block;">DocumentRoot /www/server1<br />ServerName server.example.com<br />ServerAlias server<br /></span>&lt;/VirtualHost&gt;</code></p>
</div>
<p style="line-height: 1.3em; margin-top: 0px; margin-bottom: 1em; padding: 0px;">Now requests from both networks will be served from the same&nbsp;<code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 1em;">VirtualHost</code>.</p>
<div class="note" style="padding: 0.5em; margin: 1em 2em 1em 1em; background-color: rgb(238, 238, 238);">
<h3 style="font-size: 14px; margin: 0px 0px 0.5em; padding: 0px; background-color: inherit;">Note:</h3>
<p style="margin-top: 0.5em; margin-bottom: 0px; line-height: 1.3em; padding: 0px;">On the internal network, one can just use the name&nbsp;<code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 1em;">server</code>&nbsp;rather than the fully qualified host name&nbsp;<code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 1em;">server.example.com</code>.</p>
<p style="line-height: 1.3em; margin-top: 0.5em; margin-bottom: 0px; padding: 0px;">Note also that, in the above example, you can replace the list of IP addresses with&nbsp;<code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 1em;">*</code>, which will cause the server to respond the same on all addresses.</p>
</div>
</div>

<div class="section" style="margin: -1.2em 0px 0px 60px; padding: 0px; color: rgb(0, 51, 102); font-family: Arial, Helvetica, sans-serif; font-size: 14px; white-space: normal; background-color: rgb(255, 255, 255);">
<h2 style="padding: 0.2em 0px 0.2em 0.7em; margin: 0px 0px 0.5em; font-size: 18px; color: rgb(255, 255, 255); background-color: rgb(64, 88, 113);"><a id="port" style="color: inherit; background-color: inherit;" name="port"></a>Running different sites on different ports.</h2>
<p style="line-height: 1.3em; margin-top: 0px; margin-bottom: 1em; padding: 0px;">You have multiple domains going to the same IP and also want to serve multiple ports. By defining the ports in the &quot;NameVirtualHost&quot; tag, you can allow this to work. If you try using &lt;VirtualHost name:port&gt; without the NameVirtualHost name:port or you try to use the Listen directive, your configuration will not work.</p>
<div class="example" style="color: rgb(0, 0, 0); padding: 0.5em; margin: 1em 2em 1em 1em; background-color: rgb(229, 236, 243);">
<h3 style="color: rgb(0, 51, 102); font-size: 14px; margin: 0px 0px 0.5em; padding: 0px; background-color: inherit;">Server configuration</h3>
<p style="margin-top: 0px; margin-bottom: 0px; line-height: 1em; padding: 0px;"><code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 13px;">Listen 80<br />Listen 8080</p>
<p>NameVirtualHost 172.20.30.40:80<br />NameVirtualHost 172.20.30.40:8080</p>
<p>&lt;VirtualHost 172.20.30.40:80&gt;<br /><span class="indent" style="padding-left: 1.5em; display: block;">ServerName www.example1.com<br />DocumentRoot /www/domain-80<br /></span>&lt;/VirtualHost&gt;</p>
<p>&lt;VirtualHost 172.20.30.40:8080&gt;<br /><span class="indent" style="padding-left: 1.5em; display: block;">ServerName www.example1.com<br />DocumentRoot /www/domain-8080<br /></span>&lt;/VirtualHost&gt;</p>
<p>&lt;VirtualHost 172.20.30.40:80&gt;<br /><span class="indent" style="padding-left: 1.5em; display: block;">ServerName www.example2.org<br />DocumentRoot /www/otherdomain-80<br /></span>&lt;/VirtualHost&gt;</p>
<p>&lt;VirtualHost 172.20.30.40:8080&gt;<br /><span class="indent" style="padding-left: 1.5em; display: block;">ServerName www.example2.org<br />DocumentRoot /www/otherdomain-8080<br /></span>&lt;/VirtualHost&gt;</code></p>
</div>
</div>

<h2 style="padding: 0.2em 0px 0.2em 0.7em; margin: 0px 0px 0.5em; font-size: 18px; color: rgb(255, 255, 255); background-color: rgb(64, 88, 113);"><a id="ip" style="color: inherit; background-color: inherit;" name="ip"></a>IP-based virtual hosting</h2>
<p style="line-height: 1.3em; margin-top: 0px; margin-bottom: 1em; padding: 0px;">The server has two IP addresses (<code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 1em;">172.20.30.40</code>&nbsp;and&nbsp;<code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 1em;">172.20.30.50</code>) which resolve to the names&nbsp;<code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 1em;">www.example1.com</code>&nbsp;and&nbsp;<code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 1em;">www.example2.org</code>&nbsp;respectively.</p>
<div class="example" style="color: rgb(0, 0, 0); padding: 0.5em; margin: 1em 2em 1em 1em; background-color: rgb(229, 236, 243);">
<h3 style="color: rgb(0, 51, 102); font-size: 14px; margin: 0px 0px 0.5em; padding: 0px; background-color: inherit;">Server configuration</h3>
<p style="margin-top: 0px; margin-bottom: 0px; line-height: 1em; padding: 0px;"><code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 13px;">Listen 80</p>
<p>&lt;VirtualHost 172.20.30.40&gt;<br /><span class="indent" style="padding-left: 1.5em; display: block;">DocumentRoot /www/example1<br />ServerName www.example1.com<br /></span>&lt;/VirtualHost&gt;</p>
<p>&lt;VirtualHost 172.20.30.50&gt;<br /><span class="indent" style="padding-left: 1.5em; display: block;">DocumentRoot /www/example2<br />ServerName www.example2.org<br /></span>&lt;/VirtualHost&gt;</code></p>
</div>
<p style="line-height: 1.3em; margin-top: 0px; margin-bottom: 1em; padding: 0px;">Requests for any address not specified in one of the&nbsp;<code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 1em;">&lt;VirtualHost&gt;</code>&nbsp;directives (such as&nbsp;<code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 1em;">localhost</code>, for example) will go to the main server, if there is one.</p>
</div>
<div class="top" style="width: 30px; padding: 0px 0px 0px 30px; margin: 0px; color: rgb(0, 51, 102); font-family: Arial, Helvetica, sans-serif; font-size: 14px; white-space: normal; background-color: rgb(255, 255, 255);"><a href="http://httpd.apache.org/docs/2.0/vhosts/examples.html#page-header" style="color: rgb(90, 136, 181); background-color: inherit;"><img decoding="async" alt="top" src="http://httpd.apache.org/docs/2.0/images/up.gif" style="margin-top: 0.5em; vertical-align: bottom; width: 11px; height: 11px; border-style: none;"/></a></div>

<h2 style="padding: 0.2em 0px 0.2em 0.7em; margin: 0px 0px 0.5em; font-size: 18px; color: rgb(255, 255, 255); background-color: rgb(64, 88, 113);"><a id="ipport" style="color: inherit; background-color: inherit;" name="ipport"></a>Mixed port-based and ip-based virtual hosts</h2>
<p style="line-height: 1.3em; margin-top: 0px; margin-bottom: 1em; padding: 0px;">The server machine has two IP addresses (<code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 1em;">172.20.30.40</code>&nbsp;and&nbsp;<code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 1em;">172.20.30.50</code>) which resolve to the names&nbsp;<code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 1em;">www.example1.com</code>&nbsp;and&nbsp;<code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 1em;">www.example2.org</code>&nbsp;respectively. In each case, we want to run hosts on ports 80 and 8080.</p>
<div class="example" style="color: rgb(0, 0, 0); padding: 0.5em; margin: 1em 2em 1em 1em; background-color: rgb(229, 236, 243);">
<h3 style="color: rgb(0, 51, 102); font-size: 14px; margin: 0px 0px 0.5em; padding: 0px; background-color: inherit;">Server configuration</h3>
<p style="margin-top: 0px; margin-bottom: 0px; line-height: 1em; padding: 0px;"><code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 13px;">Listen 172.20.30.40:80<br />Listen 172.20.30.40:8080<br />Listen 172.20.30.50:80<br />Listen 172.20.30.50:8080</p>
<p>&lt;VirtualHost 172.20.30.40:80&gt;<br /><span class="indent" style="padding-left: 1.5em; display: block;">DocumentRoot /www/example1-80<br />ServerName www.example1.com<br /></span>&lt;/VirtualHost&gt;</p>
<p>&lt;VirtualHost 172.20.30.40:8080&gt;<br /><span class="indent" style="padding-left: 1.5em; display: block;">DocumentRoot /www/example1-8080<br />ServerName www.example1.com<br /></span>&lt;/VirtualHost&gt;</p>
<p>&lt;VirtualHost 172.20.30.50:80&gt;<br /><span class="indent" style="padding-left: 1.5em; display: block;">DocumentRoot /www/example2-80<br />ServerName www.example1.org<br /></span>&lt;/VirtualHost&gt;</p>
<p>&lt;VirtualHost 172.20.30.50:8080&gt;<br /><span class="indent" style="padding-left: 1.5em; display: block;">DocumentRoot /www/example2-8080<br />ServerName www.example2.org<br /></span>&lt;/VirtualHost&gt;</code></p>
</div>

<h2 style="padding: 0.2em 0px 0.2em 0.7em; margin: 0px 0px 0.5em; font-size: 18px; color: rgb(255, 255, 255); background-color: rgb(64, 88, 113);"><a id="mixed" style="color: inherit; background-color: inherit;" name="mixed"></a>Mixed name-based and IP-based vhosts</h2>
<p style="line-height: 1.3em; margin-top: 0px; margin-bottom: 1em; padding: 0px;">On some of my addresses, I want to do name-based virtual hosts, and on others, IP-based hosts.</p>
<div class="example" style="color: rgb(0, 0, 0); padding: 0.5em; margin: 1em 2em 1em 1em; background-color: rgb(229, 236, 243);">
<h3 style="color: rgb(0, 51, 102); font-size: 14px; margin: 0px 0px 0.5em; padding: 0px; background-color: inherit;">Server configuration</h3>
<p style="margin-top: 0px; margin-bottom: 0px; line-height: 1em; padding: 0px;"><code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 13px;">Listen 80</p>
<p>NameVirtualHost 172.20.30.40</p>
<p>&lt;VirtualHost 172.20.30.40&gt;<br /><span class="indent" style="padding-left: 1.5em; display: block;">DocumentRoot /www/example1<br />ServerName www.example1.com<br /></span>&lt;/VirtualHost&gt;</p>
<p>&lt;VirtualHost 172.20.30.40&gt;<br /><span class="indent" style="padding-left: 1.5em; display: block;">DocumentRoot /www/example2<br />ServerName www.example2.org<br /></span>&lt;/VirtualHost&gt;</p>
<p>&lt;VirtualHost 172.20.30.40&gt;<br /><span class="indent" style="padding-left: 1.5em; display: block;">DocumentRoot /www/example3<br />ServerName www.example3.net<br /></span>&lt;/VirtualHost&gt;</p>
<p># IP-based<br />&lt;VirtualHost 172.20.30.50&gt;<br /><span class="indent" style="padding-left: 1.5em; display: block;">DocumentRoot /www/example4<br />ServerName www.example4.edu<br /></span>&lt;/VirtualHost&gt;</p>
<p>&lt;VirtualHost 172.20.30.60&gt;<br /><span class="indent" style="padding-left: 1.5em; display: block;">DocumentRoot /www/example5<br />ServerName www.example5.gov<br /></span>&lt;/VirtualHost&gt;</code></p>

<div class="top" style="width: 30px; padding: 0px 0px 0px 30px; margin: 0px; color: rgb(0, 51, 102); font-family: Arial, Helvetica, sans-serif; font-size: 14px; white-space: normal; background-color: rgb(255, 255, 255);"><a href="http://httpd.apache.org/docs/2.0/vhosts/examples.html#page-header" style="color: rgb(90, 136, 181); background-color: inherit;"><img decoding="async" alt="top" src="http://httpd.apache.org/docs/2.0/images/up.gif" style="margin-top: 0.5em; vertical-align: bottom; width: 11px; height: 11px; border-style: none;"/></a></div>
<div class="section" style="margin: -1.2em 0px 0px 60px; padding: 0px; color: rgb(0, 51, 102); font-family: Arial, Helvetica, sans-serif; font-size: 14px; white-space: normal; background-color: rgb(255, 255, 255);">
<h2 style="padding: 0.2em 0px 0.2em 0.7em; margin: 0px 0px 0.5em; font-size: 18px; color: rgb(255, 255, 255); background-color: rgb(64, 88, 113);"><a id="proxy" style="color: inherit; background-color: inherit;" name="proxy"></a>Using&nbsp;<code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 1em;">Virtual_host</code>&nbsp;and mod_proxy together</h2>
<p style="line-height: 1.3em; margin-top: 0px; margin-bottom: 1em; padding: 0px;">The following example allows a front-end machine to proxy a virtual host through to a server running on another machine. In the example, a virtual host of the same name is configured on a machine at<code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 1em;">192.168.111.2</code>. The&nbsp;<code class="directive" style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 1em; color: rgb(40, 127, 0); background-color: inherit;"><a href="http://httpd.apache.org/docs/2.0/mod/mod_proxy.html#proxypreservehost on" style="color: rgb(53, 165, 0); background-color: inherit;">ProxyPreserveHost On</a></code>&nbsp;directive is used so that the desired hostname is passed through, in case we are proxying multiple hostnames to a single machine.</p>
<div class="example" style="color: rgb(0, 0, 0); padding: 0.5em; margin: 1em 2em 1em 1em; background-color: rgb(229, 236, 243);">
<p style="line-height: 1em; margin-top: 0px; margin-bottom: 0px; padding: 0px;"><code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 13px;">&lt;VirtualHost *:*&gt;<br />ProxyPreserveHost On<br />ProxyPass / http://192.168.111.2/<br />ProxyPassReverse / http://192.168.111.2/<br />ServerName hostname.example.com<br />&lt;/VirtualHost&gt;</code></p>
</div>
</div>
<div class="top" style="width: 30px; padding: 0px 0px 0px 30px; margin: 0px; color: rgb(0, 51, 102); font-family: Arial, Helvetica, sans-serif; font-size: 14px; white-space: normal; background-color: rgb(255, 255, 255);"><a href="http://httpd.apache.org/docs/2.0/vhosts/examples.html#page-header" style="color: rgb(90, 136, 181); background-color: inherit;"><img decoding="async" alt="top" src="http://httpd.apache.org/docs/2.0/images/up.gif" style="margin-top: 0.5em; vertical-align: bottom; width: 11px; height: 11px; border-style: none;"/></a></div>
<div class="section" style="margin: -1.2em 0px 0px 60px; padding: 0px; color: rgb(0, 51, 102); font-family: Arial, Helvetica, sans-serif; font-size: 14px; white-space: normal; background-color: rgb(255, 255, 255);">
<h2 style="padding: 0.2em 0px 0.2em 0.7em; margin: 0px 0px 0.5em; font-size: 18px; color: rgb(255, 255, 255); background-color: rgb(64, 88, 113);"><a id="default" style="color: inherit; background-color: inherit;" name="default"></a>Using&nbsp;<code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 1em;">_default_</code>&nbsp;vhosts</h2>
<h3 style="font-size: 16px; margin: 1.3em 0px 0.4em; padding: 0px; background-color: inherit;"><a id="defaultallports" style="color: inherit; background-color: inherit;" name="defaultallports"></a><code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 1em;">_default_</code>&nbsp;vhosts for all ports</h3>
<p style="margin-top: 0px; margin-bottom: 1em; line-height: 1.3em; padding: 0px;">Catching&nbsp;<em>every</em>&nbsp;request to any unspecified IP address and port,&nbsp;<em>i.e.</em>, an address/port combination that is not used for any other virtual host.</p>
<div class="example" style="color: rgb(0, 0, 0); padding: 0.5em; margin: 1em 2em 1em 1em; background-color: rgb(229, 236, 243);">
<h3 style="color: rgb(0, 51, 102); font-size: 14px; margin: 0px 0px 0.5em; padding: 0px; background-color: inherit;">Server configuration</h3>
<p style="margin-top: 0px; margin-bottom: 0px; line-height: 1em; padding: 0px;"><code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 13px;">&lt;VirtualHost _default_:*&gt;<br /><span class="indent" style="padding-left: 1.5em; display: block;">DocumentRoot /www/default<br /></span>&lt;/VirtualHost&gt;</code></p>
</div>
<p style="line-height: 1.3em; margin-top: 0px; margin-bottom: 1em; padding: 0px;">Using such a default vhost with a wildcard port effectively prevents any request going to the main server.</p>
<p style="line-height: 1.3em; margin-top: 0px; margin-bottom: 1em; padding: 0px;">A default vhost never serves a request that was sent to an address/port that is used for name-based vhosts. If the request contained an unknown or no&nbsp;<code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 1em;">Host:</code>&nbsp;header it is always served from the primary name-based vhost (the vhost for that address/port appearing first in the configuration file).</p>
<p style="line-height: 1.3em; margin-top: 0px; margin-bottom: 1em; padding: 0px;">You can use&nbsp;<code class="directive" style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 1em; color: rgb(40, 127, 0); background-color: inherit;"><a href="http://httpd.apache.org/docs/2.0/mod/mod_alias.html#aliasmatch" style="color: rgb(53, 165, 0); background-color: inherit;">AliasMatch</a></code>&nbsp;or&nbsp;<code class="directive" style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 1em; color: rgb(40, 127, 0); background-color: inherit;"><a href="http://httpd.apache.org/docs/2.0/mod/mod_rewrite.html#rewriterule" style="color: rgb(53, 165, 0); background-color: inherit;">RewriteRule</a></code>&nbsp;to rewrite any request to a single information page (or script).</p>
<h3 style="font-size: 16px; margin: 1.3em 0px 0.4em; padding: 0px; background-color: inherit;"><a id="defaultdifferentports" style="color: inherit; background-color: inherit;" name="defaultdifferentports"></a><code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 1em;">_default_</code>&nbsp;vhosts for different ports</h3>
<p style="margin-top: 0px; margin-bottom: 1em; line-height: 1.3em; padding: 0px;">Same as setup 1, but the server listens on several ports and we want to use a second&nbsp;<code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 1em;">_default_</code>&nbsp;vhost for port 80.</p>
<div class="example" style="color: rgb(0, 0, 0); padding: 0.5em; margin: 1em 2em 1em 1em; background-color: rgb(229, 236, 243);">
<h3 style="color: rgb(0, 51, 102); font-size: 14px; margin: 0px 0px 0.5em; padding: 0px; background-color: inherit;">Server configuration</h3>
<p style="margin-top: 0px; margin-bottom: 0px; line-height: 1em; padding: 0px;"><code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 13px;">&lt;VirtualHost _default_:80&gt;<br /><span class="indent" style="padding-left: 1.5em; display: block;">DocumentRoot /www/default80<br /># ...<br /></span>&lt;/VirtualHost&gt;</p>
<p>&lt;VirtualHost _default_:*&gt;<br /><span class="indent" style="padding-left: 1.5em; display: block;">DocumentRoot /www/default<br /># ...<br /></span>&lt;/VirtualHost&gt;</code></p>
</div>
<p style="line-height: 1.3em; margin-top: 0px; margin-bottom: 1em; padding: 0px;">The default vhost for port 80 (which&nbsp;<em>must</em>&nbsp;appear before any default vhost with a wildcard port) catches all requests that were sent to an unspecified IP address. The main server is never used to serve a request.</p>
<h3 style="font-size: 16px; margin: 1.3em 0px 0.4em; padding: 0px; background-color: inherit;"><a id="defaultoneport" style="color: inherit; background-color: inherit;" name="defaultoneport"></a><code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 1em;">_default_</code>&nbsp;vhosts for one port</h3>
<p style="margin-top: 0px; margin-bottom: 1em; line-height: 1.3em; padding: 0px;">We want to have a default vhost for port 80, but no other default vhosts.</p>
<div class="example" style="color: rgb(0, 0, 0); padding: 0.5em; margin: 1em 2em 1em 1em; background-color: rgb(229, 236, 243);">
<h3 style="color: rgb(0, 51, 102); font-size: 14px; margin: 0px 0px 0.5em; padding: 0px; background-color: inherit;">Server configuration</h3>
<p style="margin-top: 0px; margin-bottom: 0px; line-height: 1em; padding: 0px;"><code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 13px;">&lt;VirtualHost _default_:80&gt;<br />DocumentRoot /www/default<br />...<br />&lt;/VirtualHost&gt;</code></p>
</div>
<p style="line-height: 1.3em; margin-top: 0px; margin-bottom: 1em; padding: 0px;">A request to an unspecified address on port 80 is served from the default vhost any other request to an unspecified address and port is served from the main server.</p>
</div>
<div class="top" style="width: 30px; padding: 0px 0px 0px 30px; margin: 0px; color: rgb(0, 51, 102); font-family: Arial, Helvetica, sans-serif; font-size: 14px; white-space: normal; background-color: rgb(255, 255, 255);"><a href="http://httpd.apache.org/docs/2.0/vhosts/examples.html#page-header" style="color: rgb(90, 136, 181); background-color: inherit;"><img decoding="async" alt="top" src="http://httpd.apache.org/docs/2.0/images/up.gif" style="margin-top: 0.5em; vertical-align: bottom; width: 11px; height: 11px; border-style: none;"/></a></div>
<div class="section" style="margin: -1.2em 0px 0px 60px; padding: 0px; color: rgb(0, 51, 102); font-family: Arial, Helvetica, sans-serif; font-size: 14px; white-space: normal; background-color: rgb(255, 255, 255);">
<h2 style="padding: 0.2em 0px 0.2em 0.7em; margin: 0px 0px 0.5em; font-size: 18px; color: rgb(255, 255, 255); background-color: rgb(64, 88, 113);"><a id="migrate" style="color: inherit; background-color: inherit;" name="migrate"></a>Migrating a name-based vhost to an IP-based vhost</h2>
<p style="line-height: 1.3em; margin-top: 0px; margin-bottom: 1em; padding: 0px;">The name-based vhost with the hostname&nbsp;<code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 1em;">www.example2.org</code>&nbsp;(from our&nbsp;<a href="http://httpd.apache.org/docs/2.0/vhosts/examples.html#name" style="color: rgb(90, 136, 181); background-color: inherit;">name-based</a>&nbsp;example, setup 2) should get its own IP address. To avoid problems with name servers or proxies who cached the old IP address for the name-based vhost we want to provide both variants during a migration phase.<br />The solution is easy, because we can simply add the new IP address (<code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 1em;">172.20.30.50</code>) to the&nbsp;<code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 1em;">VirtualHost</code>&nbsp;directive.</p>
<div class="example" style="color: rgb(0, 0, 0); padding: 0.5em; margin: 1em 2em 1em 1em; background-color: rgb(229, 236, 243);">
<h3 style="color: rgb(0, 51, 102); font-size: 14px; margin: 0px 0px 0.5em; padding: 0px; background-color: inherit;">Server configuration</h3>
<p style="margin-top: 0px; margin-bottom: 0px; line-height: 1em; padding: 0px;"><code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 13px;">Listen 80<br />ServerName www.example1.com<br />DocumentRoot /www/example1</p>
<p>NameVirtualHost 172.20.30.40</p>
<p>&lt;VirtualHost 172.20.30.40 172.20.30.50&gt;<br /><span class="indent" style="padding-left: 1.5em; display: block;">DocumentRoot /www/example2<br />ServerName www.example2.org<br /># ...<br /></span>&lt;/VirtualHost&gt;</p>
<p>&lt;VirtualHost 172.20.30.40&gt;<br /><span class="indent" style="padding-left: 1.5em; display: block;">DocumentRoot /www/example3<br />ServerName www.example3.net<br />ServerAlias *.example3.net<br /># ...<br /></span>&lt;/VirtualHost&gt;</code></p>
</div>
<p style="line-height: 1.3em; margin-top: 0px; margin-bottom: 1em; padding: 0px;">The vhost can now be accessed through the new address (as an IP-based vhost) and through the old address (as a name-based vhost).</p>
</div>
<div class="top" style="width: 30px; padding: 0px 0px 0px 30px; margin: 0px; color: rgb(0, 51, 102); font-family: Arial, Helvetica, sans-serif; font-size: 14px; white-space: normal; background-color: rgb(255, 255, 255);"><a href="http://httpd.apache.org/docs/2.0/vhosts/examples.html#page-header" style="color: rgb(90, 136, 181); background-color: inherit;"><img decoding="async" alt="top" src="http://httpd.apache.org/docs/2.0/images/up.gif" style="margin-top: 0.5em; vertical-align: bottom; width: 11px; height: 11px; border-style: none;"/></a></div>
<div class="section" style="margin: -1.2em 0px 0px 60px; padding: 0px; color: rgb(0, 51, 102); font-family: Arial, Helvetica, sans-serif; font-size: 14px; white-space: normal; background-color: rgb(255, 255, 255);">
<h2 style="padding: 0.2em 0px 0.2em 0.7em; margin: 0px 0px 0.5em; font-size: 18px; color: rgb(255, 255, 255); background-color: rgb(64, 88, 113);"><a id="serverpath" style="color: inherit; background-color: inherit;" name="serverpath"></a>Using the&nbsp;<code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 1em;">ServerPath</code>&nbsp;directive</h2>
<p style="line-height: 1.3em; margin-top: 0px; margin-bottom: 1em; padding: 0px;">We have a server with two name-based vhosts. In order to match the correct virtual host a client must send the correct&nbsp;<code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 1em;">Host:</code>&nbsp;header. Old HTTP/1.0 clients do not send such a header and Apache has no clue what vhost the client tried to reach (and serves the request from the primary vhost). To provide as much backward compatibility as possible we create a primary vhost which returns a single page containing links with an URL prefix to the name-based virtual hosts.</p>
<div class="example" style="color: rgb(0, 0, 0); padding: 0.5em; margin: 1em 2em 1em 1em; background-color: rgb(229, 236, 243);">
<h3 style="color: rgb(0, 51, 102); font-size: 14px; margin: 0px 0px 0.5em; padding: 0px; background-color: inherit;">Server configuration</h3>
<p style="margin-top: 0px; margin-bottom: 0px; line-height: 1em; padding: 0px;"><code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 13px;">NameVirtualHost 172.20.30.40</p>
<p>&lt;VirtualHost 172.20.30.40&gt;<br /><span class="indent" style="padding-left: 1.5em; display: block;"># primary vhost<br />DocumentRoot /www/subdomain<br />RewriteEngine On<br />RewriteRule ^/.* /www/subdomain/index.html<br /># ...<br /></span>&lt;/VirtualHost&gt;</p>
<p>&lt;VirtualHost 172.20.30.40&gt;<br />DocumentRoot /www/subdomain/sub1<br /><span class="indent" style="padding-left: 1.5em; display: block;">ServerName www.sub1.domain.tld<br />ServerPath /sub1/<br />RewriteEngine On<br />RewriteRule ^(/sub1/.*) /www/subdomain$1<br /># ...<br /></span>&lt;/VirtualHost&gt;</p>
<p>&lt;VirtualHost 172.20.30.40&gt;<br /><span class="indent" style="padding-left: 1.5em; display: block;">DocumentRoot /www/subdomain/sub2<br />ServerName www.sub2.domain.tld<br />ServerPath /sub2/<br />RewriteEngine On<br />RewriteRule ^(/sub2/.*) /www/subdomain$1<br /># ...<br /></span>&lt;/VirtualHost&gt;</code></p>
</div>
<p style="line-height: 1.3em; margin-top: 0px; margin-bottom: 1em; padding: 0px;">Due to the&nbsp;<code class="directive" style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 1em; color: rgb(40, 127, 0); background-color: inherit;"><a href="http://httpd.apache.org/docs/2.0/mod/core.html#serverpath" style="color: rgb(53, 165, 0); background-color: inherit;">ServerPath</a></code>&nbsp;directive a request to the URL&nbsp;<code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 1em;">http://www.sub1.domain.tld/sub1/</code>&nbsp;is&nbsp;<em>always</em>&nbsp;served from the sub1-vhost.<br />A request to the URL&nbsp;<code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 1em;">http://www.sub1.domain.tld/</code>&nbsp;is only served from the sub1-vhost if the client sent a correct&nbsp;<code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 1em;">Host:</code>&nbsp;header. If no&nbsp;<code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 1em;">Host:</code>&nbsp;header is sent the client gets the information page from the primary host.<br />Please note that there is one oddity: A request to&nbsp;<code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 1em;">http://www.sub2.domain.tld/sub1/</code>&nbsp;is also served from the sub1-vhost if the client sent no&nbsp;<code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 1em;">Host:</code>&nbsp;header.<br />The&nbsp;<code class="directive" style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 1em; color: rgb(40, 127, 0); background-color: inherit;"><a href="http://httpd.apache.org/docs/2.0/mod/mod_rewrite.html#rewriterule" style="color: rgb(53, 165, 0); background-color: inherit;">RewriteRule</a></code>&nbsp;directives are used to make sure that a client which sent a correct&nbsp;<code style="font-family: &#39;Courier New&#39;, Courier, monospace; font-size: 1em;">Host:</code>&nbsp;header can use both URL variants,&nbsp;<em>i.e.</em>, with or without URL prefix.</p>
</div>
<p></p>
